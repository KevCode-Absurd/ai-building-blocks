# App starter pack

Turn the skills and workflows you already use into an app your team can sign in to. From AI Blocks (useaiblocks.com/apps/starter-pack).

1. Put this folder next to your skills (any folder with `SKILL.md` files) and open it in an AI coding assistant that can read and edit files. In a chat, upload the files and save the code it returns.
2. Paste the prompt in `START-HERE.md`.
3. Answer the questions. Your AI writes a one-page brief, waits for your OK, then builds one stage at a time.

You don't need every stage. Many apps stop at stage 3. Agents (stage 7) are optional.

| Stage | You get |
|---|---|
| 1 One screen | One skill behind a form and a button |
| 2 Save the work | Every result kept, with history and approvals |
| 3 Run the workflow | Several skills in order, as jobs you can watch |
| 4 Sign in | Accounts, so only your people get in |
| 5 Teams and roles | Workspaces, roles and shared work: a multiplayer app |
| 6 Connect your data | Read-only links to your tools, a refresh button, routines |
| 7 Agents (optional) | An AI that picks its next step, inside guard rails |
| 8 Go live | Hosting, secrets, backups, spend caps |
| 9 Combine apps | Two or more apps behind one sign-in, sharing what they all use |

Example apps built this way: useaiblocks.com/apps.
