# Use Inclusive Visuals Specialist agent

Describe the people and the story. Get image or video prompts built to avoid stereotypes, cloned faces and fake cultural symbols, plus a review checklist.

## Skill hosts

Install the complete agency-design-inclusive-visuals-specialist folder with SKILL.md and references/ together. The skill reads the original profile when used.

## Chat

Paste SKILL.md, then references/source-agent.md, then your task. A plain chat can propose work; files, tools and recurring runs depend on the host you use.

## Claude Code agent

The unmodified references/source-agent.md is the upstream agent file. Copy it to .claude/agents/agency-design-inclusive-visuals-specialist.md in your chosen project. Supply the task scope and review rules in SKILL.md when invoking it.

## Other agent hosts

Import the role profile using the host's documented agent format. This pack does not register Codex agents, install software, provision integrations or create schedules.
