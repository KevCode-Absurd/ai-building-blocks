# Use Messy data cleanup agent

Fix messy data with a few tested rules, not row-by-row. You get fix formulas, a change log and a review list of risky rows.

## Skill hosts

Install the complete agency-engineering-ai-data-remediation-engineer folder with SKILL.md and references/ together. The skill reads the original profile when used.

## Chat

Paste SKILL.md, then references/source-agent.md, then your task. A plain chat can propose work; files, tools and recurring runs depend on the host you use.

## Claude Code agent

The unmodified references/source-agent.md is the upstream agent file. Copy it to .claude/agents/agency-engineering-ai-data-remediation-engineer.md in your chosen project. Supply the task scope and review rules in SKILL.md when invoking it.

## Other agent hosts

Import the role profile using the host's documented agent format. This pack does not register Codex agents, install software, provision integrations or create schedules.
