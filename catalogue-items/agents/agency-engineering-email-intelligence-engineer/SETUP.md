# Use Email Intelligence Engineer agent

Turn a messy email thread into who said what, decisions and tasks with owners. Or plan the pipeline that does it for many threads.

## Skill hosts

Install the complete agency-engineering-email-intelligence-engineer folder with SKILL.md and references/ together. The skill reads the original profile when used.

## Chat

Paste SKILL.md, then references/source-agent.md, then your task. A plain chat can propose work; files, tools and recurring runs depend on the host you use.

## Claude Code agent

The unmodified references/source-agent.md is the upstream agent file. Copy it to .claude/agents/agency-engineering-email-intelligence-engineer.md in your chosen project. Supply the task scope and review rules in SKILL.md when invoking it.

## Other agent hosts

Import the role profile using the host's documented agent format. This pack does not register Codex agents, install software, provision integrations or create schedules.
