# Use Healthcare Innovation Strategist agent

Draft or sharpen a healthcare investor memo, regulatory brief or grant section with one clear thesis and sourced claims. Not legal advice.

## Skill hosts

Install the complete agency-healthcare-innovation-strategist folder with SKILL.md and references/ together. The skill reads the original profile when used.

## Chat

Paste SKILL.md, then references/source-agent.md, then your task. A plain chat can propose work; files, tools and recurring runs depend on the host you use.

## Claude Code agent

The unmodified references/source-agent.md is the upstream agent file. Copy it to .claude/agents/agency-healthcare-innovation-strategist.md in your chosen project. Supply the task scope and review rules in SKILL.md when invoking it.

## Other agent hosts

Import the role profile using the host's documented agent format. This pack does not register Codex agents, install software, provision integrations or create schedules.
