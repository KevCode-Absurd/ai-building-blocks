# Use Hospitality Guest Services agent

Get guest service response drafts with requests and escalation steps. Bring your brief.

Install the complete agency-hospitality-guest-services folder with SKILL.md and references/ together. The skill reads the original profile when used.

## Chat

Paste SKILL.md, then references/source-agent.md, then your task. A plain chat can propose work; files, tools and recurring runs depend on the host you use.

## Claude Code agent

The unmodified references/source-agent.md is the upstream agent file. Copy it to .claude/agents/agency-hospitality-guest-services.md in your chosen project. Supply the task scope and review rules in SKILL.md when invoking it.

## Other agent hosts
