# Use M&A Integration Manager agent

Plan your first 100 days after buying or merging with a business. Get a Day 1 checklist, workstream owners, dependencies and the risks to watch.

## Skill hosts

Install the complete agency-ma-integration-manager folder with SKILL.md and references/ together. The skill reads the original profile when used.

## Chat

Paste SKILL.md, then references/source-agent.md, then your task. A plain chat can propose work; files, tools and recurring runs depend on the host you use.

## Claude Code agent

The unmodified references/source-agent.md is the upstream agent file. Copy it to .claude/agents/agency-ma-integration-manager.md in your chosen project. Supply the task scope and review rules in SKILL.md when invoking it.

## Other agent hosts

Import the role profile using the host's documented agent format. This pack does not register Codex agents, install software, provision integrations or create schedules.
