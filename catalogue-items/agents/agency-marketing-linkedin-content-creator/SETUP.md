# Use LinkedIn Content Creator agent

Get a LinkedIn voice profile, three content pillars, a 30-day calendar and post drafts with three hook options each. Bring your goal and stories.

## Skill hosts

Install the complete agency-marketing-linkedin-content-creator folder with SKILL.md and references/ together. The skill reads the original profile when used.

## Chat

Paste SKILL.md, then references/source-agent.md, then your task. A plain chat can propose work; files, tools and recurring runs depend on the host you use.

## Claude Code agent

The unmodified references/source-agent.md is the upstream agent file. Copy it to .claude/agents/agency-marketing-linkedin-content-creator.md in your chosen project. Supply the task scope and review rules in SKILL.md when invoking it.

## Other agent hosts

Import the role profile using the host's documented agent format. This pack does not register Codex agents, install software, provision integrations or create schedules.
