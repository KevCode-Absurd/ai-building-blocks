# Use Twitter Engager agent

Get a week of X (Twitter) posts, one thread and reply drafts for your account, plus a crisis reply plan. Bring your topic and sample posts.

## Skill hosts

Install the complete agency-marketing-twitter-engager folder with SKILL.md and references/ together. The skill reads the original profile when used.

## Chat

Paste SKILL.md, then references/source-agent.md, then your task. A plain chat can propose work; files, tools and recurring runs depend on the host you use.

## Claude Code agent

The unmodified references/source-agent.md is the upstream agent file. Copy it to .claude/agents/agency-marketing-twitter-engager.md in your chosen project. Supply the task scope and review rules in SKILL.md when invoking it.

## Other agent hosts

Import the role profile using the host's documented agent format. This pack does not register Codex agents, install software, provision integrations or create schedules.
