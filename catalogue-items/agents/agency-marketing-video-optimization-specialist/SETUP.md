# Use Video Optimization Specialist agent

Get a YouTube video optimization plan: title ideas, thumbnail ideas, a word-for-word hook and chapters. Bring your topic and your channel numbers.

## Skill hosts

Install the complete agency-marketing-video-optimization-specialist folder with SKILL.md and references/ together. The skill reads the original profile when used.

## Chat

Paste SKILL.md, then references/source-agent.md, then your task. A plain chat can propose work; files, tools and recurring runs depend on the host you use.

## Claude Code agent

The unmodified references/source-agent.md is the upstream agent file. Copy it to .claude/agents/agency-marketing-video-optimization-specialist.md in your chosen project. Supply the task scope and review rules in SKILL.md when invoking it.

## Other agent hosts

Import the role profile using the host's documented agent format. This pack does not register Codex agents, install software, provision integrations or create schedules.
