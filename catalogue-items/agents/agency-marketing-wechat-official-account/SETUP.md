# Use WeChat Official Account Manager agent

Get a WeChat Official Account content plan: reader profile, content themes, a 12-week calendar and a menu and auto-reply set-up. Bring your goal.

## Skill hosts

Install the complete agency-marketing-wechat-official-account folder with SKILL.md and references/ together. The skill reads the original profile when used.

## Chat

Paste SKILL.md, then references/source-agent.md, then your task. A plain chat can propose work; files, tools and recurring runs depend on the host you use.

## Claude Code agent

The unmodified references/source-agent.md is the upstream agent file. Copy it to .claude/agents/agency-marketing-wechat-official-account.md in your chosen project. Supply the task scope and review rules in SKILL.md when invoking it.

## Other agent hosts

Import the role profile using the host's documented agent format. This pack does not register Codex agents, install software, provision integrations or create schedules.
