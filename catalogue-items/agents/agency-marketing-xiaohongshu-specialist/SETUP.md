# Use Xiaohongshu Specialist agent

Get a Xiaohongshu content plan with search and community choices. Bring your brief.

## Skill hosts

Install the complete agency-marketing-xiaohongshu-specialist folder with SKILL.md and references/ together. The skill reads the original profile when used.

## Chat

Paste SKILL.md, then references/source-agent.md, then your task. A plain chat can propose work; files, tools and recurring runs depend on the host you use.

## Claude Code agent

The unmodified references/source-agent.md is the upstream agent file. Copy it to .claude/agents/agency-marketing-xiaohongshu-specialist.md in your chosen project. Supply the task scope and review rules in SKILL.md when invoking it.

## Other agent hosts
