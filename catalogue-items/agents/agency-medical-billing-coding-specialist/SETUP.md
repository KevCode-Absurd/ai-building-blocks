# Use Medical Billing & Coding Specialist agent

Check medical coding and claims against the visit notes, triage denials and draft appeal letters. A certified coder signs off before you submit.

## Before you start

Patient information is protected. Remove names, dates of birth, member IDs and record numbers before you paste anything, and use only a tool your practice's privacy rules allow. A certified coder or billing professional reviews the result before anything goes to a payer.

## Skill hosts

Install the complete agency-medical-billing-coding-specialist folder with SKILL.md and references/ together. The skill reads the original profile when used.

## Chat

Paste SKILL.md, then references/source-agent.md, then your task. A plain chat can propose work; files, tools and recurring runs depend on the host you use.

## Claude Code agent

The unmodified references/source-agent.md is the upstream agent file. Copy it to .claude/agents/agency-medical-billing-coding-specialist.md in your chosen project. Supply the task scope and review rules in SKILL.md when invoking it.

## Other agent hosts

Import the role profile using the host's documented agent format. This pack does not register Codex agents, install software, provision integrations or create schedules.
