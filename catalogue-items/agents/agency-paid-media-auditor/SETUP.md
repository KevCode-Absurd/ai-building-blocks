# Use Paid Media Auditor agent

Paste your Google, Microsoft or Meta ad exports. Get ranked account problems, each with proof from your data, a fix and the effort needed.

## Skill hosts

Install the complete agency-paid-media-auditor folder with SKILL.md and references/ together. The skill reads the original profile when used.

## Chat

Paste SKILL.md, then references/source-agent.md, then your task. A plain chat can propose work; files, tools and recurring runs depend on the host you use.

## Claude Code agent

The unmodified references/source-agent.md is the upstream agent file. Copy it to .claude/agents/agency-paid-media-auditor.md in your chosen project. Supply the task scope and review rules in SKILL.md when invoking it.

## Other agent hosts

Import the role profile using the host's documented agent format. This pack does not register Codex agents, install software, provision integrations or create schedules.
