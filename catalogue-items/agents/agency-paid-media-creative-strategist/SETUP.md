# Use Ad creative strategist agent for Google and Meta ads

Get Google search ad headlines, Meta ad text and a test plan from your offer and buyer. Draft ads for Google, Meta and Performance Max to review.

## Skill hosts

Install the complete agency-paid-media-creative-strategist folder with SKILL.md and references/ together. The skill reads the original profile when used.

## Chat

Paste SKILL.md, then references/source-agent.md, then your task. A plain chat can propose work; files, tools and recurring runs depend on the host you use.

## Claude Code agent

The unmodified references/source-agent.md is the upstream agent file. Copy it to .claude/agents/agency-paid-media-creative-strategist.md in your chosen project. Supply the task scope and review rules in SKILL.md when invoking it.

## Other agent hosts

Import the role profile using the host's documented agent format. This pack does not register Codex agents, install software, provision integrations or create schedules.
