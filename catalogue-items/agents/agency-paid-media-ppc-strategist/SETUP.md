# Use PPC Campaign Strategist agent

Plan or rebuild a Google Ads search account. Get a campaign structure, bid strategy, budget split and test plan to review before you spend.

## Skill hosts

Install the complete agency-paid-media-ppc-strategist folder with SKILL.md and references/ together. The skill reads the original profile when used.

## Chat

Paste SKILL.md, then references/source-agent.md, then your task. A plain chat can propose work; files, tools and recurring runs depend on the host you use.

## Claude Code agent

The unmodified references/source-agent.md is the upstream agent file. Copy it to .claude/agents/agency-paid-media-ppc-strategist.md in your chosen project. Supply the task scope and review rules in SKILL.md when invoking it.

## Other agent hosts

Import the role profile using the host's documented agent format. This pack does not register Codex agents, install software, provision integrations or create schedules.
