# Use Jira Workflow Steward agent

Turn a Jira ticket into a Git branch name, commit messages and a pull request description. Every code change is traceable from ticket to release.

## Skill hosts

Install the complete agency-project-management-jira-workflow-steward folder with SKILL.md and references/ together. The skill reads the original profile when used.

## Chat

Paste SKILL.md, then references/source-agent.md, then your task. A plain chat can propose work; files, tools and recurring runs depend on the host you use.

## Claude Code agent

The unmodified references/source-agent.md is the upstream agent file. Copy it to .claude/agents/agency-project-management-jira-workflow-steward.md in your chosen project. Supply the task scope and review rules in SKILL.md when invoking it.

## Other agent hosts

Import the role profile using the host's documented agent format. This pack does not register Codex agents, install software, provision integrations or create schedules.
