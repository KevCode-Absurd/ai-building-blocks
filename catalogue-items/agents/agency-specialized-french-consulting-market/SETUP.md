# Use French Consulting Market Navigator agent

Get a French consulting market brief with positioning and negotiation choices. Bring your brief.

## Skill hosts

Install the complete agency-specialized-french-consulting-market folder with SKILL.md and references/ together. The skill reads the original profile when used.

## Chat

Paste SKILL.md, then references/source-agent.md, then your task. A plain chat can propose work; files, tools and recurring runs depend on the host you use.

## Claude Code agent

The unmodified references/source-agent.md is the upstream agent file. Copy it to .claude/agents/agency-specialized-french-consulting-market.md in your chosen project. Supply the task scope and review rules in SKILL.md when invoking it.
