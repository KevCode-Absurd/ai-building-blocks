# When to use `/photography-styles`

**What it does:** Picks photography style for an ad or a campaign. Output is a primary style, a secondary style for variation testing, and one to avoid.

**Runtime:** 2 minutes.

## Run this when

1. **Starting a new brand relationship.** Style becomes a brand standard.
2. **Creative feels off-vibe.** Style is usually the culprit.
3. **Testing whether UGC or editorial fits.** Run one campaign of each, compare.
4. **Platform migration.** Moving from feed to Reels may require style shift (editorial to UGC).

## Before you run

- Brand DNA (for positioning)
- Audience definition
- Platform(s) you'll run on
- Past creative (to identify what has worked / failed)

## What you get back

- Primary style recommendation with reasoning
- Secondary style for variation testing
- Avoid list with reasoning
- Execution notes (lighting, lens, grading, talent, props)

## Chains well with

- `/brand-dna` first (informs positioning)
- `/ad-design-levers` next (style is Lever 7)
- `/generate-ad` consumes the style spec
- `/creative-brief` folds it into the production document
