# When to use `/copy-frameworks`

**What it does:** Calibrates ad copy to the customer's awareness stage. Applies the right framework (Education, PAS, Feature-Benefit-Proof, Us vs Them, Urgency) depending on stage. Prevents the #1 copy mistake: writing for the wrong awareness.

**Runtime:** 60-90 seconds.

## Run this when

1. **Prospecting copy isn't converting.** Usually it's written for Solution-Aware but audience is Problem-Aware.
2. **Retargeting audiences are stalling.** Copy is too educational for Most-Aware audience.
3. **Building a funnel.** Different copy for top/mid/bottom of funnel across stages.
4. **Diagnosing a poor-performing ad.** Often the copy was written for a stage the audience isn't in.

## Before you run

- Product + one-sentence description
- Best guess at audience awareness stage
- The funnel position (prospecting / mid-funnel / retargeting)
- Any existing copy to compare against

## What you get back

- Identified stage with confidence
- The right framework for that stage
- Full copy set (headline + subhead + body + CTA)
- Adjacent-stage cross-check
- Warnings if the current copy is stage-mismatched

## Chains well with

- `/persona-stage-theme` before, to get the stage right
- `/ad-copy` after, to produce multiple framework variants
- `/5-headline-angles` for specific angle variants within a stage
- `/ab-test` to test two different stage-calibrated variants
