# When to use `/buyer-psychology`

**What it does:** Maps the buyer's decision journey using the TEEP framework (Trigger, Emotion, Evidence, Payoff). Diagnoses which psychological element your ads are missing.

**Runtime:** 2-3 minutes.

## Run this when

1. **Ads have low conversion despite good hooks.** Usually missing a TEEP element.
2. **Onboarding a new client.** Establish the psychology before designing creative.
3. **A winning ad has decayed.** Figure out which element you under-invested in.
4. **Briefing a creative team.** Give them the TEEP map, not "make it convert."

## Before you run

- Product + one-sentence description
- Primary target audience (specific)
- Existing ad concepts (optional, for audit)
- Customer reviews or interview data (optional, for trigger identification)

## What you get back

- TEEP map for the audience
- Audit of existing ad concepts against TEEP coverage
- Recommendations for which element to lead with per funnel position

## Chains well with

- `/teep-framework` for the deeper framework walkthrough
- `/persona-stage-theme` to combine psychology with awareness stage
- `/ad-copy` for stage-calibrated copy informed by the map
- `/creative-brief` to brief production with the map as input
