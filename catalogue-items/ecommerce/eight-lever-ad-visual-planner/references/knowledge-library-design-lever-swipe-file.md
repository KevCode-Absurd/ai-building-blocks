# Design Lever Swipe File (40 entries)

Tagged examples of 8-lever configurations that have produced winning ads. Use this as a starting library when briefing a new sprint.

**Tag legend:**
- `[theme:X]` — which of the 9 themes it fits
- `[mood:X]` — dominant emotional tone
- `[vertical:X]` — product category best suited
- `[stage:X]` — buyer awareness stage
- `[format:X]` — static, video, carousel

## How to Use This Swipe File

1. Start with the theme you selected (from layout-selection-flowchart.md).
2. Filter entries by `[theme:X]` tag.
3. Within that theme, filter by `[stage:X]` matching your brief.
4. Pick the entry closest to your brand's visual position.
5. Use its 8-lever configuration as the starting point in your brief.
6. Modify 1-2 levers for differentiation (your account's Andromeda score determines how many).

**Do not copy entries verbatim across accounts.** These are starting points, not templates. Every lever should be tuned to the specific brand vocabulary.
