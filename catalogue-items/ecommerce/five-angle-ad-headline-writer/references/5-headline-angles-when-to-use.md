# When to use `/5-headline-angles`

**What it does:** Generates 5 distinct headlines for one ad concept, each using a different rhetorical angle (benefit-first, curiosity, question, callout, contrarian). Built for rapid A/B testing.

**Runtime:** 30-45 seconds.

## Run this when

1. **You have one visual and need multiple copy tests.** Fastest way to test which angle lands.
2. **A headline has fatigued.** Same ad, 5 new framings to try.
3. **Onboarding a new category.** You don't know which angle resonates yet.
4. **Before a big spend push.** Test 2-3 angles before scaling.

## Before you run

- Product + one-sentence description
- Core benefit / USP
- Specific audience
- Awareness stage

## What you get back

- 5 headlines, each tagged by angle
- Character counts
- Stage fit per angle
- Top-2 recommendation for testing

## Chains well with

- `/ad-copy` for full copy sets around a winning headline
- `/hook-generator` if headline needs to double as video hook
- `/ab-test` to design the actual test
