# 5-Point Scale-Readiness Checklist

The gate any campaign must pass before getting more budget. All 5 must pass. 4/5 is NO.

---

## Check 1: CPA Below Target for 2+ Weeks

PASS if: CPA consistently under target for 14+ days, no spikes above 1.5x target.
FAIL if: CPA above target, or oscillating (below one day, above the next).

Why: scaling a campaign with unstable CPA amplifies the instability.

## Check 2: Conversion Volume Sufficient

PASS if:
- Meta: 50+ conversions in the last 7 days
- Google: 30+ conversions in the last 30 days
- TikTok: 25+ conversions in the last 7 days

FAIL if below threshold. Platform learning requires volume.

Why: scaling a low-volume campaign wastes budget on exploration, not conversion.

## Check 3: CTR Stable or Improving

PASS if: CTR flat or trending up over the last 14 days.
FAIL if: CTR declined >10% from 14-day peak.

Why: declining CTR means creative fatigue. More budget = faster fatigue.

## Check 4: ROAS Above Target

PASS if: ROAS > target for 14+ consecutive days.
FAIL if: ROAS below target at any point in the last 14 days, or inconsistent.

Why: scaling below target multiplies the loss.

## Check 5: No Creative Fatigue

PASS if:
- Frequency (7-day) < 3.0 for prospecting, < 6.0 for retargeting
- Active rotation (new creatives added in last 14 days OR deep creative library)

FAIL if:
- Frequency above threshold
- Creative library is stale (no new creative in 30+ days)
- Single creative carries >70% of campaign spend

Why: scaling fatigued creative burns the audience faster and raises CPMs.

---

## How to Apply

1. Pull 14-30 days of data per campaign
2. Score each check as PASS/FAIL
3. If 5/5 PASS → scale-ready
4. If <5 PASS → NOT ready, identify the blocking check, fix that first
5. Re-check weekly

---

## Common Failure Patterns

| Pattern | Likely Cause | Fix |
|---------|--------------|-----|
| Fails Check 1 only (high CPA) | Creative or landing page misalignment | `/ab-test` new creative, audit LP |
| Fails Check 2 only (low volume) | Budget too low for learning | Slightly increase budget (not scale, just learning-phase unlock) |
| Fails Check 3 only (CTR decline) | Creative fatigue | Fresh creative rotation |
| Fails Check 4 only (ROAS low) | Wrong audience or broken offer | Audience diagnosis, offer review |
| Fails Check 5 only (fatigue) | Creative library thin | Bulk creative production |
| Fails 3+ checks | Campaign is fundamentally broken | Pause and rebuild, don't try to scale |

---

## "Almost Ready" Trap

If a campaign passes 4/5, resist the urge to scale "at reduced increment". The failing check will become the ceiling on any scale gains.

Example: CPA is under target (pass), ROAS is above target (pass), CTR is stable (pass), volume is sufficient (pass), but frequency is 3.2 (fail). Scaling this campaign will push frequency higher, which will crush CTR within 7-14 days. The 20% gain in week 1 becomes a 40% loss in week 3.

Fix the failing check first. Then scale.

---

## When to Override

Override only if:
- You have a time-limited opportunity (product launch, seasonal event)
- AND you're willing to eat the consequences (likely short-term win, medium-term degradation)
- AND you've documented the override decision so the team can reverse it

Never override for "gut feel" or "client pressure" alone.
