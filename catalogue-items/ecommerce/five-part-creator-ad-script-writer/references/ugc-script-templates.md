# 10 UGC Script Templates

Skeletons you can fill in for fast production. Each is a proven structure.

---

## Template 1: Morning Routine

**Length:** 20-30s

```
Hook (0-3s): "My morning doesn't start until I've done this."
Setup (3-8s): "Every morning, 6:30am, before anything else."
Demo (8-20s): [Show the routine moment with product]
Turn (20-25s): "It's been [X weeks/months]. Haven't skipped once."
CTA (25-30s): "Link's below if you want to try."
```

---

## Template 2: Test Drive

**Length:** 30-45s


---

## Fill-In Rules

1. Replace every bracket with something specific. "3 weeks" not "a while ago."
2. Keep one honest moment per script. Doubt, surprise, reversal.
3. CTAs stay soft. UGC audience rejects hard sells.
4. No em dashes. No "game-changer." No "revolutionary."
5. Read it out loud. If it sounds like a commercial, rewrite.
