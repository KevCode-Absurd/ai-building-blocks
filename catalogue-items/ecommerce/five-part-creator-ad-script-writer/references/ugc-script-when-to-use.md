# When to use `/ugc-script`

**What it does:** Writes a complete UGC script (hook + setup + demonstration + turn + CTA) with delivery notes and shot list. 15-60 seconds of conversational video that doesn't sound like an ad.

**Runtime:** 60 seconds.

## Run this when

1. **Shipping a UGC brief to a creator.** They need the full script, not just a concept.
2. **Andromeda shows UGC gap.** You're producing your first UGC ads and need fast scripts.
3. **A creator needs "something to say."** Senior creators improvise, new creators need a script.
4. **Building a testimonial ad.** Real customer on camera, needs light script scaffolding.

## Before you run

- Product + one-sentence description
- Creator profile
- Video length target
- Angle (morning routine, test-drive, comparison, etc.)
- CTA / offer

## What you get back

- Full script with timestamps
- Hook + setup + demo + turn + CTA
- Delivery notes (tone, pace, camera)
- Shot list (4-8 shots)
- Wardrobe/setting suggestions

## Chains well with

- `/hook-generator` before, to pick a winning opener
- `/diversification` before, if UGC gap was identified
- `/creative-brief` for the full production spec around the script
- `/ab-test` after, to test script variants against same product
