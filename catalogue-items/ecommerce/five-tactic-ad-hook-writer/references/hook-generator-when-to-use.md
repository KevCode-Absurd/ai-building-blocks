# When to use `/hook-generator`

**What it does:** Generates 10-15 scroll-stopping hooks (3-7 words each) using 5 proven tactics. Ranks by stop-power. Recommends visual pairing for each top hook.

**Runtime:** 30-60 seconds.

## Run this when

1. **A Hidden Gem was diagnosed by `/hook-hold`.** Body works, opening fails. You need 3-5 hooks to test over the same body.
2. **A new product launch.** No existing hooks to iterate from.
3. **A hook has fatigued.** Need fresh first-2-seconds while keeping the rest of the ad.
4. **Building a UGC brief.** The creator needs the opening line to deliver.

## Before you run

- Product name + what it does
- Core pain or promise
- Target audience (specific, not demographic)
- Tone preference
- Format (video opener, static headline, UGC voiceover)
- Awareness stage

## What you get back

- 10-15 hooks, each tagged by tactic
- Format fit (video/static/UGC)
- Stop-power estimate
- One-line reasoning per hook
- Visual pairing recommendation for top 3-5

## Chains well with

- `/hook-hold` before, to identify Hidden Gems that need new hooks
- `/ugc-script` after, to build out the full UGC script around a winning hook
- `/visual-hooks` after, if the hook needs a specific visual treatment
- `/voiceover-hooks` after, for video-specific spoken hooks
- `/ab-test` after, to test 3 hooks against the same body
