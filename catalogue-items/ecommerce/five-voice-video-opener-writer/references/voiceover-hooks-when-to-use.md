# When to use `/voiceover-hooks`

**What it does:** Generates 18 voiceover openers across 5 voice styles (UGC, founder, educator, narrator, casual friend) for video ads. 2-3 second spoken hooks with delivery notes.

**Runtime:** 45 seconds.

## Run this when

1. **Producing a video ad and need the opening line.** Specific, castable, deliverable.
2. **A voiceover ad is under-performing hook rate.** 18 new openers to test.
3. **Briefing a voice actor.** Clear script + tone + pace + emphasis.
4. **Matching voice to audience.** Founder POV for brand-led, UGC for peer-led, educator for category-led.

## Before you run

- Product + one-sentence description
- Target audience
- Preferred voice style or "let me pick"
- Tone preference

## What you get back

- 18 voiceover hooks (3-4 per voice style)
- Duration estimates
- Delivery notes (pace, emphasis, pause cues)
- Background sound suggestions
- Top-3 recommendation for production

## Chains well with

- `/hook-generator` in parallel for non-voiceover hook variants
- `/ugc-script` to build out full script around chosen hook
- `/visual-hooks` to match first frame to first voice
- `/ab-test` to test voice-style-vs-voice-style
