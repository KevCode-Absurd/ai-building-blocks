# Preflight Checklist

Run this on every brief before handing it to production. Most problems are catchable before a designer opens Figma.

---

## Hook Check

- [ ] Hook is 4-6 words
- [ ] Hook is specific (names a moment, number, or concrete thing)
- [ ] Hook does not start with a generic adjective ("Amazing", "Incredible")
- [ ] Hook does not use banned phrases (see list below)
- [ ] Hook can stand alone without the image (test: would it work as a text message?)

---

## Body Check

- [ ] Copy framework is named (PAS, AIDA, Before/After, Testimonial, Comparison)
- [ ] 3-4 key points listed, not paragraphs
- [ ] Tone is specified (conversational, authoritative, urgent, aspirational)
- [ ] Body fits the format (15s video cannot carry 6 points)

---

## Visual Direction Check

- [ ] Format specs are exact (1:1, 9:16, 4:5, etc.)
- [ ] Duration/slide count specified if applicable
- [ ] Style is one of: photorealistic, lifestyle, studio, UGC-style, editorial
- [ ] Color direction references brand palette specifically
- [ ] Product visibility is declared (hero, secondary, implied)

---

## CTA Check

- [ ] CTA text is 2-4 words
- [ ] CTA is action-oriented ("Shop", "Try", "See", "Compare")
- [ ] CTA placement is specified (end card, overlay, in-copy)

---

## Batch Diversity Check

- [ ] At least 3 different awareness stages represented
- [ ] At least 3 different formats
- [ ] At least 3 different messaging angles
- [ ] No more than 4 concepts from the same angle

---

## Banned Phrases

Any brief containing these fails preflight:

- game-changer
- revolutionary
- leverage
- unlock
- skyrocket
- next-level
- elevated
- seamlessly
- world-class
- cutting-edge
- best-in-class
- disrupt
- synergy

Fix: replace with a specific number or concrete noun.

---

## Common Failure Patterns

| Failure | Root cause | Fix |
|---------|------------|-----|
| Hook too long | Strategist wrote a sentence | Cut to 4-6 words |
| Body unsupportable in format | Format mismatch | Reformat concept or cut body points |
| Style vague ("modern", "clean") | Lazy art direction | Name a reference brand or archetype |
| Product visibility unspecified | Brief rushed | Hero/secondary/implied |
| All concepts same angle | Over-index on current winner | Enforce 3-angle minimum |
| All concepts same stage | Lazy persona mapping | Check matrix, fill empty cells |

---

## Verdict Output

Per brief:
- **PASS** — ready to produce
- **WARN** — ship anyway but note issue (e.g., hook 7 words instead of 6)
- **FAIL** — rewrite before production

Per batch:
- **PASS** — diversity requirements met, ship the top 3-5
- **WARN** — mostly good, one diversity gap
- **FAIL** — rework batch before production handoff

No em dashes anywhere in the brief.
