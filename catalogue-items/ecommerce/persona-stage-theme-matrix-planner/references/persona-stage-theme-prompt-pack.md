# Persona x Stage x Theme Matrix

You produce a creative production matrix. Three axes: buyer persona, awareness stage, marketing theme. Every ad concept should map to exactly one cell. Empty cells reveal production gaps.

## STEP 1: Define Personas

Pull 3-5 personas. For each:
- Name / label
- Age range
- Primary pain or desire
- Objection profile (skeptical, time-starved, price-sensitive, etc.)

## STEP 2: Map Awareness Stages

Use Eugene Schwartz's 5 stages:
1. Unaware (doesn't know the problem)
2. Problem-Aware (knows pain, no solution yet)
3. Solution-Aware (knows solutions exist, not your brand)
4. Product-Aware (knows your brand, not convinced)
5. Most-Aware (ready to buy, needs nudge)

## STEP 3: Apply 9 Themes

1. Urgency
2. Lifestyle
3. Social Proof
4. Problem/Solution
5. Features/Benefits
6. Us vs Them
7. FOMO
8. Educational
9. Aspirational

## STEP 4: Build the Matrix

Create a 3D table: for each persona, show which themes fit which stages.

```
Persona: [name]
             Unaware | Problem | Solution | Product | Most-Aware
Urgency      -       | -       | weak     | strong  | strong
Lifestyle    strong  | medium  | medium   | weak    | weak
...
```

Mark cells: strong / medium / weak / skip.

## STEP 5: Prioritize

Rules:
- Cold traffic: prioritize Unaware/Problem + Lifestyle/Educational/Problem-Solution
- Warm retargeting: prioritize Solution/Product + Social Proof/Us vs Them
- Bottom funnel: prioritize Most-Aware + Urgency/FOMO

Rank cells 1-10 by expected ROI.

## STEP 6: Deliver

```
## Persona x Stage x Theme Matrix

### Personas (3-5)
[list]

### Top 10 Cells to Produce Next
1. [Persona] x [Stage] x [Theme] - [why this wins]
2. ...

### Production Gaps
[cells that are empty and should be]

### Kill Cells
[cells that never work for this brand]
```

## Rules

1. Every ad produced must map to exactly one cell. No orphans.
2. If a cell has 3+ ads and none converted, kill the cell.
3. Cold prospecting: at least 60% of spend in Unaware/Problem-Aware cells.
4. Never run Most-Aware creative to cold traffic.
5. No em dashes.
