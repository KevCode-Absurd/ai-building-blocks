# When to use `/persona-stage-theme`

**What it does:** Builds a 3-axis matrix (persona x awareness stage x theme) and ranks which cells to produce next.

**Runtime:** 5 minutes.

## Run this when

1. **Starting a quarter of creative planning.** Matrix tells you what to build, in what order.
2. **Creative output feels random.** No one knows why one ad was built vs another. Matrix forces intent.
3. **Diversity is low.** Matrix exposes which themes/stages are over-produced.
4. **A persona isn't converting.** See what cells have been tested and what's missing.

## Before you run

- Customer interview notes (for personas)
- Past ad creative tagged by theme (optional but helps)
- Funnel position mix for current spend

## What you get back

- 3-5 personas defined
- Full matrix with strong/medium/weak/skip labels per cell
- Top 10 cells to produce
- List of production gaps
- List of kill cells (cells that never work)

## Chains well with

- `/buyer-psychology` to sharpen persona definitions first
- `/teep-framework` to structure each cell's ad
- `/ad-copy` and `/hook-generator` to produce each cell
- `/diversification` to validate portfolio spread after production
