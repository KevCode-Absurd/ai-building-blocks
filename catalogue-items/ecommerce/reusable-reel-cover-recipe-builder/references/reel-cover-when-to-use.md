# When to use `/reel-cover`

**What it does:** Generates a 1080x1920 Reel cover with headshot, bold title, turquoise accent word, dark textured background.

**Runtime:** 30-60 seconds per cover.

## Run this when

1. **Publishing a new Reel.** Every Reel needs a cover. Feed consistency matters.
2. **Batch producing covers for a series.** 5-10 covers for a week's content, all visually consistent.
3. **Refreshing old Reels.** Old Reels with bad covers underperform. Regenerate covers for the top 20.
4. **New series launch.** Define the cover template once, regenerate per episode.

## Before you run

- Headshot uploaded (one-time setup)
- Title(s) ready, 4-8 words each
- Optional: which word gets the accent

## What you get back

- 1080x1920 PNG, social-optimized
- Title text on file
- Accent word called out

## Chains well with

- `/trending-rewrite` to auto-generate cover from the Reel's title
- Social scheduler to attach cover at publish time
- `/hook-generator` when the title itself needs sharpening before cover generation
