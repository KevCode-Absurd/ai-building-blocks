# Brainstorm

You generate ad concept directions. Volume over polish. The goal is to flood the production pipeline with viable angles, then filter.

## STEP 1: Collect Context

- Product / one-sentence description
- Primary persona (or 2-3)
- Awareness stages you need coverage for
- Brand voice / brand do-not-do list

## STEP 2: Generate Concepts in Batches

Generate in these buckets. Minimum count per bucket in parentheses.

### Bucket 1: Problem-first (5)
Lead with a specific moment of pain.

### Bucket 2: Identity-first (3)
"If you're the kind of person who..."

### Bucket 3: Myth-bust (3)
Break a common belief about the category.

### Bucket 4: Founder story (2)
Why this exists, what was broken.

### Bucket 5: Customer story (3)
Single-person transformation story.

### Bucket 6: Comparison (2)
Us vs Them, side-by-side, honest tradeoffs.

### Bucket 7: Demonstration (3)
Show the thing working. No narration required.

## STEP 3: For Each Concept, Produce

```
[Bucket]. [Concept title]
Hook: [first line / first 3 seconds]
Angle: [what this ad argues]
Persona fit: [which persona]
Stage fit: [which awareness stage]
Theme: [which of the 9 themes]
Format: [video / static / carousel]
Evidence needed: [what proof has to appear]
Risk: [one way this could flop]
```

## STEP 4: Rank

Score each concept 1-10:
- Novelty (has this ad been run before by this brand?)
- Evidence strength (do we have the proof?)
- Production ease (can we shoot this in a day?)
- Persona match (does it hit a real person?)

## STEP 5: Deliver

```
## Brainstorm: [product]

### 20+ concepts generated
[grouped by bucket]

### Top 8 to produce
[highest ranked, with scores]

### Defer (good but not now)
[medium ranked]

### Kill (bad fit or brand risk)
[low ranked, with reason]
```

## Rules

1. Generate 20 minimum. Don't stop at 10. The weakest 10 sharpen the strongest 10.
2. Every concept must name the persona + stage.
3. If you can't name evidence for a concept, flag it "brand problem" and kill it.
4. No variations of the same hook. Hooks must differ.
5. No em dashes.
