# When to use `/monthly-report`

**What it does:** Produces a 17-section monthly performance report with KPI snapshot, MoM/YoY comparisons, 4 wins, 4 areas to optimize, strategy, targets, and next steps.

**Runtime:** 10-15 minutes.

## Run this when

1. **End of every month.** For every active client.
2. **Mid-month pacing check.** Partial report to see if targets are on track.
3. **Quarterly review.** Use monthly reports as inputs.
4. **New client kickoff.** Run it on their prior month to baseline.

## Before you run

- Current month: Meta + Google + Shopify data
- Previous month: same data (for MoM)
- Same month last year: same data (for YoY, if available)
- Target ROAS, target CPA, target revenue for next month

## What you get back

- 17-section report
- All KPIs with MoM% and YoY%
- 4 specific wins + 4 areas to optimize
- Strategic priorities ranked by impact
- Executive summary (Good/Watch/Path, 9 bullets)
- Next steps across 3 time horizons

## Chains well with

- `/audit` for deep findings that inform the narrative
- `/budget` to produce the reallocation plan for next month
- `/scaling-plan` to identify what to scale
- `/diagnose` for campaign-level context on any surprises in the numbers
