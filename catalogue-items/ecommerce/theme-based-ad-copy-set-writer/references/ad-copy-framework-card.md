# Ad Copy Framework Card

Quick reference for a starter set of theme-specific copy frameworks. Start with these four. Add more (Urgency, Educational, Us vs Them, etc.) as your brand voice demands.

---

## Lifestyle
- **Use when:** Identity purchase, aspirational brand, premium positioning
- **Framework:** Identity + Aspiration
- **Headline:** "For the [Tribe]", "Live [Desired State]", "Made for [Moment]"
- **Body:** Minimal or none, image carries weight
- **CTA:** Discover / Explore / Join the [Tribe]

## Problem-Solution
- **Use when:** Customer has a known pain, functional product
- **Framework:** Problem-Agitate-Solve, or Before/After
- **Headline:** "Tired of [problem]?", "The [old way] vs The [brand] way"
- **Body:** Name the pain, sharpen it, present the fix
- **CTA:** Fix It Now / Switch Today / See the Difference

## Social Proof
- **Use when:** Credibility is the objection, new category entrant, review-heavy
- **Framework:** Testimonial + Result + Validation
- **Headline:** Direct customer quote, "[X] people switched this month"
- **Body:** Quote with attribution, star rating, specific result
- **CTA:** See Why / Join [X]+ Customers / Try Risk-Free

## Founder-Story
- **Use when:** Brand-building months, relaunches, category entries
- **Framework:** Origin + Decision + Result
- **Headline:** "I built this because...", a specific origin cue
- **Body:** The moment you realized the gap, the decision, what came of it
- **CTA:** Learn the Story / Try It

---

## Choosing the Right Framework

### By Awareness Stage

| Stage | Best Frameworks |
|-------|-----------------|
| Unaware | Lifestyle, Founder-Story |
| Problem-aware | Problem-Solution, Founder-Story |
| Solution-aware | Social Proof, Problem-Solution |
| Product-aware | Social Proof |
| Most-aware | Social Proof, direct offer |

### By Product Category

| Category | Default Frameworks |
|----------|-------------------|
| Supplements / Health | Problem-Solution, Social Proof |
| Apparel | Lifestyle |
| Beauty | Social Proof, Lifestyle |
| Tech / SaaS | Problem-Solution |
| Food / Beverage | Lifestyle, Social Proof |
| Home | Lifestyle |

## Banned Phrases (never use)

- game-changer
- revolutionary
- leverage
- unlock
- skyrocket
- delve
- at the end of the day
- synergy
- paradigm shift
- best-in-class

And never use em dashes. Use commas or periods.
