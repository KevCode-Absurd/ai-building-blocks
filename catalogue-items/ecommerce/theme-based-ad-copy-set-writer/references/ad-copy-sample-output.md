## A/B Test Recommendation

**Test Set 1 (PAS) vs Set 3 (Comparison) first.**

Why:
- Same audience (solution-aware), different angle (pain-driven vs mechanism-driven)
- Isolates the "emotion vs logic" variable
- Both use specific numbers (20% vs 97%), so quality of claim is equal

Setup:
- 2 ad variants, same visual, same audience, same budget
- Minimum 1,500 impressions per variant before declaring a winner
- Measure CTR (top-funnel signal) and CVR (bottom-funnel signal)
- Run 5-7 days to avoid weekday/weekend bias

If Set 1 wins: audience responds to pain framing. Double down on problem/solution in future creative.
If Set 3 wins: audience responds to credibility framing. Lead with mechanism in future.
