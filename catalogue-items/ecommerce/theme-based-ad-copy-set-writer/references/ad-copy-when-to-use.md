# When to use `/ad-copy`

**What it does:** Generates 3-5 full ad copy sets (headline, subheadline, body, CTA) each using a different proven framework. Validates against quality gates. Recommends which 2 to test first.

**Runtime:** 60-90 seconds.

## Run this when

1. **Launching a new creative concept.** You have the visual, you need the copy to pair with it.
2. **A winning ad has decayed.** Same visual, new copy angles to revive it.
3. **You need A/B test variants.** This skill is built around the A/B structure.
4. **Onboarding a new client.** Quickly produce multiple angles to find what lands.

## Before you run

- Product name and what it does
- Marketing theme (see theme list in prompt pack)
- Awareness stage of target audience
- Key benefit/USP
- Target persona (recommended)
- Offer details if applicable

## What you get back

- 3-5 copy sets, each with different framework
- Character counts for compliance
- Quality gate pass/fail
- Top-2 test recommendation with isolated variable

## Chains well with

- `/brand-dna` before, to establish voice and tone constraints
- `/persona-stage-theme` before, to pick the right theme and stage
- `/5-headline-angles` if you need more headline variety
- `/generate-ad` after, to produce the visual that pairs with the copy
- `/ab-test` after, to design the actual test
