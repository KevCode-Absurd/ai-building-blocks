# When to use `/teep-framework`

**What it does:** Structures any ad using TEEP (Trigger, Emotion, Evidence, Payoff). Produces a brief with second-by-second timeline (video) or position-by-position layout (static) ensuring all four elements are present.

**Runtime:** 2 minutes.

## Run this when

1. **Building a new ad from scratch.** Start with TEEP structure, fill in creative.
2. **A video ad is converting poorly.** Usually missing one TEEP element.
3. **Briefing a creative team.** TEEP makes the brief specific and testable.
4. **Auditing a winning ad to replicate.** Identify what TEEP elements made it work.

## Before you run

- Product + one-sentence description
- Audience
- Funnel position
- Existing creative for comparison (optional)

## What you get back

- Per-element worksheet (Trigger, Emotion, Evidence, Payoff)
- Ad structure timeline (video) or layout (static)
- Production notes
- Element coverage score

## Chains well with

- `/buyer-psychology` for the deeper audience psychology map
- `/creative-brief` to convert the TEEP brief into a full production spec
- `/ad-copy` for copy informed by the TEEP structure
- `/hook-generator` + `/visual-hooks` for the Trigger element specifics
