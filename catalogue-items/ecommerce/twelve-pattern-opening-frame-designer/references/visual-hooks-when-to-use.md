# When to use `/visual-hooks`

**What it does:** Designs the first visual frame of an ad using 12 proven patterns. Covers text-over-color, split screens, close-ups, lifestyle moments, comparison charts, and more.

**Runtime:** 60 seconds.

## Run this when

1. **A Hidden Gem needs new openings.** Hold rate is good, hook rate is weak. Visual hook is the fix.
2. **Briefing a designer.** Instead of "make it pop," hand them a specific pattern.
3. **Launching a new ad concept.** Visual hook locked before production starts.
4. **Running visual A/B tests.** 3 visual hooks against same body.

## Before you run

- Product + packaging reference
- Core claim / angle
- Theme
- Target audience
- Platform (feed, Reels, Story, Display)
- Brand visual guidelines

## What you get back

- 3-5 visual hooks with full design spec
- Composition, background, text overlay, lighting, palette
- Production notes (photography type, assets needed, timeline)
- A/B test variant suggestions

## Chains well with

- `/hook-generator` in parallel, to match verbal hook with visual hook
- `/layout-templates` to apply visual hook inside a proven layout
- `/generate-ad` to produce the actual AI-generated image
- `/ad-design-levers` to refine the visual details (color, hierarchy, motion)
