## Static Ad Brief: Problem Moment (Archetype 1)

### Why This Archetype

- Funnel = cold prospecting → cuts to 4 top-funnel archetypes
- Evidence available = real customer testimonials, no lab display
- Strongest single claim = "3pm crash is real and we fix it"
- Problem Moment wins because it names a specific time-bound pain the audience has felt this week.

### Visual

Close-up photograph of a woman in her late 30s at an office desk, slight yawn, clock on wall visible reading 3:00. Natural afternoon light. Slightly desaturated. No product visible in frame (product shows up in the caption/secondary asset).

### Copy

- Headline (on image, max 5 words): **"3pm. Again."**
- Sub: none (negative space is the message)
- CTA (bottom right): **"See what worked"**

### Layout

```
+------------------------------------------+
|                                          |
|                                          |
|       CLOCK SHOWING 3PM (15%)            |
|                                          |
|       CUSTOMER MID-YAWN (55%)            |
|                                          |
|                                          |
|                                          |
+------------------------------------------+
|   "3pm. Again." (20%)                    |
+------------------------------------------+
|   See what worked (5% button)            |
+------------------------------------------+
```

### Evidence Required

- Real photo of customer (or documentary-style model shot) at 3pm, at a desk
- Clock visible or implied
- No product shown in image (product is the reveal on landing page)

### Production Notes

- Shoot spec: office location, natural afternoon light, 50mm, slight desaturation in grade
- Talent: age 35-45, natural hair, no model-type polish
- Equipment: phone quality acceptable, DSLR preferred
- Estimated cost: $300-500 if UGC, $1,500-2,500 for staged shoot
- Alt: Generate via `/generate-ad` with documentary-editorial style → ~$0.04

### Opposite Archetype (for A/B test)

**Solution Moment**: Same woman at 3pm, no yawn, focused, product visible. Caption: "3pm. Now." Test both at equal spend for 3 days. Winner reveals whether this audience responds to pain-first or payoff-first framing.

Run this single static in cold prospecting ad set for 5 days at $75/day. Success metric: CTR above 1.5%, hook rate above 20% on the landing page. If both pass, pair with Multi-Proof Grid archetype in retargeting to close.
