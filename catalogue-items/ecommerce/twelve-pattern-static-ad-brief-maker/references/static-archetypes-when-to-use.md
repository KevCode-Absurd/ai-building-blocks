# When to use `/static-archetypes`

**What it does:** Produces a static ad fast by pattern-matching to one of 12 proven ecommerce archetypes. Each archetype bundles theme + layout + copy into a single spec.

**Runtime:** 2-3 minutes per archetype.

## Run this when

1. **You need a static ad by end of day.** Archetype is faster than building from scratch.
2. **Team has no designer.** Archetype spec is tight enough to hand to a junior.
3. **Testing placement fit.** Static archetypes are predictable; good A/B baselines.
4. **Filling gaps in a campaign.** Identify which archetypes are missing vs saturated.

## Before you run

- Product
- Audience (1 primary)
- Funnel position
- Evidence inventory (reviews, labs, testimonials, demos)

## What you get back

- 1 selected archetype with reasoning
- Visual description
- Copy (all text caps respected)
- ASCII layout
- Evidence list
- Production notes
- Opposite archetype for A/B testing

## Chains well with

- `/persona-stage-theme` to know which funnel cells need filling
- `/brand-dna` for brand colors and visual vocabulary
- `/generate-ad` to produce the static image
- `/ad-copy` for longer caption if needed
