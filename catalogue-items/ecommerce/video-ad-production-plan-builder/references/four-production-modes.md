# Four production modes

## Podcast conversation
Plan a two-person exchange with clearly different roles and voices, a stable table, microphones and eyelines. Make listener reaction shots meaningful; do not generate both speakers talking over one line. Track product placement and hand state through alternating coverage. Do not imply professional expertise or a genuine customer story without evidence. The handoff includes cast references, shot prompts, dialogue source, voice plan and edit notes.

## 2D illustrated animation
Lock drawing medium, line thickness, palette and proportions. Use readable silhouettes, limited poses, simple hand/product contact and clear visual metaphors. A claim remains sourced even when shown by a drawing. Keep character/location sheets reusable and explain which static frame precedes each motion shot. Avoid photoreal texture terms that conflict with illustration.

## Clay stop-motion
Lock scale, handcrafted surface, joints/limb simplicity, set lighting and camera. Use discrete pose-to-pose actions, material contact and readable product handling. A clay stage can still hold an accurately represented product. Keep small parts from multiplying or changing positions across shots. Separate decorative surreal scenery from factual demonstrations.

## Short film
Start from the audience’s understanding before/after each shot. Build character passports, location/layout references, object-state continuity and a beat table. Plan establishing shot, action coverage, reaction, insert and payoff as needed, not a fixed recipe. Prompt each shot using look, context, reference roles/exclusions, camera, timed action, visible motion, sound and targeted avoidances. Keep all necessary state inside an independent generation. A location kit belongs to this project, not hidden memory.

## Master plan output
Approved facts → story arc → cast/location/product kit → timed shot cards → image prompts → clip prompts → dialogue/audio handoff → edit order → checks and missing work. Tool execution remains separate from the planning skill. Use one relevant mode rather than including all four.
