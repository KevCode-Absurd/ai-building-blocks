# Advertorial static ad: online store add-on

## Extra inputs
- Product page URL and the product's three strongest facts (material, process, test, count).
- Review count and average, if shown on the page.

## What changes
- **Comparison pairs that work for stores:** coated against bare, clear against amber glass, monthly pack against quarterly, refillable against single-use. Use the kind, never a rival brand.
- **Image:** the real product photo, small, in a corner or beside the list. Do not restyle the pack or reset its label.
- **List headlines:** "3 reasons ..." works best when each reason maps to a product page section (material, making, guarantee), so the page can repeat it.
- **Proof:** review counts and verified-buyer quotes only as the reviews platform shows them. No "bought today" counters.
- **Page check:** the product page must show the same claim above the fold. If the first screen is a generic collection grid, send the ad to a landing page instead.
