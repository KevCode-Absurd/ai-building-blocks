# Study board: for online stores

## How to collect in the library
- Set the country you sell in, the category "All ads", and search by advertiser name. Filter to active ads and to images if you only want image ads.
- For each ad you keep, copy the library ID and the "started running" date, and take a screenshot of the creative.
- Open each advertiser's own page in the library as well as keyword results, so you see their quiet long-runners next to the loud new ones.

## What changes for a store
- **The offer** covers percent off, money off, buy-one-get-one, a free gift, free shipping over a threshold and subscribe-and-save. Note the offer's shape on the card, never its wording.
- **The occasion** needs a dated reason: a holiday gift date, a new flavour or colour, a restock. An ad that only mentions a season with no date stays under its main type.
- **Old way, new way** for a store is the usual routine against the product, shown with objects. If a card names or shows a rival brand, file it but note it, since you won't do that in your own ads.
- **Where the ad leads.** Note whether the link goes to a product page, a collection or an article-style page. Ad type and page type often travel together.
- **Rerunning the board.** List the library IDs already on it first and add only new ones. Update each card's tier, because a new ad may now be kept.
