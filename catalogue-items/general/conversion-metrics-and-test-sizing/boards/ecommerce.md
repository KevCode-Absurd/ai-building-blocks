# Conversion metrics: online store add-on

## Extra inputs
- Store report exports for the same window: sessions, conversion rate, AOV, orders, revenue, mobile against desktop, top landing pages, new against returning, return or refund rate.

## Store numbers that mislead (Shopify named; the same traps exist elsewhere)
- Total sales include tax. Use net sales plus shipping collected.
- The store's AOV leaves out shipping you collected, which is real revenue. Add it back before computing RPV.
- Store sessions include bot traffic. Prefer the analytics tool's sessions for any per-session figure.
- Conversion rate on its own can hide a mix shift (see step 3).

## Thresholds and wording for stores
- **Products bought once** have few returning buyers, so judge them on first orders, return rate and referrals. **Products bought again** are judged on first order and then reorder rate and subscription churn.
- **Cart abandonment** (Baymard Institute research, quoted from a course; the study updates yearly, so read the current one before quoting a number): about 70% of carts are abandoned. Reasons given in that research: extra costs too high, slow delivery, not trusting the site with card details, forced account creation, long checkout, unclear returns, total cost not shown up front. Three of these (cost, delivery, returns) are answered by facts the page can state.
- **A real testing programme** needs the volume above. Many stores below it should ship obvious fixes and track RPV monthly.
- **Do not over-optimise:** dark patterns and claims the product cannot keep raise conversion now and cost returns, chargebacks and repeat orders later. Watch return rate and one-year value by angle.
