# ElevenLabs Script Writer — Reference Examples

## Cinematic narration

### Input
Write a 20-second narration about a man realizing his memories are fake. Start calm and become disturbing.

### Output

```text
[calm]
I used to remember this place perfectly.

Every room... every sound... every face.

[slightly uneasy]
But yesterday, I found a photograph.

And I wasn't in it.

[pause]

[whispers]
None of us were.
```

## UGC ad

### Input
Write a natural 15-second UGC voice-over for a skincare product. Friendly, believable, not too polished.

### Output

```text
[conversational]
Okay, I genuinely didn't expect to notice a difference this fast... but look at my skin.

[surprised]
It's way calmer, way smoother, and I haven't changed anything else in my routine.

Honestly? I'm keeping this one.
```

## Multi-speaker scene

### Input
Two characters are trapped in an elevator. One is terrified, the other is strangely calm.

### Output

```text
Speaker 1: [panicked] Why did it stop? Why did it STOP?

Speaker 2: [calm] Breathe. It's just an elevator.

Speaker 1: [nervous] You don't understand... this happened before.

Speaker 2: [quietly amused] I know.
```

## Emotional progression

### Input
Make the speaker begin confident and slowly lose control.

### Output

```text
[confident]
This was supposed to be simple.

[slightly tense]
One door. One hallway. One answer.

[nervous]
But the hallway keeps getting longer...

[panicked]
No. No, no, no—this isn't possible.
```
