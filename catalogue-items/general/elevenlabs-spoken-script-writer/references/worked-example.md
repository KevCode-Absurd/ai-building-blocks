# Fictional offline practice case

## Input

Write a 20-second fictional museum-closing announcement: warm, then clear, no audio tool; two speakers, no unsupported tags.

## Example result

SCRIPT
Host: Thanks for exploring with us. The museum closes in ten minutes.
Guide: Please make your way to the main exit. Our team can help you find it.
Host: We hope to see you again soon.
DELIVERY NOTES
Warm opening, clear middle, unhurried finish; 33 words, about 18–23 seconds with pauses. Tag-free because voice-mode support is unknown.
NOT RUN
Audio synthesis; listening and exact-duration verification.

## Checks

- Two speakers clearly labeled
- 33-word spoken draft fits approximate duration with pauses
- No invented factual sales claims
- Synthesis is explicitly not run

No external service was called in this practice case.
