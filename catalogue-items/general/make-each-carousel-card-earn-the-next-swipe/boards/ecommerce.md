# Make each carousel card earn the next swipe: for online stores

## Extra things to give it
- Product photos by job: pack front, open or in use, a close-up. One photo of each product shown, to check against.
- Bundle and price facts, shipping and returns terms.

## What changes
- **Product cards:** check each card's product, colour and label against the product photo. Never mix variants in one carousel unless the card says so.
- **What-to-expect structure:** use weeks for something that gets used up (skincare, supplements, coffee) and years for something kept (cookware, bags). Use only points in time the brand can support.
- **Offer card:** price, bundle contents, shipping and returns in the store's own wording. A discount code only if it works today.
- **One-product-per-card catalogue carousels** are a different job. This format is one argument across the cards.
- **Reviews:** a quote card uses a verified review as the platform shows it, with no face and no invented first name.
