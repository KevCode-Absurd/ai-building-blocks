# MidJourney Image Prompter — Reference Examples

## Example 1 — Cinematic portrait

### Input
Create a realistic cinematic portrait of a woman alone inside a late-night diner. Moody, quiet, slightly uncomfortable.

### Output direction
Keep the subject visually dominant, use the diner as environmental storytelling, and vary framing, lighting, and mood while preserving the same core concept.

### Prompt 1
```Midjourney
cinematic photograph of lone woman,
seated inside empty night diner,
quiet guarded expression,
chrome counter and vinyl booths,
fluorescent practical lights overhead,
rain streaks across front windows,
three-quarter eye-level framing,
muted green and amber palette,
35mm documentary photography,
subtle film grain,
uneasy nocturnal stillness
```

### Prompt 2
```Midjourney
35mm portrait of solitary woman,
late-night diner booth by window,
face caught in side profile,
neon reflections on wet glass,
soft practical light from table,
shallow depth of field,
negative space around subject,
weathered cinematic texture,
desaturated color grade,
quiet psychological tension
```

## Example 3 — Reference-inspired iteration

### Input
Use my reference image only for the lighting and camera feeling. Replace the person with a man in a dark suit standing outside a hotel.

### Behavior
Extract the visible lighting direction, contrast, lens feel, framing, grain, and color mood from the reference. Do not copy unrelated objects or identity traits. Build four new prompts around the man's requested scene while keeping the reference-inspired visual language.

## Example 4 — Iteration

### Input
Same concept, but make it less polished and more like a real street photograph.

### Behavior
Preserve the established subject and scene. Reduce commercial polish, introduce more documentary framing, imperfect ambient light, realistic grain/noise, less controlled composition, and a more observational camera feel.
