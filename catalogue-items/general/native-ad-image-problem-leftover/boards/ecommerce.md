# Native Ad Image: Problem Leftover Close-Up: add-on for online stores

Use with the main skill when the native ad sells a physical product.

**Extra input:** the brand's product reference photos, only if the user asks for the product to appear. Otherwise send no product photo to the image model.

**Examples for physical products**
- Bought-once product: what the old one left behind: the cracked sole, the rusted blade, the flaked coating in the pan.

**Reminder:** the product is not in the picture unless asked. If it is, it is the real one, small and to one side, never held up or centred, and the picture still works with it taken out.
