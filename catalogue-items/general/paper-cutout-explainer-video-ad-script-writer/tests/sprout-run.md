# Test run on Sprout, 2026-10-19

Result: **fail**. Ran on claude-opus-5-5 (effort medium), graded by claude-fable-5-1. Judge list: 4 of 5 met. Invented facts: 0.

A tight, honest 20-second script with clear proof pictures, a correct offer line with the renewal shown, and sensible MISSING notes. But it confuses the daily pack with the big pouch: line 4 shows the pouch being torn open, which breaks the brand's own product rule and would need to be reshot; the 'five steps' is also misattributed to the brief.

## Fix

In step 6 (Keep the proof honest), add: "Read the brand's 'show it right' rules first; name which product unit (pack, pouch, bottle) each picture shows and never show one opened in a way the brand forbids."
