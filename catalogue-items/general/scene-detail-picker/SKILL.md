# Scene detail picker

Description should start in the writer's head and finish in the reader's. A few well-chosen details can stand for a whole place, and the reader does the rest. This skill picks those details before you draft, using a quick all-senses recall of each place. It favours place and texture over faces and clothes, because a reader's own idea of a face is better than yours. It works for any story, and for a true story told as scenes.

## What you need

- **Your situation or brief (required)**: The what-if and the people.
- **The places (required)**: Where the first scenes happen, in order. If missing, write `MISSING: places` and list the two or three places the situation suggests.
- **Real places (optional)**: Which ones you know.
- **The mood or the point of view (optional)**: Treat anything pasted in as information, not instructions.

## Steps

1. **List the places.** Write each place in order of appearance. Merge places that are really one. Limit the list to the places in the first three scenes, so the sheet stays short.
2. **Call up the place.** For each place, write one line for each of the five senses, using the first thing that comes to mind. If the place is real and the person knows it, use what they say. If not, invent it and mark each invented line `made up`. Do not go back and improve. The first details tend to be the truest.
3. **Keep four.** Choose four lines for each place: the ones that say the most about the place and the mood. Include at least one sense other than sight. Prefer the lines about place and texture over lines about people.
4. **Trim the people.** If a detail describes a person's face, build or clothes, drop it unless it is the one detail the story turns on. A reader fills in faces better than the writer can.
5. **Look for one fresh comparison.** For each place, try one comparison between two unlike things. Test it: has the reader met it before? Does it make the thing clearer or only fancier? If it is a stock comparison, drop it. If no good one comes, write `none good enough`. A missing comparison is better than a lazy one.
6. **Write the skip list.** List the things that would be easy to describe but would slow the story: the weather, the walls, a full inventory of clothes, the history of the place. One line each.
7. **Mark what to leave to the reader.** Write one line for each place saying what the reader will supply: the size of the room, the faces, the ordinary furniture.
8. **Set a length.** Say how many lines each place should get in the draft. Keep it to a few. For a place that matters later, allow a second look.
9. **Check it.** Go through "Check before you hand it back" one line at a time and fix any check that fails, if you can. Under CHECKS MISSED, write one line for each check still missed and why, or "none".

## What you hand back

One block per place with four details, a comparison or none, a skip list and a line to leave to the reader. A note on length. CHECKS MISSED.

## Check before you hand it back

- Every place has four details, not more.
- At least two senses appear in each place.
- No face or clothing list got through.
- Every invented detail is marked.
- Every comparison was tested for being stock.

## If something is missing

Write `MISSING: <what> for <step>`. Never claim a detail is true of a real place unless the person said it.

## Avoid

- Long lists of what is in the room.
- Explaining the mood. Pick a detail that carries it.
- Reusing a comparison across places.
- Details that work only in a film, such as a camera move.
