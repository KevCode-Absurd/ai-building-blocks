# Selling Points List Writer

A short list of supporting points where each one is a small sale: one benefit plus a reason to believe it or read on.

## Inputs
- **Feature and fact list** (required): what the thing is, has, does, with sources.
- **Buyer read** (required): stage, the live wants and doubts.
- **Slot** (required): on an image, in a list, or in long copy; how many points; length limits.
- **Competitor claims** (optional): what rivals all say, so you can avoid it.

## Steps
1. For each feature, climb the chain: what it is, how it works, what the buyer gets. Support each link separately. A material, ingredient, certificate or warranty proves only its own fact or terms. If the next link is not supported, keep the verified fact and note that evidence is needed; never complete the chain from plausibility.
2. Make each point specific: add the how or why (form, amount, moment of use, comparison). Use an exact detail only if the source holds it.
3. Mix kinds so the list does not read as one pattern: plain benefit with its number; a bare fact and what it changes; an unexpected-but-true turn; how it works in the buyer's words; an exact detail; a common mistake (fault in what they were told, never in them; use rarely); the easy way plus what makes it easy; a real customer line; proof or guarantee last.
4. Aim each point at a different live want or doubt. Two points making the same argument are one point.
5. Order: strongest first, proof closing. A ready buyer wants facts and terms. A comparing buyer wants the difference. A buyer who knows the problem wants the struggle recognised, without technical terms.
6. When every rival lists the same benefits, add what removes the first objection, or say how it works.
7. On an image: one doubt per point, a short plain sentence. Smaller idea, not a squeezed sentence.
8. Read each aloud; then skim the list quickly and rewrite or cut any point where your eye slides.

## Output
A numbered list of points, each followed in brackets by: kind, want or doubt targeted, source fact. Then a "Needs evidence" list for unsupported links.

## Checks
- Each point is a plain sentence a person would say.
- No two points make the same argument.
- Every number and claim traces to the supplied facts.
- No point is a bare feature.

## If something is missing
Write `MISSING: evidence for <link>` next to a point and keep only the verified fact. Never invent an exact number.

## Avoid
- "Easy" or "high quality" with nothing behind them.
- A list of one kind.
- Made-up exact figures (the most damaging fault here).
