# Swipe carousel: online store add-on

## Extra inputs
- Product photos by job: pack front, open or in use, detail shot. One SKU reference per product shown.
- Bundle and price facts, shipping and returns terms.

## What changes
- **Product cards:** check each card's product, colour and label against the SKU reference. Never mix variants in one carousel unless the card says so.
- **What-to-expect structure:** use weeks for something used up (skincare, supplements, coffee), years for something kept (cookware, bags). Only points in time the brand can support.
- **Offer card:** price, bundle contents, shipping and returns in the store's wording; a code only if live today.
- **One-product-per-card catalogue carousels** are a different job. This format is one argument across cards.
- **Reviews:** a quote card uses a verified review as the platform shows it, with no face and no invented first name.
