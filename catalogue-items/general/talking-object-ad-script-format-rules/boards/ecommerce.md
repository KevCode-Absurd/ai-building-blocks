# Talking Object Ad: online store add-on

## Extra inputs
- Review excerpts that name objects ("graveyard of tubs under my sink", "my wobbly suitcase") with source.
- Product data: what the product replaces, true size next to the object, pack and label.
- Current offer with end date (shown as on-screen text, never spoken by the object).

## Where it fits
- Replacement products: the old item, kept and failing, is the best narrator (the scratched pan, the leaking bottle, the broken zip bag).
- Home and kitchen problems where a witness object sits in the room (hook, lamp, spoon, shelf).

## Store-specific rules
- Pick an object shopper reviews already mention; a bought-and-abandoned product category is the strongest source.
- Never use a competitor's pack, shape or colour as the failing object. Use the generic type.
- Size matters on a shelf shot: the product stands beside the object at true scale, label readable.
- The offer, price and shipping terms stay in on-screen text on the last shot, checked against the live offer.
