# Delegation decision reference

1. Determine whether the work is client-specific and preserve its scope.
2. Route by domain: Meta, Google, creative review, copy, reporting, communication or onboarding. A specialist can request a supporting specialist only if the registry grants that authority.
3. Check the registry's delegation allowlist. No agent receives authority merely because another agent names it.
4. Check the parent chain against the configured maximum depth. Return an excessive chain for review or split it into a flatter plan.
5. Record required sibling results as blocked dependencies. Do not wake blocked work.
6. Apply the exact risk/approval policy for spend, live campaign changes, external messages and changes to approved creative.
7. Create a child issue, link dependencies, wake only eligible work, and append an audit event.

A parent completes only after required child outputs satisfy its acceptance rules; a child status alone does not prove quality.
