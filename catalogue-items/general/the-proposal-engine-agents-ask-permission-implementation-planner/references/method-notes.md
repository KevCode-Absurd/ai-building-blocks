

Agents detect problems, build strategies, estimate impact, and propose actions via Slack with Approve/Reject/Elaborate buttons. On approval, delegation plans become issue trees.Proposal Approval PlaybookWhen to auto-approve. When to require human review. When to require multi-human review.Decisions are based on three dimensions: dollar impact, reversibility, and blast radius.1. The Three DimensionsDollar ImpactMoney the action touches. Direct (budget change) or indirect (opportunity cost of a pause).- Trivial — under $50/day - Moderate — $50–500/day - Material — $500–5,000/day - Major — over $5,000/dayReversibilityHow hard it is to undo the action:- Instant — one API call to revert (pause, budget change) - Hours — requires manual work (recreate from config) - Days — requires rebuild (replace deleted assets) - Permanent — cannot be undone (emails sent, client-facing posts)Blast RadiusWho experiences the impact:- Internal — only your team sees it - Client-visible — visible in client dashboards - Customer-visible — affects end customers (ads, emails) - Multi-tenant — impacts multiple clients2. Decision Matrix (Approval Rules)Auto-approve only exists in the safest case. Everything else escalates.- Trivial + Instant + Internal → Auto-approve - Trivial + Instant + Client-visible → Human review (any) - Any + Hours + Internal → Human review (any) - Moderate + Instant + Client-visible → Human review (account owner) - Moderate + Hours + Client-visible → Human review (account owner) - Moderate + Days + Any → Two humans (account owner + lead) - Material + Any + Any → Two humans + written justification - Any + Permanent + Customer-visible → Two humans + written justification - Major + Any + Any → Two humans + Chris - Any + Permanent + Multi-tenant → Blocked (not a proposal, must escalate)3. Auto-Approve Allow-List (Default Deny)Only these actions can be auto-approved:- Data refresh proposals (read-only, no mutation) - Draft-only proposals (nothing is published or executed) - Reassigning internal issues between in-scope agents - Archiving closed findings older than 30 daysEverything else requires approval.4. Human Review SLAs- Normal urgency → 24 hours- Auto-expires if no action - High urgency → 4 hours- Escalates to account owner DM after 1 hour - Emergency → 15 minutes- Pages on-call human - Auto-converts into required human action if missed5. When to Split a ProposalIf one proposal spans multiple risk tiers, split it.Example:- Pausing a creative (low risk) - Increasing budget significantly (high risk)These must be two separate proposals.Reason:- One rejection shouldn’t block safe actions - One approval shouldn’t bundle risky decisions6. Rejection Is DataEvery rejection is a feedback signal.- Store the rejection reason - Feed it into the reflection system - Agents adjust thresholds over timeExample:If “pause this creative” gets repeatedly rejected, the agent raises its confidence threshold before proposing again.7. Special Case: Client-Named ChannelsAny proposal targeting channels like:- #client-* - #account-*→ Automatically blockedRules:- Agents never post directly in client-facing channels - Route through the communication agent - Communication agent drafts → human reviews → then posts
