# Ecommerce add-on: UGC scripts

**Extra inputs:** how the product opens, is held and used (so the shown use is accurate), the visible result if the store records one, packaging that must be readable on camera, what must never be shown.

**Used up vs kept**
- Used up (cream, coffee, supplement): the shown use is the real step (the pour, the pump, the amount); the one number is days a pack lasts or a real count; the verdict is a first-use observation; never an effect on a body.
- Kept (case, pan, jacket): the shown use puts the thing through its job (closing, rolling, a hose, a wash); the one number is something the store holds (trips, washes, a returns window); the verdict is "nothing went wrong".

**Display-only products:** if handling rules say display only, show a verified sealed detail on a surface; nobody holds, opens or uses it, and no scale or efficacy is implied. If the words require use that cannot be shown, revise the words first.

**Handoff for stores:** name the action and what happens next ("it's on their site; I'd start with the small one"), and state the offer only as the store words it.
