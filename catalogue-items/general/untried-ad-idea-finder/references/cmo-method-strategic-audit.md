# Full creative-coverage matrix

For a broad audit, map desire/job, hook mechanism, awareness, micro-situation, format, competitor message and product as separate dimensions. Give each actual ad a source ID, period and uncertainty. A format is not an angle; an inferred persona is not a measured segment.

Use reference taxonomies as starting labels, merging or adding when the sample warrants it. A fourteen-format checklist can reveal missing forms, but absence is not proof that a brand should make them. Vertical playbooks are hypotheses, not forecasts backed by another brand's results.

Rank up to ten gaps by buyer importance, available product proof, coverage, feasibility and evidence quality. Show the weak cell and alternative explanations such as incomplete data. Develop up to five concrete concepts using available proof; return fewer when needed. Never manufacture limited runs, reviews, ROAS or expected lift. Save the dated matrix and history only in the requested record.
