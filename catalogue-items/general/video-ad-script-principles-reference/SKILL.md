# Video Ad Script Principles (Reference)

A library of what is true of ad scripts that sell, for any product. It describes; it does not order. Load only the sections the task needs.

## Inputs
- **Task** (required): the script you are writing or judging.
- **Sections wanted** (optional): default is the sections the task needs (table below).
- **Product type** (optional): bought again (used up, reordered) or bought once (kept). Most rules differ by this.

## Steps
1. Read `references/principles.md` for the sections you need.
2. Use the section as a standard, not a script. The business's own voice, facts and guardrails win wherever they differ.
3. When judging a script, quote the line and name the section it breaks.

| Task | Sections |
|---|---|
| Writing from research | all |
| Rewriting a reference's structure | claims, offer, promise and mechanism, hook and bridges, objections/proof/CTA, voice |
| Picking a format | beats, length and format |
| Polishing for speech | voice |

## Output
If used as guidance: no separate output; the script obeys the sections. If used to judge: a list of `line | section | what is wrong | fix`.

## Checks
- Each cited principle is actually in the reference.
- No example from the reference ends up in a script as a fact.

## If something is missing
Write `MISSING: product type` and apply the rule for both ways of buying, naming the difference.

## Avoid
- Treating the examples as usable copy: they are made up.
- Using a section the task did not call for.
