

The callAI pipeline: budget gating, soul injection, model routing (Gemini/Claude/OpenRouter), cost tracking, and the tool-calling loop for chat-mode agents.callAI — overviewcallAI is the standard method every agent uses to talk to AI models. It always follows the same 4-step pipeline:- Budget check – verifies spend before making any call - Soul injection – injects the agent’s identity and rules into the system prompt - Model routing – decides which model to use (Gemini or Claude) - Cost tracking – logs the cost of the call in the databaseYou never call model SDKs directly. Always use callAI.How to use itYou pass a config (AICallConfig) + the current job.Core fields:- model: which model to use - prompt: what you want the model to do - operation: required → defines how the cost is categorizedOptional controls:- systemPrompt: extra instructions (soul is automatically prepended) - maxTokens: response length - temperature: creativity level - images: for vision (Gemini only) - promptVersion: version trackingWhat you get backEvery response is standardized and includes:- response text - input/output tokens - cost in USD (already logged) - model usedIf tools are involved, you also get the tool execution context.Model selection (practical rule)- gemini-2.0-flash → default (cheap, fast, covers most use cases) - gemini-2.5-flash → when you need higher quality output - claude-sonnet-4 → only for high-level strategic reasoning (very expensive)Key concepts- Everything reduces to read, write, decide, respond - Every call must include an operation tag → this is how cost is tracked - JSONB + logs + cost tracking = full system visibility - The soul ensures consistent behavior across all callsTool-calling variantcallAIWithTools:- runs the same 4-step pipeline - allows up to 5 model ↔ tool interactions - returns a single final response - logs total cost for the full loopOperation tags (what matters)Every call must use a clear tag, such as:- chat → Slack responses - audit → audits - monitoring → automated checks - creative-analysis → creative reviews - hook-generation → hook creation - strategy → higher-level decisionsRules:- always lowercase, kebab-case - reuse existing tags whenever possible - never include client names - choose a level of detail that matches how you want to track costCommon mistakes- Calling model APIs directly (breaks tracking and consistency) - Skipping the operation tag (kills cost visibility) - Bypassing the soul (inconsistent agent behavior) - Retrying on budget errors manually (the system handles it) - Creating random custom tags without standardizingMental modelcallAI is not just an AI call — it’s control infrastructure.It ensures:- cost control - consistent behavior - full traceability - system-wide standardizationWithout it, you have scattered AI calls.With it, you have an operating system for agents.
