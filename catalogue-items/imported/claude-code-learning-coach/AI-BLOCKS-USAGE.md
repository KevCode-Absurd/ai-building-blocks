# Claude Code learning coach

Download and unzip the complete folder. Give SKILL.md and its references folder to an AI that can read local files; ask it to run this learning activity. Use numbered chat choices if your AI has no structured question tool. No API key or code execution is required.

AI Blocks adapted this package from luongnv89/claude-howto at 188f468893231cbe4525f45e657d554746232072, by Luong NGUYEN (luongnv89), under the included MIT license. The primary instructions are an adaptation; the original instruction, selected references, and all ten lesson texts are preserved as raw Git-blob bytes under references/upstream with .txt filenames. This avoids broken repository-relative Markdown links. Use references/lesson-index.md for the working local paths. source.json records every upstream path and hash.

The lessons describe the pinned source version. Note relevant differences from your installed Claude Code version. Scores are learning feedback, not a certification. This package has source and packaging checks; no completed AI coaching session or Tested badge is claimed. Examples in lesson files are reference text; running a command, installing a hook, connecting a service or changing permissions requires the user's actual task authorization.
