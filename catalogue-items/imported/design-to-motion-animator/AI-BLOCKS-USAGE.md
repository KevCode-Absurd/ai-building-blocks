# Design animator

Download the complete folder and read these notes before asking your AI to follow SKILL.md. Use it for the design animation you requested, within your existing task authorization. Adding this package to a library does not install or activate it, run its examples, access Figma, change a website or publish anything.

Bring a Figma frame or a static image you have permission to use. A static image is an alternative when a Figma connection is unavailable; the AI should state which layers cannot be separated reliably. For Figma, prefer an already connected, authorized tool. If a token is needed, keep it in a secure environment variable or secret store. Never paste it into chat, page code, logs or a download. Use only the supplied design scope.

Choose the result before rendering. A standalone showcase can be an HTML animation with the MP4 or GIF exports you request. Website work adds only the requested animated sections and keeps text readable in HTML; exports are optional. Follow the formats you asked for instead of treating the source's example export set as automatic authorization. File writing, capture, encoding and tool installation must stay within the task and permissions already given. Publishing needs the user's actual publishing instruction.

The workflow needs an AI coding environment, browser preview and local file access. Requested video or GIF export also needs capture and encoding tools such as FFmpeg. If a tool is unavailable, report that limit and deliver only the work completed. Source commands are examples, not commands executed during this import.

Check the finished still, movement, overflow, loop seam and reduced-motion state. State measured results and visible differences honestly. The source's image-comparison targets guide a check; they do not guarantee pixel-perfect fidelity. This import received source and packaging checks, not an executed Figma or animation-render test, and has no Tested badge.
