# 行业自适应 KPI

先识别模式。Standard 选择 5–6 个最影响价值创造、领先/结果与风险判断且可比较的 KPI；Audit 可按重大不确定性和口径问题扩展，不受 Standard 上限约束。银行、保险等不强求工业企业的 Revenue/OCF/FCF/ROIC 或 FCFF DCF；不适用项目说明 N/A 理由并使用行业指标。

| 行业/模式 | 优先 KPI |
|---|---|
| SaaS/订阅 | ARR、NRR、客户数、ARPU、毛利率、CAC 回收、FCF margin、SBC/收入 |
| 消费/零售 | 同店销售、客流/客单、门店、渠道库存、促销、毛利率、库存周转 |
| 制造/半导体 | 出货/ASP、订单、Book-to-Bill、利用率、良率、库存、Capex、ROIC |
| 银行 | NIM、贷款增长、不良率、拨备、信用成本、CET1、存款、效率比、ROE |
| 保险 | 保费、综合成本率、新业务价值、投资收益、偿付能力、留存 |
| 医药/生物科技 | 患者/处方、渗透、管线、成功概率、读出、专利、现金跑道 |
| CDMO/CRO | 在手/新签订单、项目阶段、利用率、客户集中、毛利率、Capex、回款 |
| 互联网/平台 | MAU/DAU、频次、转化、ARPU、Take rate、获客、贡献利润 |
| REIT/地产 | NOI、同店 NOI、入住、租金差、AFFO、NAV、LTV、利息覆盖 |
| 能源/矿业 | 产量、实现价格、单位成本、储量寿命、Capex、净债务、安全 |

优先长期稳定披露、可比且连接现金流的 KPI；记录定义变化；同时选择领先、结果和风险指标。停止披露是待调查信号，不自动视为负面事实。

## 选择与验证规则

- 核心 KPI 跨期使用前，按 [financial-analysis.md](financial-analysis.md) 标记 `Comparable / Partially Comparable / Not Comparable`。
- 同时选择价值创造指标、领先指标和风险指标；不因某 KPI 容易获得就代替更有决策价值的指标。
- 对影响核心 Thesis 的行业判断，按 [research-framework.md](research-framework.md) 分开展示 Company Evidence、Competitor Evidence 与 Independent Industry Data。
- 竞争对手与独立数据必须与目标公司在产品、客户、地域、时间和定义上有合理可比性；不可比处要明示。
- 无可靠独立数据时写 `Independent industry evidence unavailable / insufficient`，降低相关置信度，不伪造三角验证。
