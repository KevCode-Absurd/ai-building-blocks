# Screen stocks with a defensive investor's seven tests

Paste company figures. Get each company passed or failed on seven tests, with the price sums shown, and a short list.

This workflow follows the method in The Intelligent Investor (revised edition, with commentary by Jason Zweig) by Benjamin Graham. Each step is its own skill. You run them one after another, and each skill's result is saved and passed to the next.

## How the run works
Save each step's result as `outputs/step-NN-<skill>.md` before the next step starts.
- **A question** (a step needs something only the person knows): if they're there, wait. If not, write it as `MISSING: <what>` and carry on.
- **An approval** (nothing is sent, published or paid for without the person's clear yes).
- **A stop** (a required input is missing or a check fails): stop at that step and go to the hand-back summary.

## Steps
1. **Test each company for size, strength, record and growth.** Use the skill `defensive-stock-quality-screener`. A pass, fail or unknown on each quality test for each company, with the figure behind it.
2. **Check the per-share earnings for traps.** Use the skill `earnings-padding-detector`. Give it the audit report from the steps before. Restates the profit figures the price tests will use.
3. **Test the price against a ceiling.** Use the skill `defensive-price-ceiling-tester`. Give it the audit report from the steps before. A price pass or fail with the sums shown, so a high-flying name is cut for its price, not its story.
4. **Build the list and keep it spread.** Use the skill `defensive-stock-list-builder`. Give it the audit report from the steps before. A short list, how many names to hold and the date to look again.
5. **Write the rules for sitting still.** Use the skill `sit-still-rule-writer`. Give it the plan and the audit report from the steps before. The list becomes a holding plan with the only reasons to act.
6. **Hand back.** End with a section headed `HAND-BACK SUMMARY`: each step's file, any step not run and why, then every `MISSING:` line from all steps in one list.

## What you hand back
5 step files and the summary. The last file holds the plan.
