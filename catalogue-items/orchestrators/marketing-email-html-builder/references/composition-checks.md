# Composition and delivery checks

One module map drives both directions. Build subject, preheader, hero, mechanism or story, actual proof, product and footer only when the brief calls for them. HERO campaigns may use two art directions; WORKHORSE reminders may use a simpler single execution when requested.

For continuous-surface concept art, sample the image edge colour before blending into a solid section. Keep the product unobscured; no badge over its defining feature. A hard band is a deliberate break, not an accidental crop.

For sendable HTML, use a 600px table container, inline critical CSS, live headings/buttons, explicit image dimensions, useful alt text, logical reading order and a text fallback. Gradients, masks, local fonts and background images require fallbacks. Test the actual exported email in the intended clients; a browser screenshot is not inbox verification.

Check 320, 390 and 600px layouts, images off, enlarged text, contrast, links and unsubscribe/address placeholders. Preview at 600 logical pixels and 2x for craft review, then verify a real narrow viewport. Log exact tool/version, tested clients and any unsupported effects.
