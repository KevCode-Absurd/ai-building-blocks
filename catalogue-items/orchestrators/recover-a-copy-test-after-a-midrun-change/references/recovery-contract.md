# Copy-test recovery contract

Preserve the original question, assignment method, control/variant content, event definitions, target population, timestamps/timezone, attribution delay, planned analysis and stop rules. Record each material change with effective boundary, versions affected and evidence for the boundary.

For each proposed comparison show units, period, offer/product/tracking versions, assignment/exposure definitions and exclusion reasons. Keep excluded periods and raw totals visible. Do not select a flattering subset after seeing outcomes. An aggregate without version/time linkage cannot be silently split. A pre/post difference is not automatically an effect of copy.

Recovery decision: resume unchanged; restart with aligned versions; run a new bounded test; or stop for evidence. New test contract includes the one variable, preserved locks, outcome, guardrails, assignment, budget/time limits, lag handling, analysis/uncertainty plan and owner. No universal spend or calendar count proves significance.
