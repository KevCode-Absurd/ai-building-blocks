# Two endpoint transformation modes

For either mode, the endpoint comparison is the acceptance gate before animation. List all unchanged details; do not obscure source text or change the camera to hide a mismatch.

## Illustration to dimensional figure
A photographed drawing remains printed on the original page. Replace only the selected figure with a volumetric interpretation at the same position, pose and scale; preserve book edges, paper texture, other graphics and words. Match the real light and cast shadow. Animate apparent depth/material growth without moving the figure’s footprint or changing the scene. End with small natural motion only if it suits the subject.

## Mechanical object to toy vehicle
The original object contains design cues that can plausibly unfold into an original toy. Design the end frame with the same color/material language and camera/desk/light. Map seams and pivot points to an assembly sequence. Describe resistance, contact, weight and settling; nothing floats or liquefies. If hands interact, specify entry, grip, release and withdrawal without hiding the mechanism. Hold the finished toy long enough to read it.
