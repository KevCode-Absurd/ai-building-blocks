# Value a stock with a margin of safety

Paste a company's results, its balance sheet and the share price. Get an earnings value, an asset floor and the gap.

This workflow follows the method in Security Analysis: Principles and Technique (second edition) by Benjamin Graham and David L. Dodd. Each step is its own skill. You run them one after another, and each skill's result is saved and passed to the next.

## How the run works
Save each step's result as `outputs/step-NN-<skill>.md` before the next step starts.
- **A question** (a step needs something only the person knows): if they're there, wait. If not, write it as `MISSING: <what>` and carry on.
- **An approval** (nothing is sent, published or paid for without the person's clear yes).
- **A stop** (a required input is missing or a check fails): stop at that step and go to the hand-back summary.

## Steps
1. **Sort it as investment or speculation.** Use the skill `investment-or-speculation-sorter`. A first label and a reminder of how rough the value will be.
2. **Value it from earning power.** Use the skill `earnings-value-range-builder`. Give it the audit report from the steps before. A low, middle and high value from earnings, and how much of the price is hope.
3. **Find the asset floor.** Use the skill `asset-floor-estimator`. Give it the audit report from the steps before. What the company would fetch if it stopped, set beside the earnings value.
4. **Judge the gap between price and value.** Use the skill `price-versus-value-gap-judge`. Give it the audit report from the steps before. A plain verdict on whether there is a real margin of safety, and the risks that could remove it.
5. **Hand back.** End with a section headed `HAND-BACK SUMMARY`: each step's file, any step not run and why, then every `MISSING:` line from all steps in one list.

## What you hand back
4 step files and the summary. The last file holds the audit report.
