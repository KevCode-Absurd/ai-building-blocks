# Book notes: *AI Engineering* (Chip Huyen, O'Reilly, 2025), mapped onto our stack

One file per chapter, written on 2026-10-18 from a full read of each chapter. Each keeps:
1. the chapter in brief;
3. how we apply it, by building-block level (prompt, skill, routine, workflow, agent, app, platform), with the book's section names;
4. what it changes in docs 04–09 and the final plan;
5. what we don't adopt, and why;
6. lesson ideas for the course;
7. the questions it raised.

The section-by-section summaries of the book (section 2) are deliberately left out: we keep our own mapping, not a condensed copy of the book. For the ideas themselves, read the book.

The master is `../10_AI_ENGINEERING_FRAMEWORK.md`. It merges these notes and settles where they disagree (for example, test-set sizes and the Recommended rule), so where a note and the master differ, the master wins.
