# Knowledge pieces (planned)

This folder will hold the know-how that items are built from. The sources are Creative Engine's 403 Learning guides, the playbooks, Kevin's own docs and our own lessons.

The process (see `docs/planning/07_SOURCES_TO_SKILLS.md`):
1. Register each source.
2. Split it into pieces: rule, step, check, threshold, template, example, pitfall, metric or explanation.
3. Tag each piece by module and by how well it's backed up.
4. Group matching pieces.
5. Map each group into the items it belongs to.

Rights decide what's allowed:

| Source rights | What we can do |
|---|---|
| Own | Convert directly |
| Course | Learn from it and rebuild in our own words |
| Purchased (no redistribution) | Use as a benchmark only |
| Private client | Never use |
