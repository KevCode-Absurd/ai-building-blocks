# Example businesses

Every example on the site is made for this business. It is a real brand with the name, people and some details changed.

| id | Business | What it sells | Use it for |
|---|---|---|---|
| `sprout` | Sprout | Daily greens gummies in single-serve packs, adults and kids, sold online and in stores | Ads, images, video, product photos, product pages, offers, reviews, store work |

Rules for examples:
- Use only the facts in these files. If an example needs a fact that is not here, add it to the business file first, then use it.
- Every example on the site carries the line "Real brand, name and details changed".
- Numbers in `sprout/ad-results.csv` are practice numbers, not the brand's real results. Never present them as real benchmarks.
- No real brand names in examples. Competitors are described ("a big-name greens powder, about $79 a month"), never named.
- No real people. No names of customers, staff or spokespeople.

Files:
- `sprout/README.md`: what Sprout is and how the files were built
- `sprout/brand.md`: the brand file (what a filled-in brand brain looks like)
- `sprout/reviews.md`: 20 real public review quotes
- `sprout/ads.md`: 15 real live ad headlines
- `sprout/product-page.md`: the main product page text, warts and all
- `sprout/ad-results.csv`: practice results for 9 ads (10 rows)
