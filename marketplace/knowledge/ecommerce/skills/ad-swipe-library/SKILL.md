# Ad swipe library for an online store

**You get:** a sorted swipe library sheet and folder index of ads worth learning from, a list of real gaps, and brief starters naming which entries and elements to borrow for the next three briefs.

## When to use

- The store is starting to make ads and needs real examples to brief a designer, creator or image tool.
- Every brief says "make it pop" because nobody can point at an example.
- Before a monthly briefing round, to add fresh entries and retire stale ones.
- A new use case is coming (gifting season, a bundle launch, a sale) with no reference for it.
- Screenshots live in chat threads and nobody can find them again.

## Not for

- Rival study with a gap table and test ideas: use `store-meta-competitor`.
- Clustering long-running category ads into formulas with adaptation briefs: use `category-ad-formula-teardown`.
- Making more ads in the style of the store's own winners: use `new-ads-from-store-winners`.
- Judging the store's live ads: use `store-meta-creative-review`.

## What you need

Required:

1. **Store profile** from `store-meta-brand-dna`: products with gross profit per purchase (GPP), buyer groups, live offer, claims allowed.
2. **Source list:** 5 to 15 brands in the category, of which 3 to 5 are about ten times the store's size [MCR-0034], plus 5 to 10 outside the category whose formats the team admires.
3. **Market countries**, so searches run where the store sells.

Optional: the store's own best ads with store-side cost per purchase; last year's sale calendar; the existing library, if any.

Missing 2: start from category keywords in the Ad Library for the store's country and say so. Missing GPP: build the library, but mark offer entries "not checked".

**Access:** level 1 (read). The Ad Library is public; no account access is needed. The library lives in a sheet and folder the client owns.

## Before you start: the gates

1. **Money.** *Pass:* GPP and break-even ROAS per hero product from `store-meta-math`. *Fail:* offer, bundle and gifting entries are marked "not checked".
2. **Capacity.** *Pass:* someone briefs from the library at least monthly and one person owns updates. *Fail:* cap at 40 entries in the three folders the next briefs need.
3. **Rights.** *Pass:* the client accepts links, library IDs and our own notes, not downloaded files or retyped ad text from other brands. *Fail:* stop; copying others' creative invites claims [MCR-0055].
4. **Tracking.** Needed only for the "own winners" folder, which uses store-side cost per purchase.

## Steps

### 1. Set the folders the store will brief from

| Folder | Holds |
|---|---|
| Creator videos | A real person talking to camera, phone-native |
| Demonstration | The product working on screen |
| Before and after | Visible change with time language, checked against policy |
| Bundles and sets | Kits, multi-unit, build-your-own |
| Gifting | Explicit recipient framing ("for her", a named occasion) |
| Offers | Discount, gift with purchase, threshold, guarantee |
| Reviews and proof | Ratings, quotes with names, press with the outlet's words |
| Comparison | Versus the usual way, or a named rival where provable |
| Founder | Founder voice, story or evidence [MCR-0005] |
| Statics | Designed single images, readable in about 3 to 4 seconds [MCR-0024] |
| Problem first | Opens on the buyer's situation, product as the fix |
| Own winners | The store's best ads with results |

Add a folder only when a brief will use it in the next 90 days.

### 2. Search per folder, not one big pile

Run a search per folder: keywords for that use (for gifting: gift, for her, the next occasion) in the store's category and country, plus each source brand's page. Free tools: Meta Ad Library (note "Started running on" and the library ID) and TikTok Creative Center top ads. Paid ad-research tools can speed this up; nothing here depends on one.

Prefer ads from brands one or two steps bigger, longest running first [MCR-0034]. Look outside the category for formats, inside it for offers and claims [MCR-0055]. Include ended ads where the library shows them (EU-delivered ads stay listed after they stop).

### 3. Drop what is not a usable ad

Reject before reading further:

- The link goes to a blog, article, guide or news page; the image is usually a page preview, not designed creative.
- A boosted organic post that links to a social post, not a product page. For organic short-form, high views with under about 2% engagement suggest a paid boost [ORG-0010].
- Publishers and media pages.
- No image or video loads.
- The store's own ads (they go only in "Own winners").
- Already in the library: same library ID, or the same brand with the same landing URL (query strings removed) or the same opening text. Keep the longest-running version.

### 4. Read run length honestly

Run length = today minus "Started running on". Outside the EU the library shows commercial ads only while live, so a long live run is the best free sign an ad pays.

- 30 days or more: candidate. 90 days or more: strong (practitioner default, test it).
- A long run can be an always-on retargeting or brand ad [MCR-0034]; mark copy that assumes the viewer knows the brand "probably retargeting".
- Spend is hidden. Many live variants of one idea is a better sign than one old ad (practitioner default, test it).
- Brands whose demand comes from outside their ads run ads most stores cannot copy; one ran 0% of ads with price and 96% at product-aware buyers [MCR-0064]. Tag them "low transfer".
- Trend formats already everywhere among marketers: tag "past peak" [MCR-0062].

### 5. File each ad where it really belongs

Classify from what you see plus the copy, not from the search that found it. One primary folder; when two fit, choose the more specific. A "treat yourself" ad is not gifting. A polished, scripted actor ad is not a creator video. At most 2 entries per brand per folder.

If a folder has fewer than 3 good entries, search categories that commonly run that ad type (gifting in jewellery, candles and gift sets; before and after in hair and skin care), at most two rounds. Then record the gap as real rather than padding the folder with weak fits.

### 6. Write the teardown in our words

| Field | Rule |
|---|---|
| ID, brand, country | Library ID or link |
| First seen, run length (days), live or ended | Dated today |
| Size band | Smaller, similar, about 10x, giant |
| Folder, format, ratio | One primary folder |
| Layout zones | Top to bottom with rough percentages |
| Message roles | What each text block does ("offer in four words", "named reviewer quote"), never their words |
| Type and colour | Weight, case, size relationships; colour roles (one accent for the offer) |
| Product staging | Angle, light, crop, props |
| Awareness stage, hook type | Spoken, text and visual noted apart [MCR-0028] |
| Why it works | The mechanism, in one line |
| Rebuild for us | What to keep and what to swap, with the store's proof row |
| Pays for us | Yes, no, not checked (step 7) |
| Built already | Date, if the store has made its version |

Keep each teardown under 80 words. A claim the store cannot make (press, a figure, before and after) keeps the layout and swaps the claim; note the swap.

### 7. Price every offer against the store

Rebuild each offer on the store's numbers: break-even ROAS at that discount depth [OFF-0065], or contribution per order for bundles and gifts [OFF-0066] [OFF-0078]. "Pays for us" only when contribution per order stays at or above today's.

### 8. Screen for risk

Flag (do not delete) before and after on health or body results, copy implying the viewer has a condition [MCR-0020], and named-rival comparisons.

### 9. Refresh monthly, never restart

Add new entries, skip known IDs, recheck "live" on the top 20, retire ended entries older than 12 months, keep 3 to 10 per folder, move new store winners into "Own winners".

## Checks before you hand it over

1. Every entry has an ID, first-seen date, country, run length and live or ended.
2. No other brand's file or verbatim text is stored.
3. No entry failed a step 3 filter; no near-duplicates.
4. No folder holds more than 2 entries from one brand; thin folders show the search rounds and the recorded gap.
5. Every offer entry is priced on the store's numbers or marked "not checked".
6. Every "rebuild for us" names a proof row the store holds.
7. The plain answer ("50 ads I liked") would not beat it: each entry says what to borrow.

## Output

1. **One-screen summary:** entries by folder, real gaps, the five most useful entries for the next brief, offers that pay.
2. **Library sheet** `swipe-library.csv` with the fields in step 6.
3. **Folder index** `SWIPE-LIBRARY.md`: one section per folder, each entry a short card with the link.
4. **Brief starters:** for the next three briefs, two or three entry IDs and the exact element to borrow.

## Common mistakes

- **Saving copies of rivals' ads and their words.** Step 6 keeps links and message roles only.
- **Blog previews and boosted posts filed as ads.** Step 3 drops them.
- **Padding a thin folder.** Step 5 records the gap instead.
- **One brand filling a folder.** Step 5 caps it at two.
- **Copying a rival's discount.** Step 7 rebuilds it on the store's margin.
- **Reading run length as proof of a cold winner.** Step 4 flags retargeting look-alikes.

## Sources

- MCR-0005: founder ads work without the founder on camera.
- MCR-0020: illustrated or implied health claims still face policy.
- MCR-0024: statics clear in 3 to 4 seconds.
- MCR-0028: hooks have spoken, text and visual levers.
- MCR-0034: study longest-running ads from brands about ten times bigger.
- MCR-0055: swipe formats from outside the niche; never copy scripts.
- MCR-0062: formats decline once widely promoted.
- MCR-0064: demand-harvesting brands run ads most stores cannot copy.
- ORG-0010: high views with low engagement suggest paid boosts.
- OFF-0065: a discount can triple break-even ROAS.
- OFF-0066: buy-one-get-one can beat half price on contribution.
- OFF-0078: a low-cost gift can lift order value at nearly unchanged margin.

What makes this skill ours: every offer is priced against the store's own gross profit per purchase before anyone briefs from it; entries are our own structural teardowns with links, never copies; run length is read with the Ad Library's real limits; and each entry names the store's own proof for its rebuild, so the library only suggests ads the store can truthfully make.
