# Colour standard and lab dip approval

**You get:** a colour spec sheet per SKU, a lab dip and strike-off request, approve or reject notes the dye house can act on, a shade band rule for bulk, and a colour log with matched photos, so the colour on the product page is the colour that arrives.

## When to use

- Samples come back "close but not right" and nobody can say what is wrong.
- A product has fabric, trim, plastic and print that must all match one brand colour.
- Bulk colour differs from the approved sample.
- Returns or reviews say "colour not as pictured" or "darker than the photos".
- A new colourway is being added.

- Product photo colour accuracy on the site: work with Aurelio (`product-photo-retouch-and-consistency`).

## What you need

Required:

1. **The brand colour** for each part, as a Pantone code or a physical swatch.
2. **The materials** each colour goes on (cotton jersey, nylon webbing, ABS plastic, coated paper).
3. **The factory or dye house contact** and its usual lab dip turnaround.

Optional: the current product page photos, return reasons and reviews about colour, a competitor product whose colour the owner likes.

Maxine drafts at level 2. Buying Pantone books or physical standards, and courier costs, need the owner's yes. Colour approval is the owner's call; this skill prepares it.

## Before you start: the gates

1. **One master standard.** Pass: the store holds one physical standard per colour. Fail: buy it before the first dip; a screen or a PDF is not a standard.
2. **Right book for the material.** Pass: the code comes from the Pantone guide for that material (textile cotton or polyester guides for fabric, coated or uncoated guides for print, plastic standards for moulded parts). Fail: a print code on a fabric spec will never match.
3. **Light agreed.** Pass: the factory and the store judge under the same named light. Fail: agree it first; colour judged under shop lights or a window will not match.

## Steps

### 1. Write the colour spec per part

For each part: colour name, Pantone code and book, material, physical standard reference, and the light. Parts that must match each other are listed together, with which one leads (usually the main fabric). Different materials take dye differently, so each material needs its own approval.

### 2. Set the lights

Primary: D65 (daylight) in a light booth. Second check: TL84 (shop fluorescent) or the light the buyer will see it under. A dip that matches under one light and not the other has a metamerism problem; reject it, because the buyer will see the shift at home.

### 3. Send a lab dip request

Ask for 2 or 3 dips per colour (labelled A, B, C) on the real base material, cut to a set size (house default about 10 by 10 cm), with the dye house reference on each. For prints, ask for a strike-off on the real fabric at real scale. Give the turnaround you need and where to send.

### 4. Judge and write notes a dye house can use

Compare each dip to the standard in the booth under both lights, side by side, at arm's length. Mark one of:

- **Approve:** matches under both lights.
- **Approve with comment:** close; write the direction for bulk.
- **Reject:** write the direction in dye terms: lighter or darker, redder or greener, yellower or bluer, brighter or duller. "Too red, slightly lighter" is useful; "not quite right" is not.

If the factory or a lab measures colour with a spectrophotometer, agree a number in writing; a common commercial tolerance is a colour difference of 1.0 or less on the CMC 2:1 scale. Keep the visual check as the final word.

### 5. Photograph every round the same way

Same light, same grey card, same camera settings, standard and dip in one frame. Screens and phones shift colour, so the photo is a record, not the approval.

### 6. Control bulk with a shade band

Bulk dye lots vary. Ask the factory for a shade band (cuttings from each bulk lot) before cutting, and approve each lot against the standard. Lots outside the band are rejected or kept to separate SKUs, never mixed in one order.

### 7. Close the loop with the page

Send the approved colour and a booth photo to Aurelio so the product page matches. Watch "colour not as pictured" returns on the first lot for 90 days.

## Checks before you hand it over

- Every part has a code from the right book for its material and a physical standard.
- The primary and second light are named and agreed with the factory.
- Each rejected dip has a direction in dye terms.
- Every round has a photo under the same set-up.
- A shade band rule covers bulk lots.
- The approved colour reached the product page team.

## Common mistakes

- **Approving on screen.** Gate 1 and step 5 use a physical standard and a booth.
- **A print code on fabric.** Gate 2 uses the book for the material.
- **One light only.** Step 2 checks a second light for shift.
- **"Not quite right".** Step 4 gives a dye direction.
- **Mixing dye lots.** Step 6 approves each lot against the band.
