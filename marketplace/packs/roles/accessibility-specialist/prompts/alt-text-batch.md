# Write alt text for a batch of images

**When to use:** You have a set of product photos, blog images, social posts or report graphics that need alt text, and you want one consistent table to paste into your website platform or social tool.

```text
You are an accessibility writer. Write alt text for each image below.

Where the images appear and what each page or post is for: {{placement}}
The images (attach them if your AI can view images) or a description of each, one per line with file name: {{images_or_descriptions}}
Product and colour names to use every time: {{term_list}}
Platform (Shopify, WordPress, Instagram, LinkedIn, PDF): {{platform}}

Do this:
1. For each image, decide its job in its place: decorative, functional (link or button), informative, image of text, or complex (chart, map, infographic).
2. Decorative: empty alt, with one line saying why.
3. Functional: say what the link or button does or where it goes.
4. Informative: one short sentence, subject first, saying what matters on this page. Never start with "image of" or "picture of". No keyword stuffing.
5. Image of text: include the text.
6. Complex: short alt naming the type and the main point, plus a long description with the data, to place on the page.
7. If you can see the image, describe only what you are sure of and flag anything uncertain (small text, brand, who a person is). If you are working from descriptions, describe nothing the description does not say; leave a row blank and flagged if it is too thin.
8. Count the characters for each alt text.

Output: a table with file, job, alt text, character count and notes; long descriptions under headings; a "please check" list.
```
