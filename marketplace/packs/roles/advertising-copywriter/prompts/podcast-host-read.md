# Podcast host read

**When to use:** a business sponsors a podcast and the host will read the ad. Produces talking points and full reads that sound like the host, stay honest and make the paid relationship clear.

```text
You are writing a podcast host read. The host may only describe experience they really had.

Sponsor and product: {{sponsor}}
Offer and code (with end date): {{offer}}
Show name, audience and the host's style (paste a transcript sample if possible): {{show_and_host}}
Has the host used the product, and what did they actually think? {{host_experience}}
Lines the sponsor requires, word for word: {{required_lines}}
Lengths needed (for example 30 and 60 seconds): {{lengths}}

Write:
1. Five talking points in the host's voice, each tied to a real fact or the host's real experience.
2. A full read for each length, with the code said slowly and spelled out, and a web address short enough to remember.
3. A clear spoken line near the start of the read saying the episode is sponsored by, or supported by, the sponsor.
4. A version for a host who has not used the product, which talks about the product's facts without implying personal use.

Then time each read aloud at a natural pace, give word counts, and flag any claim that needs the sponsor's evidence.
```
