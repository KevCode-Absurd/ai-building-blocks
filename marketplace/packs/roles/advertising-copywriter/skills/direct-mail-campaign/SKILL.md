# Direct mail campaign

Direct mail is one of the few media where every reply can be traced to a version and an area. This skill sets the maths before the words, writes versions that teach something, and reads the results against break-even. The client owns the list and its data rules; the copywriter does not buy lists, handle personal data or rule on data protection law.

## When to use

- A local service mailing homes in chosen areas.
- A restaurant or shop mailing past customers from its own system.
- An online brand mailing lapsed buyers.
- An owner who mailed before and could not tell if it worked.

## What you need

- **Costs:** print and postage per piece, design, any list or mail-house fees.
- **Value:** average first order or job, gross margin, repeat rate and repeat value if known.
- **Who to mail:** the client's own customer data or chosen areas, and the client's list rules. In the UK, addressed marketing mail lists are usually screened against the Mailing Preference Service, which takes up to three months to take effect and does not cover unaddressed mail. In the US, USPS Every Door Direct Mail reaches every address on chosen carrier routes without names. Data protection questions go to the client's adviser.
- **Offer and deadline** the business can afford and honour.
- **Format:** postcard size, letter and envelope, or door drop; the mail house's or postal service's template.
- **Access level:** level 1 for planning and copy. Preparing files and order details needs level 2. Sending files to a printer or mail house needs level 3, within the client's quantity and spend cap; the client places and pays for postage orders.

## Steps

1. **Work out break-even.** Profit per response = average order x margin (or job value less job costs). Break-even response rate = cost per piece / profit per response. Show the sum. Repeat it with repeat value, if the client has it, so they see both views.
2. **Set the list rules with the client:** who is in, who is out, how many, when. Record that the client has checked them against their own data rules and preference services.
3. **Design the offer:** specific, affordable at the expected response, with a real deadline that is honoured.
4. **Decide what to test.** Three versions, each changing one thing: offer, headline or format. Split the list randomly or by matched areas so the versions are comparable.
5. **Write the copy.** Postcard front: headline that works at a glance, picture idea, offer. Back: two or three short benefit lines, proof, offer details with conditions beside them, deadline, response path, return address. Letter: envelope line, headline, opening that names the reader's situation, body, offer, the deadline restated, signature and a P.S. that repeats the action.
6. **Set tracking per version:** a unique code, phone number or landing page, and how staff log each response (date, version, value).
7. **Write the layout spec:** size, bleed and safe area from the printer's template, address area and postal indicia position from the postal service's rules, where the offer, deadline and code sit.
8. **Check:** claims only from the brief, prices and deadlines correct, the code on every version, the response path working before the drop.
9. **After the drop,** read the response counts: response rate, cost per response, revenue, and each against break-even, by version and area. Allow for late responses before the final call.
10. **Write the next test** from what was learned.

## Checks

- Break-even sum shown with the client's numbers.
- Every version changes one thing and has its own code or number.
- Deadline is real and printed in full.
- Conditions sit next to the offer.
- List rules recorded as the client's; no personal data handled by the copywriter.
- The response path was tested before printing.

## Output format

1. **Break-even table:** cost per piece, profit per response, break-even rate, with and without repeat value.
2. **Plan:** list rules (client's), quantity, split, dates.
3. **Copy per version:** front and back, or envelope and letter, with what each version tests.
4. **Tracking set-up:** code or number per version, logging steps.
5. **Layout spec.**
6. **After the drop:** results table and verdict against break-even.

## Example of good output (short)

*Brightpane Window Cleaning is a made-up business used only to show the format. Costs and values below are the made-up client's.*

| Item | Value |
|---|---|
| Print and postage per card | 0.42 |
| First clean, profit after labour | 30.00 |
| Break-even response rate (first clean only) | 0.42 / 30.00 = 1.4% |
| Share who become regulars, and profit per regular per year | 60%, 120.00 |
| Break-even with first-year repeat value | 0.42 / (30.00 + 0.6 x 120.00) = 0.41% |

**Versions:** A, "First clean half price" with code BP-A. B, same offer with headline "See your street through clean glass" and code BP-B. C, "Free gutter check with your first clean" with code BP-C. Each goes to matched postcode areas of equal size.

**Readout rule:** after four weeks, compare response rate and value per version against both break-even rates, and keep the version that clears the first-clean break-even, or the repeat break-even if the client confirms repeat rates.
