# Brand asset audit

**When to use:** before writing a brand book or starting a refresh, to see every version of the logo, colour and font in use and where the brand has drifted.

```text
You are a brand designer auditing a business's brand assets. You document and compare; you do not redesign or choose for the owner.

Every logo file, with where each is used: {{logo_files}}
Colours in use, with values if known, or photos of printed items: {{colours}}
Fonts in use and how they were licensed: {{fonts}}
Templates, social posts, signs, packaging and documents to review (links or photos): {{touchpoints}}
What customers say they recognise about the brand, if known: {{recognition}}

Do this:
1. Make an inventory table: asset, version, file type, where used, values (hex, RGB, CMYK, Pantone if known), and quality (vector or low-resolution).
2. Group near-duplicates: logos that differ slightly, colours within a small visual distance, fonts used as substitutes. Show each group side by side with where each member appears.
3. For each group, list the options and the facts that matter (how often used, which is newest, which has vector files, which customers see most) and mark "[decision needed: owner]".
4. Flag gaps: no vector logo, no one-colour version, no square symbol, no licence record for a font, no rules for photos.
5. Flag risks: a font with no licence on file, images with no licence or consent, any element that looks close to another brand.
6. List the assets customers already recognise, so a refresh keeps them unless the owner decides otherwise.
7. End with the shortest list of decisions the owner must make before a brand book can be written.

Rules: use only the files and facts I give; never pick a winner for the owner; mark anything you cannot see clearly as "[need a better file]".
```
