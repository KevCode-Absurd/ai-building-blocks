# Brand book from scattered assets

**Trigger:** a business has several logo versions, colours and fonts in use, staff make their own versions, or a new agency or printer needs one document to follow. No redesign is wanted.

**Time:** usually one to three weeks, most of it waiting for files and the owner's decisions.

## Steps

1. **Intake and access.** Ask for every logo file, colour, font, template and photo in use, and where each appears. Ask which access level the client grants in each tool (Canva, Figma, a brand portal, shared drives) and record it as "Access I have". Until they answer, work at level 1: read what is shared, change nothing.
2. **Audit (prompt: brand-asset-audit).** Inventory every asset, group near-duplicates, flag gaps (no vector logo, no one-colour version) and risks (fonts with no licence on file, images with no licence or consent).
3. **Decisions.** Send the owner the shortest list of choices: which logo, which green, which font. Each option shows where it is used today.
   **Approval point 1:** the owner decides every "[decision needed]" item. Nothing is documented as a rule until it is decided.
4. **Fill gaps.** Where a one-colour version, square symbol or vector master is missing, brief the client's designer to make it from the approved logo, without redesigning (skill: logo-design-brief, versions and files section only).
5. **Colour and type (skill: palette-and-type-system).** Record roles and values, mark conversions for the printer, build the contrast pairing table, and record font licences and Office fallbacks.
6. **Write the book (skill: brand-guidelines-book).** Logo rules, colour, type, imagery, applications (email signature, letterhead, cards) and a template list.
   **Approval point 2:** the owner approves the book.
7. **Roll out.**
   - Level 1: deliver the book as a file; the client's team updates templates.
   - Level 2: build the book and the template set in the client's tool as drafts named "DRAFT"; set up a draft brand kit with the approved colours, fonts and logos. Log what was created.
   - Level 3: show the action list and limits (which brand kit, which templates, which shared folders) and get a yes; then publish the brand kit and templates within those limits. Move old files to a "Retired" folder rather than deleting them; deleting any file needs a fresh yes. Log each action.
8. **Hand over.** Deliver the book, the decision list with the owner's choices, the approved asset files, the template list and the action log. Suggest a review date, such as when the next campaign or agency brief starts.

## Outputs

- Asset inventory with conflicts, gaps and risks.
- Decision list with the owner's choices.
- Brand book: logo, colour, type, imagery, applications.
- Template list with master layouts.
- Draft templates and brand kit (level 2) or published ones within limits (level 3).
- Action log of every change made in the client's tools.

## Needs the client's approval

- The access level for each tool, and the limits for level 3.
- Every conflict decision (point 1).
- The finished book (point 2).
- Any font or image licence bought, each time; payment stays with the client.
- Deleting or replacing any live file or template, each time.
- Anything outside the level 3 limits, asked again each time.
