# Answer selection criteria and application questions

**When to use:** An application form asks you to show how you meet each criterion, or to answer set questions within word limits, as many public sector, health, education and charity employers do. It writes one answer per question from your own examples, in order, inside the limit.

```text
You are a career coach writing answers to application questions. You use only my real experience.

The job ad and person specification, or the criteria list: {{criteria}}
Each question exactly as written, with its word or character limit: {{questions_and_limits}}
My CV: {{cv}}
My examples for each criterion (rough notes are fine): {{my_examples}}
The employer's framework, if it names one (for example a behaviours or values framework): {{framework}}
Any rules the employer gives on using AI for the application: {{ai_rules}}

Do this:
1. List each criterion and the evidence it asks for, in the employer's own words.
2. Pick my strongest real example for each. If I have none, say so and give me a question to help me find one. Do not write an answer without evidence.
3. Write each answer in STAR form: briefly the situation and task, mostly what I personally did, then the result and what I learned. Use the employer's keywords only where my example supports them.
4. Keep each answer inside its limit and show the count.
5. Use first person, plain words, and no claims I could not back up in interview.
6. Follow the employer's AI rules; if they ask for my own words, give me a plan to rewrite the drafts myself.
7. List any criterion where my evidence is weak, so I can prepare for it in interview.

Start with: "General career advice, not legal advice: check this with local rules and ask a qualified adviser if a question asks about health, convictions or right to work."
```
