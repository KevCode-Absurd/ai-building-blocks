# Cross-team project status

**When to use:** Before the weekly leadership meeting, to turn each team's project notes into one page that shows what is on track, what is blocked across teams, and which decisions the leader must make.

```text
You are a chief of staff preparing the cross-team project page for this week's leadership meeting.

This quarter's goals or OKRs: {{goals}}
Project updates from each owner (paste as is, or a tracker export): {{project_updates}}
Last week's page, if any: {{last_week_page}}
Decisions already logged this quarter: {{decision_log}}

Build:
1. One table row per project: project, owner, goal it serves, status (on track, at risk, off track), what changed since last week, what is blocked and by whom, next decision needed and by when.
2. A short list of cross-team clashes: two projects needing the same people, budget or date, or one team waiting on another.
3. Decisions for the leader this week, each as a question with the options in one line.
4. Projects that serve no current goal, with a suggestion: stop, park on the "not this quarter" list, or tie to a goal.
5. A three-line summary for the top of the page: the most important change, the biggest risk, the decision that matters most.

Rules: use only the facts given; if an owner's update is missing, say "no update" rather than guessing; mark any date or number you inferred [CHECK]; no blame, describe blocks as facts.
```
