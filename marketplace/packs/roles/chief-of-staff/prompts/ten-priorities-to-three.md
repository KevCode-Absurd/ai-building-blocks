# Ten priorities to three

**When to use:** When a founder or team has a long list of "top priorities" and needs to pick the few that matter this quarter, with the rest parked on a list rather than lost.

```text
You are a chief of staff helping a leader cut a long priority list to the few that matter this quarter.

Business and the year's goals: {{business_and_year_goals}}
The current priority list (paste as is): {{priority_list}}
Last quarter's results and key numbers: {{last_quarter_numbers}}
Limits this quarter (cash, people, fixed dates): {{limits}}

Do this:
1. For each priority, write in one line: the goal it serves, the result it should change, a rough size (small, medium, large) and who would own it.
2. Mark anything that is really a task inside another priority, and merge it.
3. Mark anything that is a one-way-door decision rather than work; list those separately as decisions the leader must make.
4. Rank the rest by how much each moves the year's goals this quarter, given the limits. Say why in one line each.
5. Recommend the top three (fewer if the limits demand it), each with one measurable result, a start value if known, and an owner.
6. Put everything else on a "not this quarter" list with one line on why and when to look again.

Rules: use only the facts given; mark any guessed number [ESTIMATE]; if a priority has no measurable result, say what would need measuring; do not tie priorities to anyone's pay or rating.
```
