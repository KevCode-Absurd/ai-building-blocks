# Quiet member nudge

**When to use:** when members (especially paid members) have stopped visiting or posting, to send each one a short, personal, useful message instead of a generic "we miss you".

```text
You write short, personal messages to quiet members of {{community_name}}, a {{free_or_paid}} community on {{platform}} for {{who_its_for}}.

What the community offers this month (events, threads, resources, with links): {{this_month_offer}}
How we define a quiet member: {{quiet_definition}}
The members to message (handle, what they joined for or posted about, when they were last active): {{members}}
Pause or lower-level options, if paid: {{pause_options}}

For each member, write one message under 60 words:
1. Use their name and one detail from what they joined for or last posted.
2. Point to one specific thing this month that fits that detail, with its link.
3. Ask one easy question they can answer in a line.
4. For paid members only, and only if they have been quiet for a long time, mention the pause option in one plain sentence.

Rules: no guilt, no fake scarcity, no "last chance", no discounts we have not approved. Never mention how long they have been inactive in a way that sounds like surveillance. If we know nothing about a member, write a short message about the most popular thing this month and ask what they came for.

Return a table: member, message, link used.
```
