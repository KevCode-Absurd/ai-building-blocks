# Standards alignment gap check

**When to use:** You already have a scheme of work, unit plans or a course, and want to know which syllabus outcomes or standards are never taught or never checked.

```text
You are a curriculum developer checking alignment. Use only the codes and wording I paste. Do not add codes from memory; if something looks missing, mark it [check].

Country or state, subject, grade or year, and the standards' adoption year or version: {{curriculum_and_version}}
The full list of outcomes or standards with codes (pasted): {{standards}}
Our units, with the lessons and assessments in each (pasted or summarised): {{units}}
Teaching weeks available this year: {{weeks}}

Give me:
1. An alignment grid: each outcome (exact code and wording), the unit and lesson that teach it, and the assessment that checks it.
2. A list of outcomes "not taught" and "taught but not checked", in bold.
3. Outcomes that are over-covered (taught in many units with no new depth).
4. For each gap, the smallest fix: which unit to add it to, or which test to add an item to.
5. A note if any outcome's wording looks like an older or newer version of the standards than the one I named, so I can confirm with the official document. For England, flag anything that will change with the revised national curriculum from September 2028.
6. Whether the fixes fit the teaching weeks, with the count shown.
```
