# Adapted materials, same goal

## When to use

- A teacher has a worksheet or lesson and a class with a wide reading range.
- A tutoring centre wants the same task at three levels so one answer key works.
- An adult education class needs a scaffolded version of a real-life reading task.
- New learners of English need key vocabulary before a lesson.
- A learner needs a step-by-step visual version of a practical task.

Do not use it to diagnose needs, describe or label children, write education plans for named pupils, or change what a lesson assesses. Those belong to the teacher and the school's SENCO or specialist staff.

## Access needed

- **Level 1 (read):** the original lesson or worksheet and the goal.
- **Level 2 (read and draft):** save all versions to the agreed folder; create draft assignments.
- **Level 3 (read, write and publish):** post the agreed versions to the named class or groups on the agreed date. Assigning a version to a named learner is the teacher's choice; I post to groups the teacher set up.

## What you need

1. The original worksheet or lesson, pasted or shared.
2. The learning goal, if the teacher has one; otherwise I write it from the task and ask for confirmation.
3. The levels needed, described by reading demand ("about two years below the class", "new to English, can read simple sentences"), never by a child's name or diagnosis.
4. Any words learners must learn, and any the teacher does not want simplified (subject terms).
5. Whether the copy is printed or digital.

## Steps

### 1. Write the shared goal

One line: "Learners can ...". Put it in a box at the top of every version. If a change would alter the goal, stop and ask.

### 2. Read the original for demand

Mark long sentences, rare words, idioms, dense paragraphs and multi-step instructions. Keep subject terms the lesson teaches, and explain them rather than replace them.

### 3. Build three reading levels

- **Version A:** the original, tidied (clear numbering, one instruction per line).
- **Version B:** shorter sentences, common words for non-subject vocabulary, a glossary box for subject terms.
- **Version C:** short sentences, one idea each, a worked example before the first question, a word bank, and chunked text with headings.

Keep the same questions in the same order with the same numbers, so one answer key works and the class can discuss the same items together. Never remove the question that checks the main idea; add steps before it instead.

### 4. Build the scaffolded version

Break each task into steps. Add sentence starters for written answers ("One cause was ... because ..."). Add a word bank. Add a worked example of a similar, not identical, item. Leave real space to write.

### 5. Visual schedule and task cards

One step per card: a short instruction under a picture brief. Picture briefs describe the action or object ("hand pouring water into a measuring jug, 250 ml line visible"), never a real child. Number the cards.

### 6. Vocabulary sheet

Key words with a simple definition, an example sentence linked to the lesson, and a picture brief. Offer flashcards if asked. Keep definitions accurate; check them against the teacher's material.

### 7. Check for giveaways

Read each easier version aloud. Does any scaffold, starter or example give the answer to a question? If so, change it to a parallel example. Does the easier version still ask learners to do the thinking the goal requires?

### 8. Accessibility for digital copies

Alt text for every image (or empty alt for decoration), readable contrast, headings, no text inside images, spacing that holds when learners enlarge text, and no strict timer. This follows UDL's idea of more than one way in and more than one way to show learning.

## Checks

- The goal box matches across every version.
- Question numbers and order match across versions; one answer key fits all.
- The main-idea question is present in every version.
- Subject terms are kept and explained, not swapped out.
- No starter or example gives an answer away.
- Every fact comes from the teacher's material.
- No learner is named, described or diagnosed; levels are described by task demand.
- Digital versions pass the basic accessibility checks above.

## Output format

1. **Goal box.**
2. **Versions A, B and C** one after another (or side by side in a table), with matching numbers.
3. **Scaffolded version** with starters in bold.
4. **Task cards** with picture briefs in brackets.
5. **Vocabulary sheet** table: word, definition, example sentence, picture brief.
6. **One answer key.**
7. **Notes for the teacher:** what changed in each version and why, and anything to [check].

## Example

*Made-up example: "Elm Street Adult Learning Centre" is invented for illustration.*

**Goal (all versions):** Learners can find a departure time and a platform on a bus timetable.

**Question 3, Version A:** Using the timetable, state the latest bus that reaches the hospital before 10:00 and the stop where it leaves.

**Question 3, Version C:**
Look at the timetable.
Find the row for "Hospital".
Look for the times before 10:00.
Which is the last bus before 10:00?
Where does it leave from?
**Starter:** The last bus before 10:00 is the ... It leaves from stop ...

**Worked example (Version C, before Q1):** "To find the 08:15 bus, go to the top row. Read across to 08:15. Look down to the 'Market' row." (Different times and stops from the questions, so it shows the method without the answer.)

**Vocabulary:**

| Word | Simple meaning | Example | Picture brief |
|---|---|---|---|
| departure | when the bus leaves | The departure time is 09:40. | (bus pulling away from a stop, clock showing 09:40) |
