# Weekly lesson pack

**Cadence:** Once a week, usually Thursday or Friday for the week ahead. About 20 minutes of the teacher's time: send the week's aims and last week's exit-ticket results, then review the pack.

**Access:** Set at the start, per tool (see `access.md`). Until you choose, I work at level 1 and hand you documents to copy.

## Steps

1. **Collect (level 1).** The scheme of work or unit plan for next week, the curriculum wording for each lesson, lesson lengths after settling, any timetable changes (trips, assemblies, mock exams), and last week's exit-ticket or quiz results with names removed.
2. **Act on last week.** Run the `exit-tickets-to-reteach-plan` prompt on each class's results. Fold a short reteach into the first lesson of the week where most learners missed the aim.
3. **Plan the lessons.** Use the `lesson-plan-and-class-materials` skill for each lesson: aim, exit ticket first, timed plan, support and stretch, worksheets and answer keys. Keep a running review of earlier content in starters.
4. **Adapt where needed.** For classes with a wide reading range or new learners of English, run the `adapted-materials-same-goal` skill on the main worksheet. Same goal, same questions, one key.
5. **Quiz at the end of a unit.** If a unit ends this week, build the quiz with the `assessment-blueprint-and-mark-scheme` skill; agree the blueprint first.
6. **Cover-ready.** Add a one-page cover version of the riskiest lesson with the `cover-lesson-for-a-non-specialist` prompt, so an absence costs nothing.
7. **Check.** Run the skill checks: timings add up, codes match the pasted wording, keys complete, no pupil names, digital copies accessible.
8. **Save (level 2).** Save the pack to the agreed folder and create draft assignments in the class platform. *Approval: the teacher reviews the pack and marks any changes.*
9. **Publish (level 3).** After the teacher's yes, schedule the agreed assignments and quizzes to the named classes on the agreed dates, and log each one (what, where, when, result).
10. **Close the loop.** Ask for this week's exit-ticket results next Thursday.

## Outputs

- One plan per lesson with timed table, exit ticket, support and stretch
- Worksheets and answer keys, plus adapted versions where needed
- End-of-unit quiz and mark scheme, if a unit ends
- One cover-ready lesson
- Draft or scheduled assignments in the class platform, with a log

## Needs the client's approval

**Runs at level 3 after one confirmation per week.** I show the list: which assignments and quizzes go to which classes on which dates. After your yes, I schedule them and log each one.

**Always needs a fresh yes.** Deleting or replacing an assignment learners have started; changing released marks; sending anything to parents or a new class; publishing anything outside the class platform.
