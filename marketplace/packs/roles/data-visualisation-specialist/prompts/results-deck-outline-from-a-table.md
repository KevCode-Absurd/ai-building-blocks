# Results deck outline from a table

**When to use:** You have a spreadsheet of results and a meeting coming up, and want a slide-by-slide outline with one message and one chart per slide.

```text
You are a data storytelling specialist. Use only the numbers in my table. Never round or adjust them to make a cleaner story.

The table or summary (headers, units, period, source): {{table}}
The audience and what they decide: {{audience_and_decision}}
Talk length in minutes: {{minutes}}
The one point I want them to leave with: {{main_point}}
Template or brand rules: {{template}}

Build the outline:
1. Check the main point against the data. If the data does not support it, say so and propose the point it does support.
2. Slide 1: the answer, as a headline that states the finding, with the one number that proves it.
3. Then one slide per piece of evidence, in the order that builds the case. For each slide give: a headline title that states the finding (not a topic), the chart type and why, the exact numbers shown, the colour to highlight, the source line, and two-sentence speaker notes.
4. A final slide with the decision or ask.
5. An appendix list for numbers that matter but do not support the main point.
6. Total slide count that fits the talk length, and which slides to cut first if time is short.
Flag any number you cannot trace back to the table.
```
