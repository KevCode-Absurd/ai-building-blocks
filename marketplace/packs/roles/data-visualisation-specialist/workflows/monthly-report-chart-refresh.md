# Monthly report chart refresh

**Cadence:** Monthly or quarterly, when new figures land for a recurring report, board pack or results page. About one to three hours once the chart set and style are in place.

## Steps

1. **Confirm access (level 1).** Re-read "Access I have" from last time. If anything changed (new folder, new deck, new person who sees it), ask before going on.
2. **Collect the new figures (level 1).** The updated table, its source and export date, and any changes to definitions or periods since last month. Note late or revised figures.
3. **Tie out the numbers (level 1).** Check three totals against the source the owner trusts (accounts, till, CRM). Check that the base for each percentage is unchanged. Any mismatch goes back to the data owner before charts change.
4. **Re-check each message (level 1).** For each chart, does last month's headline still hold? If the finding changed, rewrite the headline title; never keep an old title on new data.
5. **Update the specs (level 1 or 2).** Swap in the new data. Keep chart types, axes, colours and positions the same as last month so readers compare like with like, unless the review below says otherwise. Use the `chart-pick-and-spec` skill for any new chart.
6. **Review (level 1).** Run the `chart-review-and-fix` skill on the refreshed set. Check axis ranges did not silently change (a bar axis must still start at zero), that new categories got a colour from the palette, and that alt text and long descriptions carry the new numbers.
7. **Style check (level 1).** Compare against the palette sheet from the `accessible-chart-colour-and-text` skill: hex codes, contrast ratios, labels, source line format, date format.
8. **Build the refreshed drafts (level 2).** Update a copy of the deck or workbook, or the unpublished versions in the chart tool. *Approval: the report owner reviews changed headlines and any number flagged in step 3.*
9. **Publish (level 3).** After the owner's yes on the list, republish the charts, update the embedded data or replace the slides in the live file, within the limits set. Replacing a chart others embed elsewhere needs a fresh yes. *Approval: yes on the action list.*
10. **Check and report.** Open the live versions, check five values against the table, then send a short note: what changed this month, headlines that changed, any open data questions, and the action log.

## Outputs

- Tie-out table (number, source value, chart value, match)
- Refreshed chart specs or files with updated headlines, alt text and long descriptions
- Drafts for review (level 2) and published charts (level 3)
- Monthly change note with the action log

## Needs the client's approval

Any number that does not tie out; any headline that changes meaning; any change to chart type, axis, palette or position; the action list before republishing at level 3; and a fresh yes before replacing charts embedded elsewhere or sharing with new people. The client can lower the access level at any time.
