# Review a teardown before it goes to the owner
Read report.md against evidence.json, not against the summary. For each section ask: is the claim cited, does the cited item actually say it, is an inference labelled, is an unknown treated as absent? Re-derive three numbers (a price, a count, a run length) from evidence.json.

Check the engine sentence: would an operator agree it names the one to three channels doing the work and the entry offer? Check each hand-off: the right agent for the lane, a brief with a number and a deadline, no instruction to copy the competitor's words or images, a fit with the owner's store. Run `teardown-report.mjs check` and treat its errors as blockers. Return blockers, then improvements, with section names.
