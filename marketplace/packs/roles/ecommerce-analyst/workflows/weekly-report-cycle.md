# Weekly report cycle

**Cadence:** weekly, Monday morning, covering the previous Monday to Sunday (or the client's own week).

**Trigger:** a new week starts, or a number in last week's report moved enough that the owner asked "why?".

## Steps

1. **Pull the exports (level 1; tools: store reports or order export, GA4 or Shopify analytics).** Last week, the week before and the same week last year. Confirm time zone and currency.
2. **Reconcile first (prompt: store-vs-analytics-reconcile).** Store orders against analytics purchases by day. If the gap changed sharply, mark the days as partial and raise it before anything else.
3. **Build the report (skill: weekly-store-report).** KPI table, channel table, three to five findings with actions, glossary. Mark known breaks (Shopify's September 2026 session change, channel value changes, banner or tag changes).
4. **Explain any big move (skill: sales-change-diagnosis).** Only when a headline number moved beyond its usual range or the owner asks.
5. **Check margin and returns monthly (skill: margin-and-returns-check).** On the first Monday of each month, add the margin and returns page for the month whose return window has closed.
6. **Share (level 2 to save a draft; level 3 to publish the dashboard and add GA4 annotations within limits).**
   **Approval point:** the first week's report layout, definitions and channel groups are approved by the owner. After that, the same layout can be published each week at level 3 without a new yes. Changing a definition needs the owner's yes and a note in the data check box.
7. **Log and report.** What was pulled, any change made in a tool, and anything unexpected (a tracking break, a privacy warning, a sudden gap). Stop and ask before acting outside the limits.

## Outputs

- One-page weekly report, same layout each week.
- Data check box with the reconcile result and breaks.
- Sales change note when needed.
- Monthly margin and returns page.
- Change log.

## Needs the client's approval

- The report layout, metric definitions and channel groups (once, then on any change).
- Any change to GA4 or store settings beyond annotations and saved reports.
- Sharing the report with anyone new.
