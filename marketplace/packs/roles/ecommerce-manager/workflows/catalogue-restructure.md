# Catalogue restructure

**Trigger:** filters are messy, shoppers can't narrow down, a large new range is coming, or the store is moving platform.

**Cadence:** a project of two to six weeks, then a monthly tidy-up.

## Steps

1. **Agree access and scope (level 1 to start).** Ask the access level per tool and write it under "Access I have". Agree which categories are in scope and what must not change.
2. **Audit (prompt: filter-and-attribute-audit, one category at a time).** Shopper dimensions, filter gaps, duplicate values, missing data.
3. **Design (skill: catalogue-structure).** Category tree, attribute dictionary, allowed values, variant and tag rules, import template.
4. **Plan search impact.** Which filtered views become real collections, which filtered URLs stay out of crawling, and which old category URLs need redirects (with the Shopify specialist or the site's developer).
   **Approval point 1:** the client approves the tree, the attribute dictionary, the value map and the redirect plan. Bulk category changes that affect tax need explicit approval.
5. **Fill the gaps.** Request missing values from the client and suppliers. Products without required values wait, or go live with the gap listed.
6. **Load as drafts (level 2).** Import sheet or draft products; filters saved but not published; menu changes prepared.
7. **Go live in order (level 3 within limits, or the client applies).** Values first, then filters, then menu and redirects. Show the change list and get a yes before the first live change.
8. **Check.** Every collection with each filter applied; products that vanish; site search for top terms; feed diagnostics after the next update. If products disappear or errors appear, stop and report.
9. **Hand over (prompt: filter-and-attribute-audit monthly).** The import template, the keep-it-tidy guide, and a monthly check.
10. **Ask the ecommerce copywriter** to update collection copy and product titles to match the new names.

## Outputs

- Category tree, attribute dictionary, value map, variant and tag rules.
- Import template and guide.
- Product map and missing-data list.
- Change log and post-launch check.

## Needs the client's approval

- The structure, value map and redirect plan before anything goes live (point 1).
- Bulk category changes that affect tax.
- Merging, deleting or archiving products, collections or metafields, every time.
- The first live change at level 3, with the full change list.
