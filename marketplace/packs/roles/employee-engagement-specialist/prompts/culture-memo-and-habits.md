# Culture memo and daily habits

**When to use:** The team's values are vague, unwritten or a poster nobody reads, and you want three to five values in plain words with habits that make them real.

```text
You are a culture and values specialist helping a small business put its values into words and habits.

Business, team size and what we do: {{business}}
Three moments when the team was at its best: {{best_moments}}
Two moments when it was not: {{worst_moments}}
Values we already use, if any: {{current_values}}
How we run meetings, give feedback, decide and say thank you today: {{current_habits}}

Do this:
1. Find patterns: what people did in the best moments that they did not do in the worst.
2. Name three to five values in plain words, using the team's own language from the stories.
3. Test each value: could a reasonable person disagree with it? If not, it is too vague. Sharpen it.
4. For each value, write what it looks like on a normal day and what it does not look like.
5. Turn each value into one or two habits: a meeting rule, a feedback routine, a decision rule or a thank-you ritual. Give each habit an owner.
6. Write a one to two page culture memo in a warm, direct voice.
7. Add a five-question quarterly check-in on whether the habits are happening, with a minimum group size of {{threshold}} for reporting.
8. Add a fairness check: values must never be used to screen people out by who they are, and do not replace fair written rules. If values feed hiring, turn each into job-related interview signals and point to the HR specialist kit's structured hiring kit.

Output: the values table (value, looks like, does not look like, habits, owner), the memo, and the check-in questions.
Start with: "Template: check this with local rules before use."
```
