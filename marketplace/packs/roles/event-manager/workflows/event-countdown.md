# Event countdown: brief to doors open

**Trigger:** an event is agreed, with a date or date range. Ideally three months or more ahead for a conference or launch; the steps compress for smaller events.

**Access:** set at the start, per tool (see `access.md`). Level 1 to read briefs, quotes and registrations. Level 2 to build the plan, budget, run sheet and messages as drafts and set up registration unpublished. Level 3 to publish registration, send approved guest messages and non-binding supplier requests, and edit agreed live documents. Until you choose, I work at level 1.

## Steps

1. **Brief and budget.** Use the `event-brief-budget-and-timeline` skill: one-page brief, budget with statuses, payment schedule, countdown timeline with outside deadlines, risk list.
2. **Access first.** Run the `access-and-inclusion-checklist` prompt before choosing a venue, so access shapes the choice.
3. **Suppliers and venue.** Send briefs and quote requests with the `supplier-brief-and-quote-request` prompt (level 3 within agreed suppliers). Compare quotes and summarise contracts with the `venue-and-supplier-contracts` skill.
4. **Decision on contracts (client).** The client and their adviser review the summaries. Signing, deposits and any later change or cancellation need the client's fresh yes each time; the client pays.
5. **Licences and safety.** List what applies (for example, a Temporary Event Notice in England and Wales, road closures, Martyn's Law for large UK public events) and who handles each with the venue and authorities. Diary the deadlines.
6. **Registration.** Design the form with the `registration-form-and-data-check` prompt; set it up unpublished (level 2); publish after approval (level 3).
7. **Guests.** Write invitations, reminders and the day-before email with the `guest-invitation-and-reminders` prompt; send approved messages to approved lists (level 3).
8. **Final numbers.** Adjust for no-shows using the client's own history, or the sourced ranges in knowledge section 4, and confirm with the caterer by the contract date.
9. **Run sheet.** One week before, use the `run-sheet-and-contingency` skill: run sheet, "if this goes wrong" list, crew briefing, contact sheet, pack-down plan. Share with the agreed crew and suppliers.
10. **Day.** The crew follows the run sheet; the agent logs any changes and issues for the report.
11. **After.** Within a day, start the `post-event-wrap-up` workflow.

## Outputs

- Brief, budget, payment schedule, timeline and risk list
- Access checklist and venue questions
- Supplier briefs, quote comparison and contract summaries
- Registration form and data plan
- Guest communications
- Run sheet, crew briefing and contact sheet
- Action log

## Needs the client's approval

**Approved once, then run at level 3 within your limits.** Publishing registration, the guest message calendar and lists, sending non-binding quote requests and briefs to the agreed suppliers, editing the agreed documents.

**Always needs a new yes, every time.** Signing or accepting any contract, booking form or binding quote; paying or authorising any deposit or balance (the client pays); cancelling or changing a booking; adding a payee; sharing attendee data with anyone new; sending to a new list; deleting records.
