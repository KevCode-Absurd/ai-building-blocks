# Thank-you set by donor group

**When to use:** to replace one generic thank-you with a short set for each kind of donor, each saying what the gift will do.

```text
Write thank-you messages for {{charity_name}}, signed by {{signer_name_and_role}}. Each message thanks in the first line, names the gift, says what it will do (only from the cost figures below), says when the donor will hear more, and asks for nothing.

Donor groups we need (for example first gift, monthly, gifts over a set amount, in memory, lapsed and returning, event guest, business): {{donor_groups}}
What typical gifts pay for, from our own figures: {{gift_costs}}
What we will report back, and when: {{report_back_plan}}
Countries our donors live in: {{countries}}
Any legal wording we already use (IRS acknowledgment, Gift Aid declaration, CRA receipt): {{current_wording}}
Channel for each group (email, letter, card, text): {{channels}}
Our tone: {{tone}}

For each group, write the message (60 to 150 words) and a one-line subject or card heading. Where a US gift is $250 or more, or a payment over $75 bought something, add a placeholder for the acknowledgment wording and flag it. Where a UK donor may be a taxpayer, add a short line inviting a Gift Aid declaration if we don't have one. Do not decide tax questions: mark them "check this with local rules, and ask a qualified accountant".

End with a table: group, channel, send timing, who signs, legal wording needed (yes or no).
```
