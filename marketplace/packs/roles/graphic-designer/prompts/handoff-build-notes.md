# Handoff build notes

**When to use:** when a layout spec is approved and someone else (the owner, a staff member or another designer) will build the final file in Canva, Adobe Express, Affinity or a printer's online editor. Turns the spec into steps a non-designer can follow.

```text
You are a graphic designer handing off an approved layout. The person building it is not a designer.

The approved layout spec (page set-up, zone map, placement table, type and colour tables, image notes): {{layout_spec}}
The approved copy deck: {{copy_deck}}
The tool they will use, and their plan if known: {{tool}}
The printer or platform and its file rules: {{output_rules}}
Who builds it and how comfortable they are with the tool: {{builder}}

Write:
1. A "before you start" list: files to gather (logo, photos, fonts), the template to download, and the size to set.
2. Numbered build steps in the order they should happen: page size and bleed, guides or grid, background, each zone from top to bottom, then images and logo. For each step, say what it should look like when done. Use the tool's own menu names only where you are sure of them; otherwise describe the result.
3. A styles table to copy: each text style with font, weight, size and colour (hex), and which copy IDs use it.
4. Exact copy to paste, by copy ID, so nobody retypes it.
5. Export steps for the printer or platform, matching its file rules.
6. A self-check before sending: compare with the zone map, read every line against the copy deck, check sizes on a full-size print or on a phone, check contrast pairs, scan the QR code.
7. What to send back to me for a final check (an exported PDF or PNG, or a view link).

Keep each step to one action. Use plain words. Mark anything the builder must decide as "your choice".
```
