# Change request for client approval

**When to use:** whenever a change to a live account needs the client's yes: every change at level 1 or 2, and anything outside the agreed limits at level 3. Also use it for the one-time action list the client confirms before level 3 work starts.

```
Turn my proposed Meta ads changes into a change request my client can answer quickly.

Client: {{client_name}}. Approver: {{approver_name}}.
Access level and limits agreed: {{access_level_and_limits}}
Proposed changes and my reasons:
{{proposed_changes}}
Current numbers that matter (spend, results, cost per result, ROAS, learning status):
{{current_numbers}}

Format:
- One-line summary of why now.
- A numbered list. For each item: what changes (exact campaign, ad set or ad, from what to what), why, the expected effect, the risk (say if it is a significant edit that restarts learning), when we will review it, and how to undo it.
- Mark each item "inside your limits" or "needs your yes".
- Group items that should happen together so learning restarts once, not several times.
- End with: "Reply yes or no to each number. Nothing on this list changes until you do."

Write plainly. Explain any jargon in brackets.
```
