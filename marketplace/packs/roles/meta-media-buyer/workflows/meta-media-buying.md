# Meta media buying

Own one Meta account from diagnosis through verified delivery and review. Start here for an account audit, campaign launch, budget or bid change, tracking review, creative test or optimization. This workflow governs execution when a generic checklist assumes access or platform features.

## Account and capability check

1. Discover actual tools and inspect their read, draft and mutation capabilities. A tool guide does not prove a connector is installed. Resolve the current Meta account ID, currency, timezone, markets and account status through Meta Ads Manager and Events Manager when access exists. Never substitute a different platform's ads connector.
2. Read current state before diagnosis. Request only the missing evidence: Meta campaign/ad-set/ad exports, placement and creative results, Events Manager diagnostics and catalogue status, plus comparable store orders, refunds, margin and inventory. If only exports are available, record their dates and limitations and finish Meta campaign build sheet and approved ad copy/assets. Label it local and unsubmitted.
3. Read shared brand-brain facts; store operating memory under `context/media-buying/meta/<account-id>/`. Keep account IDs, attribution settings, tests, creatives, budgets and action history there. Shared brand facts do not grant shared operating authority. Do not put credentials or customer-level personal data in the memory.

## Meta decisions

- Audit campaign and ad-set structure, Facebook and Instagram placements, catalogue/product sets, creative fatigue, bids and pacing. Choose the campaign type and test cadence from current account evidence; verify available settings instead of imposing a fixed learning threshold or automatic budget percentage.
- Check Meta Pixel and Conversions API (CAPI). Trace a purchase through browser/server or import routes, record deduplication evidence and distinguish a tracking event from an attributed conversion. Do not place a paid test order without authority.
- Record metric source, date range, currency, timezone, conversion definition, attribution window and reporting lag beside each result. Keep platform-attributed conversions separate from store totals. Do not add Meta, Google, Snapchat and TikTok conversions together as unique orders. Use store orders/refunds and margin for business outcomes; do not force attribution reports to equal store totals.
- Set a test hypothesis, budget, minimum evidence and stop/review rule from this account's economics. Verify changing feature limits and rules against current official documentation or the live account. No fixed scaling percentage or universal learning threshold is an instruction to spend.

## Authority and execution

Maintain an explicit mutation allowlist: platform `meta`, exact account IDs, permitted object IDs and operations, access level, approved campaign plan, budget amount/currency/units and kind, cap, dates, end time and maximum change. Reuse existing approval only inside that scope. Read access permits no writes; draft access permits only the agreed non-live changes; publishing requires live-change authority. No permission transfers between platforms or accounts. If a required permission is missing, complete the reviewable build file before asking.

Before mutation, inspect the current tool schema and object state, confirm all intended targets against the allowlist and preview the exact change. If paused creation is unavailable, prepare a local build file; never create an active campaign just to simulate a draft. A lifetime or average budget is not a guaranteed daily spend ceiling. Confirm enforceable pacing controls and disclose any unsupported cap before launch.

Capture actual returned IDs, then fresh readback of status, budget, dates, audience, destination and tracking. Reconcile partial successes by ID before retrying. Report saved draft, submitted/reviewing, active and observed delivery separately. A successful API response or ACTIVE configuration alone does not prove impressions, spend or conversions.

## Ownership and finished output

Keep the job with this platform buyer through audit, campaign plan, creative test, authorized execution and review. Use another specialist only for a specific missing asset or technical fix. In the e-commerce team, Jared (`jared-performance-marketing`) owns cross-channel allocation. In other teams, use the named allocation owner from that team's context; do not assume Jared is available. Recommend changes to the channel share without moving another channel's budget. In the e-commerce team, Lindsey owns Meta budgets and testing; Dustin (`dustin-ad-deployment`) handles approved Meta copy or scoped launch execution, never an independent budget decision. Outside that team, the current Meta buyer retains ownership and uses only helpers available in its team context.

Deliver the account snapshot, evidence-backed decisions, Meta campaign build sheet and approved ad copy/assets, scoped approval record, change log/readback when executed, and the next test with its review date and stop rule. With no connector, deliver those local artifacts and the exact remaining operation without claiming a live result.
