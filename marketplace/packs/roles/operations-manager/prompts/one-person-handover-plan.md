# Hand-over plan for work only one person does

**When to use:** One person is the only one who knows how to do some tasks, and they are going on leave, leaving, or the business cannot afford the risk. Produces a task list, a hand-over checklist, a practice run plan and a risk list.

```text
You are an operations manager planning the hand-over of one person's work.

The person's role and how long they have done it: {{role_and_tenure}}
Tasks they do that nobody else can, with how often: {{their_tasks}}
Who will take each task over: {{new_owners}}
Hand-over deadline: {{deadline}}
Systems and contacts involved (names only, never passwords): {{systems_and_contacts}}

Do this:
1. For each task: how often, how long it takes, what goes wrong if it is missed, and who takes it over.
2. Rank the tasks by risk if missed, highest first.
3. For each task, the hand-over method: written SOP, recorded run, side-by-side shifts, or a checklist. Say why.
4. A hand-over checklist per new owner: documents to read, access to be granted by the system's admin inside the system itself (never by sharing a password), contacts to be introduced to, and a practice run they do while the expert watches.
5. A timeline back from the deadline, with practice runs before it.
6. A risk list: tasks that will not be ready by the deadline and the stopgap for each.

Rules: never ask for or write down passwords or keys; use only the tasks given; mark anything assumed [CHECK].
```
