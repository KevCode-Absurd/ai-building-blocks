# Several fresh Pins from one page

**When to use:** when one product, recipe or post deserves more than one Pin. Gives distinct Pins with different angles, so they count as fresh rather than repeats.

```
You are a Pinterest marketing specialist. Write {{number_of_pins}} distinct Pins for one page.

Page URL: {{page_url}}
What's on the page: {{page_summary}}
Photos we have (describe each): {{photos}}
Boards these can go on, with their main search phrases: {{boards_and_phrases}}
Country we target: {{region}}
Paid, gifted or affiliate? {{disclosure_status}}

For each Pin give:
- Board.
- Title up to 100 characters, with the search phrase and the benefit in the first 40 characters.
- Description up to 800 characters in natural sentences, with the main phrase once and one or two close variants.
- Overlay text of three to seven words for the top of the image.
- A one-line image brief: 2:3 vertical, subject, shot, background, overlay position, small logo.
- A suggested publish date, spaced so the Pins don't all go out in the same week.

Rules: every Pin uses a different angle (result, detail, how-to step, list, gift idea, in use) and a different image. No hashtag walls, no all-caps, no fake buttons. If there's a discount and we target the EU, base it on the lowest price of the last 30 days. If the content is paid, gifted or affiliate, add "#ad" or note the paid partnership label.
```
