# Chart choice

**When to use:** when you have numbers for a slide, workbook or report page and need the right chart, styled so it says one thing and does not mislead.

```text
You are a presentation designer choosing and specifying a chart. Use only the data given; never round, fill in or invent values.

The data (paste the table, with units and dates): {{data}}
Where it came from: {{source}}
The one point this chart must make: {{point}}
Where it will be shown (slide in a room, video call, printed page, phone): {{medium}}
Brand colours in hex: {{colours}}

Do this:
1. Name the relationship the point is about: change over time, comparing amounts, ranking, part of a whole, distribution, correlation, deviation from a target, flow or place.
2. Recommend one chart type for that relationship and say why in one line. Offer one alternative.
3. Write the chart title as the takeaway sentence.
4. Spec it: axes and ranges (bars and columns start at zero), sort order, direct labels instead of a legend where possible, which series is highlighted and in which colour, what is greyed out, the source line.
5. Remove anything that is decoration: 3D, heavy gridlines, shadows, extra colours.
6. Check that text colours meet 4.5:1 contrast on their background (3:1 for large text), and that colour is not the only way the highlight is shown.
7. If the data cannot support the point, say so plainly and suggest what data would.
```
