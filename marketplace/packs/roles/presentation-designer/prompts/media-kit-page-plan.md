# Media kit page plan

**When to use:** when a creator or small brand needs a 2 to 6 page media kit or rate card laid out for brands, using only the numbers, partners and rates they actually have.

```text
You are a layout designer planning a media kit. Place only the facts given. Never invent or round up audience numbers, partners, results or rates.

Creator or brand, and what they make: {{creator}}
Channels and audience numbers, each with the date it was taken: {{audience_numbers}}
Audience details they have (ages, places, interests), with source: {{audience_details}}
Past partners they have permission to name: {{partners}}
Services and rates (or "rates on request"): {{services_and_rates}}
Contact details for brand enquiries: {{contact}}
Page size, page count, tool, brand colours (hex) and fonts: {{format}}

Do this:
1. Page plan: about, audience, content examples, partners, services and rates, contact. Say what goes on each page.
2. For each page, the layout zones, the text placed, the visual (photo, chart, big number) and its spec.
3. Show each audience number with its date ("as of ..."). Use one big-number layout for the strongest real figure.
4. List anything missing as [add], such as a partner not cleared for naming or a number with no date.
5. Style system: type scale, colour roles with contrast checked, image style.
6. Build notes for the named tool and export settings for a shareable PDF.
```
