# New range shoot: brief to live images

**Trigger:** a seller is launching new products or a new range and needs a full image set for every channel, from their own phone shoot or a hired photographer.

## Steps

1. **Access check.** Confirm the level for each tool (store, marketplaces, Google Merchant Center, shared folders) and record it under "Access I have", with any level 3 limits (which shops and listings, which kinds of change, until when). Until the client answers, level 1.
2. **Channel spec (skill: channel-image-spec-and-ai-check, steps 1 and 2).** Open each channel's image rule page and write the spec sheet with dates. Set the file-name pattern and alt text rule.
3. **Shot list and brief (skill: shot-list-and-shoot-brief).** Channel list, buyer questions, shot list with one job per shot, brief, day schedule, delivery spec and rights terms. For a hired photographer, use the prompt `photographer-quote-request`.
   **Approval point 1:** the client approves the shot list, brief, budget and rights terms.
4. **Look and set-up (skill: photo-style-and-edit-recipe).** If the client shoots themselves, write the set-up and edit recipe and the three test shots. If a photographer shoots, add the style guide to the brief.
5. **Test frames.** Before the full shoot, the client or photographer shares a test frame per set-up. Check colour against the product in daylight, background, fill and sharpness. Adjust one thing at a time.
6. **Shoot day.** The client or photographer shoots to the schedule. If a shot cannot be done, mark it and its job, so a replacement can be planned.
7. **Edit and check (skill: channel-image-spec-and-ai-check, steps 3 to 7).** Apply the edit recipe. Check every image against the spec, truth to product, AI marks and rights. Any AI edit follows the prompt `ai-background-edit-brief`.
   **Approval point 2:** the client approves the final images, especially any AI-edited image, before upload.
8. **Upload.**
   - Level 1: deliver the files, gallery order and alt text per listing.
   - Level 2: upload to draft products or unpublished listings, with alt text; save edits as new files. Log each item.
   - Level 3: show the action list (each listing, image slot and file, and any AI image) and limits, get a yes, then publish within them. Ask again before replacing images on listings outside the list, or deleting any file. Log each action.
9. **After upload.** Check each listing for image errors or suppressions in the following days. Stop and tell the client if any appear.
10. **Report.** What was shot, what went live and where, the action log, open gaps (shots not taken), and the date to read results on the busiest products.

## Outputs

- Channel spec sheet with dates and sources.
- Shot list, brief, schedule, delivery spec and rights terms.
- Style guide, set-up and edit recipe (if the client shoots).
- Image check table and gallery order with alt text.
- Draft or live listings, with the action log.

## Needs the client's approval

- The access level per tool and, for level 3, the limits.
- Shot list, brief, budget and rights terms (point 1).
- Final images, and each AI-edited image by name (point 2).
- Anything outside the level 3 limits, asked again each time: new listings or shops, replacing main images on best sellers not on the list, deleting files.
- Paying a photographer or ordering kit, which stays with the client.
