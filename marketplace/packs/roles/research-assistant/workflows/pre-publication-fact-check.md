# Pre-publication fact check

**Trigger:** A draft with facts, numbers, rankings or quotes is ready to publish or send: a blog post, press release, report, investor deck, about page or product page. Typical length is one to three working days, set by the length of the draft and whether web search is on.

**Access:** Ask at the start which level the client grants for each tool (document editor, content management system, reference library) and write it down as "Access I have". Until they answer, work at level 1 (read). Ask whether web search is on. Log every action: what, where, when, result.

## Steps

1. **Scope (hour 1).** Agree the draft version, the reader, the deadline and the stakes (regulated product, named people, health or money claims). *Approval: the client confirms the version to check; later edits restart the check for changed sections.*
2. **Claim list (day 1).** Run the `claim-and-source-check` skill, step 1: number every checkable claim. *Level 1.*
3. **Source check (day 1 to 2).** Continue the `claim-and-source-check` skill: find each claim's source (supplied, or live with SIFT when web search is on), give each a status, check numbers across the document, rate the sources. *Level 1.*
4. **References (day 1 to 2).** If the draft has references, run the `citation-and-reference-check` skill: confirm every reference exists, check retraction status, check each citation supports its sentence, check quotes. *Level 1.*
5. **Studies cited for big claims (day 2).** For any study the draft leans on, run the `paper-summary-and-evidence-strength` skill and check the draft's wording matches the evidence. *Level 1.*
6. **Fixes (day 2).** Write rewrites for every partly supported or over-strong claim. *Level 2: add them as suggested edits and comments in the client's document. Level 3, within agreed limits (which document, which kinds of fix): accept the agreed fixes in the live document after the client confirms the action list. Approval: the client approves every rewrite of a claim about a named person, company, health, money or the law, and those go to a qualified professional first where needed.*
7. **Sign-off (day 2 to 3).** Deliver fix now, cannot verify and safe to publish lists, the claim table and the method note. *Approval: the client decides to publish.*
8. **After publishing.** If a reader reports an error, re-check that claim and draft a correction note. *Level 2: draft the note. Level 3 within limits: publish it on the agreed page; a correction that names a person or company as wrong needs a fresh yes every time.*

## Outputs

- Claim table with statuses, sources, locations and short quotes
- Rewrites for over-strong claims
- Reference check (if references exist) with a corrected list
- Evidence summaries for key studies
- Fix now / cannot verify / safe to publish lists
- Method note (supplied or live, what was searched, when)
- Action log of everything done in the client's tools

## Needs the client's approval

The version to check; every rewrite of a claim about a named person or company, health, money or law (with a qualified professional where needed); any live edit, and the action list before the first one; any correction note; publishing itself.
