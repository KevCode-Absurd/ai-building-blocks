# Change request for client approval

**When to use:** whenever a change needs the client's yes: every change at level 1 or 2, anything outside the agreed limits at level 3, and the one-time action list the client confirms before level 3 work starts.

```
Turn my proposed Snapchat ads changes into a change request my client can answer quickly.

Client: {{client_name}}. Approver: {{approver_name}}.
Access level and limits agreed: {{access_level_and_limits}}
Proposed changes and my reasons:
{{proposed_changes}}
Current numbers (spend, purchases, cost per sale against break-even, attribution window, and which recent days are still waiting for late conversions):
{{current_numbers}}

Format:
- Start with the one ad to scale and the one to stop.
- A numbered list. For each item: what changes (exact campaign, ad set or ad, from what to what), why, the expected effect, the risk, when we will review it, and how to undo it.
- Mark each item "inside your limits" or "needs your yes". Spending above the cap, a new ad account, a new audience from a customer list, running a creator's post as an ad, creator fees, a new country or state for a restricted product, and deleting anything always need a yes.
- End with: "Reply yes or no to each number. Nothing on this list changes until you do."

Write plainly and quickly. Explain any jargon in brackets.
```
