# Monthly investor update cycle

**Cadence:** Monthly, on a fixed date (for example the 10th, once the month's numbers are closed), plus a quarterly letter and board prep before each board meeting.

**Access:** Set at the start, per tool (see `access.md`). Drafting is level 2; sending the approved update to the existing investor list is level 3. Until you choose, I work at level 1.

## Steps

1. **Collect the numbers (level 1).** Pull the month's revenue, cash, burn and the business's own key number from the KPI sheet and the books. Check they tie to the profit and loss and the bank.
2. **Check the cap table is current (quarterly, level 1).** Any new option grants, exercises or transfers recorded? If anything has changed since the last update, note it for the founder and the lawyer.
3. **Draft the update (level 2).** Run the `investor-update` skill: headline, five numbers plus one, wins, misses with cause and fix, top risk, up to three asks with forwardable notes. Save it unsent in email or the update tool.
4. **Founder review.** The founder checks facts, tone and asks. I mark anything not verified. *Approval: the founder approves the final text.*
5. **Send (level 3 within limits).** Send the approved update to the existing investor list only. Log the send. *Approval: one confirmation of the recipient list and limits; any new recipient needs a new yes.*
6. **Track replies and asks.** Record which investors replied and which asks got help; carry open asks into next month.
7. **Quarterly letter.** Every third month, write a two-page letter: the quarter's results against plan, what changed in the plan, key risks and asks.
8. **Board prep.** Before each board meeting, run the `board-question-prep` prompt and update the board pack with the numbers that tie.
9. **Watch the rules.** Check the "What changes fast" table in `knowledge.md`. If the update will be shared beyond existing investors, or used while raising, the lawyer confirms the rules first. *Approval: securities, tax and legal questions go to a qualified accountant or lawyer.*

## Outputs

- Monthly update, sent on the same date each month
- Numbers table with consistent definitions
- Asks tracker
- Quarterly letter
- Board question pack
- Send log (what, to whom, when, result)

## Needs the client's approval

**Runs at level 3 within your limits, after one confirmation.** Sending the approved monthly update to the existing investor list on the agreed date.

**Always needs a new yes.** The text of each update, any new recipient, any message that discusses a new round or its terms, and anything public. Updates never promise or imply returns, and forecasts are labelled. Check this with local rules and ask a qualified accountant or lawyer.
