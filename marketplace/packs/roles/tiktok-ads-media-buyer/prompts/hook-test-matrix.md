# Hook and format test matrix

**When to use:** planning the next round of TikTok creative tests, so each test changes one thing and has a kill rule before it starts.

```
Build a TikTok hook and format test matrix.

- Product and the one promise we are testing: {{product_and_promise}}
- Who it is for and how aware they are of the problem: {{audience_and_awareness}}
- Proof we can stand behind: {{proof}}
- Break-even cost per sale or sign-up: {{break_even}}
- Daily test budget the client approved: {{daily_test_budget}}
- Formats we can make (talking head, demo, unboxing, slideshow, creator): {{formats_available}}
- Past winners and losers, with hook names: {{past_results}}

Give:
1. Five hooks, each with a short name, written for different awareness levels, with the first two seconds as its own line (spoken words and on-screen text).
2. A matrix: hook name, format, length, the one thing that changes from the control, kill rule, and how long the cell runs.
3. Which three to launch first and why.
Rules: brand visible in the first 2 seconds; most ads under 25 seconds; no claims beyond the proof given (write [NEEDS PROOF] if needed); mark any AI-made realistic person or voice "AIGC disclosure on". Do not invent benchmark numbers.
```
