# Weekly shop cycle

**Cadence:** every week once the shop is live, with a monthly check of TikTok's rules. Monday reads last week; the rest of the week makes and sells.

## Steps

### Monday: read and decide

1. Pull last week's Seller Center exports (level 1) and run the **weekly-shop-review** prompt. Rank by contribution, not sales.
2. Pick three actions: one thing to cut, one to repeat, one test (change one thing at a time).
3. List anything that needs the client's fresh yes: new paid creators, commission changes, price changes outside the plan.

### Tuesday: content

4. Run the **shoppable-video-briefs** prompt for the week, building on the formats that sold.
5. Run the **claims-price-and-disclosure-check** prompt on every script and caption.
6. Level 3: schedule or post approved videos. Level 2: save drafts.

### Wednesday: creators and samples

7. Work the sample request log with the **creator-affiliates-and-samples** skill. Approve within the rule and budget (level 3) or prepare decisions (level 2).
8. Check last week's creator posts for labels, claims and offers. Ask for fixes the same day; pause samples for repeat failures and tell the client.

### Thursday: listings and stock

9. Fix any listing issues from Seller Center notices or returns reasons, using the **tiktok-shop-listing** skill.
10. Check stock cover for heroes and dispatch times; flag any hero under two weeks of cover.

### Friday: LIVE

11. Build the run sheet with the **live-selling-run-sheet** skill, including the offer check.
12. Level 3: start and end approved promotions on time. The host goes live.
13. After the LIVE: orders, watch time, orders by segment, and the one change for next week.

### Monthly

14. Run the **tiktok-rules-snapshot** prompt again and compare with last month. Update the margin table if fees changed.
15. Run the **fulfilment-and-returns-check** prompt before any sale period.

## Outputs

- Weekly review with three actions and owners.
- The week's video briefs, checked scripts and posted videos (level 3).
- Updated sample and post check logs.
- Listing fixes and a stock note.
- LIVE run sheet and after-LIVE notes.
- Action log: what, where, when, result.
- Monthly rules snapshot and any margin changes.

## What needs the client's approval

- New creators invited into paid commission offers, and commission changes: a fresh yes every time.
- Prices, offers, "was" prices and deadlines outside the approved plan.
- Replies to formal complaints, disputes or policy appeals.
- Deleting listings or videos.
- Anything new in TikTok's rules that changes the plan.
- Refunds above the client's limit, payouts and payout details stay with the client.
