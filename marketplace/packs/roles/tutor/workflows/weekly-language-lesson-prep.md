# Weekly language lesson prep and practice between classes

**Trigger:** A language teacher, tutor or school runs regular classes and needs fresh practice for each lesson, plus short practice for learners between classes.

**Cadence:** Weekly, two or three days before each lesson; daily practice messages on the days the teacher chooses; a short level check every few units.

**Access:** At the start, ask which level the teacher grants for their documents, the class tool and the messaging tool, and record it under "Access I have". Until they answer, work at level 1. Steps marked [L2] need read and draft access; steps marked [L3] need read, write and publish access within the teacher's limits.

## Steps

1. **Set up once.** Record the language, CEFR level, class size, lesson length, the course book units or syllabus, the learners' first language, and whether any learners are under 18. For children, record the school's or parents' consent for any messages and the safeguarding contact. *Approval: the teacher confirms the set-up.*
2. **Collect the week's brief.** Topic, unit word list, grammar points, and the errors the teacher heard last lesson.
3. **Write the practice set.** Run `language-practice-set`: key words, dialogue, drills from easy to hard, speaking task, fluency round and answer key. [L2] Save it in the teacher's folder.
4. **Add role-play cards.** Run the `role-play-cards` prompt for the lesson's speaking task if the set needs more pairs or a workplace situation.
5. **Teacher review.** *Approval: the teacher approves or edits the set before it is used.*
6. **Confirm the live action list.** [L3] The first time, show the actions and limits: which class the set is posted to, which learners get daily messages, at what time, which days, until when. *Approval: the teacher's yes.*
7. **Post and send.** [L3] Post the approved set to the named class as practice, and send the approved daily practice messages to learners who opted in: one small task a day, with the answer the next day. Stop at once for anyone who asks. At lower levels, the teacher posts and sends.
8. **Deck.** Every two or three units, build a vocabulary deck file with `flashcard-deck-builder`, tagged by unit. [L2] Save it for the teacher to share.
9. **Level check.** Every few units, write a short level check with answers and score bands (`language-practice-set`, step 8). It is a teaching check, not an official certificate. *Approval: the teacher decides how results are used.*
10. **Review.** Each week, read replies to practice messages (if the teacher shares them) and the teacher's notes; feed common errors into next week's set. Flag anything worrying in a learner's message to the teacher or safeguarding contact at once.

## Outputs

- Weekly practice set with answer key and role-play cards
- Daily practice messages
- Vocabulary deck files by unit
- Level checks with answers and score bands
- Action log of every post and message

## Needs the client's approval

The set-up and consents, every practice set before use, the level 3 action list and limits, and anything outside them: a new class, new learners, a new time or channel for messages, or anything that would count towards a mark.
