# Weekly clip batch

**Cadence:** weekly. The client publishes a podcast, webinar or long video each week and wants a steady set of short clips from it on the same days each week.

## Steps

1. **Review last week (level 1).** Read results for last week's clips: views, audience retention, average view duration, follows. Note which openings held viewers and which lost them. With no access, ask for screenshots or exports.
2. **Check this week's rules.** Open each platform's help page and note the current clip limits and any music rule changes with the date (for example YouTube Shorts up to 3 minutes; Shorts over 1 minute with an active claim blocked, as of 6 Nov 2026). For TikTok, note the upload limit shown in the client's account.
3. **Pick clips (skill: short-clip-finder).** From this week's timed transcript, pick the agreed number of clips. Use last week's results as evidence for which kinds of opening to favour, and say when the pick is judgement.
4. **Meaning check (prompt: meaning-check-on-cuts).** Check each clip's in and out points against the full source.
5. **Captions (skill: clip-captions-srt).** One clip-relative caption file per clip, from the final audio, inside the safe zone if burned in.
   **Approval point:** the client approves the week's clips, hook text, captions and music.
6. **Build and schedule.**
   - Level 1: deliver the clip table, caption files and a posting calendar.
   - Level 2: cut draft clips in the connected tool and upload them as drafts or private.
   - Level 3: show the week's action list (channels, clips, dates and times) and get a yes, then schedule within those limits. Ask again before posting to a new account, changing the agreed days or deleting a live clip.
7. **Log and report.** Log each upload and its result. Stop and ask on any claim, block or policy warning. At the end of the week, report results against last week and the plan for next week.

## Outputs

- Weekly results note.
- Clip table with hooks, lengths, ratios and music status.
- Caption files per clip.
- Draft clips (level 2) or scheduled posts (level 3).
- Action log.

## Needs the client's approval

- Access level and level 3 limits (channels, number of posts, days).
- Each week's clips, hook text, captions and music.
- Any licence bought or accepted, each time.
- Disputing a claim, deleting a live clip, or posting to a new account.
- Anything outside the agreed limits.
