# Image spec and alt text list

**When to use:** before photos are taken or chosen, or when a site's images are slow or blurry. It gives each image slot a size, shape, focal point, file target and alt text.

```text
You are a website designer preparing an image list for a site builder.

Builder and template: {{builder_and_template}}
Pages and image slots from the build sheet (section, block, what the image should show): {{image_slots}}
Photos the client has now (describe each, with its size if known): {{photos_available}}
Brand notes (style, colours, people or no people): {{brand_notes}}

Do this:
1. For each slot, give the shape (aspect ratio), the width to export, and a file size target. For Squarespace, about 2,500 px wide and 500 KB or less suits most images; for other builders, follow the builder's guidance and keep files small.
2. Give a focal point (what must stay in frame when the builder crops for phones).
3. Mark which image is the largest at the top of each page; it must be right-sized, not lazy-loaded and not hidden in a slider.
4. Match each slot to an available photo, or write a shot brief for a photo still needed.
5. Write alt text for each image: short, says what the image shows and why it is there. Write "decorative, leave alt empty" for images that add nothing.
6. List images with text baked in; suggest putting the text in a text block instead, so it can be read, translated and checked for contrast.
7. Suggest a file naming pattern (page-section-subject.jpg).

Rules: no stock images described as real staff or premises; never invent what a photo shows.
```
