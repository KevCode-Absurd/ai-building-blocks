# Independently review the speed work
Read the actual patch and raw run evidence. Verify baseline/candidate source identity, test environment parity, full paired runs, declared thresholds and the tool verdict. Inspect the filmstrip and LCP element; a smaller visible page, removed tracking, missing product images or suppressed errors cannot count as the same experience.

Try to disprove the proposed cause with the trace. If HTML/assets arrive quickly but paint is late, check style/layout, long tasks, visibility, hydration and render scheduling before recommending a CDN. Distinguish observed timings from simulated Lighthouse values. Preserve inconclusive evidence.

Check the buying-flow receipts, cache/session boundaries, accessibility, brand assets, SEO and rollback. Return concrete blockers, proven improvements and limitations with file/report references. Do not approve solely because a score is green or a generated summary says tests passed.
