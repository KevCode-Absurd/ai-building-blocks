Free: code builds the plan

  1. Reject greeting-only/oversized requests. No model call.
  2. Normalize words and synonyms; rank library blocks using rare-term/title/alias matches.
  3. Match reviewed intent methods; join supported compound requests and choose new/existing/reference/platform branches.
  4. Preserve coordinators. Connect typed outputs and explicit conversions; compute external inputs and ordered review gates.
  5. Fill concrete step instructions using the request/context, bounded checks and action boundaries.
  6. Let the user edit and download the complete pack.

Fast, repeatable and free of planning inference charges. Coverage depends on authored intent rules and library contracts. Unknown wording can still pick a weak search match.

Paid: model customizes the plan

  1. The server applies the same input and usage limits; clients cannot send a model override.
  2. Retrieve relevant blocks and reviewed-method candidates from the same library.
  3. Sol interprets the whole request, constraints and business context. Return one JSON plan with allowed-slug enums.
  4. Validate real slugs, instruction lengths,16-step bound, repeat limits and typed inputs. Code owns question selection.
  5. Use the same editor, checks and export as free.

Default budget$2/day total and10 attempts/IP/day in preview, atomic reservations and idempotency. Request: 10,000 characters; additional context: 4,000. Voice has a five-minute per-visit limit; browser support varies. No paywall yet.

Only the generated plan JSON uses billed output tokens. Existing skill files, the README template and the ZIP are assembled by code; the model does not rewrite every file in the pack. Execution of the skills has its own separate costs.
