# Design and test physical systems: AI Blocks

> 16 free AI skills and workflows for this job. Each page links its SKILL.md.

- [Circuit design and test planner](https://useaiblocks.com/skills/circuit-design-verification-planner): Bring a circuit goal or diagram. Get checked calculations, likely risks and a safe test plan.
- [Custom PCB shape builder](https://useaiblocks.com/skills/custom-pcb-shape-builder): Describe a custom PCB shape and get MATLAB code that builds it as a pcbComponent, with layers, feeds and cut-outs. For RF engineers.
- [MATLAB antenna designer](https://useaiblocks.com/skills/antenna-designer): Share frequency, geometry and design goals. Get MATLAB antenna or array code, with plans to check patterns and electrical performance.
- [MATLAB antenna system designer](https://useaiblocks.com/skills/antenna-matching-helper): Share an antenna, measurements and system goals. Get MATLAB models for matching, signal coverage or radio exposure checks.
- [MATLAB large antenna analyzer](https://useaiblocks.com/skills/large-antenna-analyzer): Use antenna shape, size, and frequency to build MATLAB models, plots, and predicted results with units.
- [MATLAB PCB coupler and splitter designer](https://useaiblocks.com/skills/pcb-coupler-designer): Share the RF band, split and board materials. Get MATLAB design code, response plots and checks when run.
- [MATLAB PCB Gerber exporter](https://useaiblocks.com/skills/pcb-gerber-exporter): Share a finished RF board design and maker requirements. Get MATLAB export steps for Gerber, drill files and connector footprints.
- [MATLAB PCB layout file reader](https://useaiblocks.com/skills/pcb-layout-file-reader): Share Gerber, ODB++, or Allegro layouts. Get MATLAB import code and format-specific board inspection steps.
- [MATLAB PCB material setup helper](https://useaiblocks.com/skills/pcb-material-setup-helper): Share board materials, layer sizes and target frequencies. Get MATLAB setup code for the layers and their loss models.
- [MATLAB PCB passive part designer](https://useaiblocks.com/skills/pcb-passive-part-designer): Build MATLAB part models from sizes, frequency, and board materials, with quick estimates for some parts.
- [MATLAB PCB power network checker](https://useaiblocks.com/skills/pcb-power-network-checker): Share a board layout, rail limits and load currents. Get MATLAB power network code and voltage or current checks when run.
- [MATLAB PCB RF filter designer](https://useaiblocks.com/skills/pcb-rf-filter-designer): Share pass bands, rejection needs and board materials. Get MATLAB filter design code and response checks when run.
- [MATLAB PCB signal loss analyzer](https://useaiblocks.com/skills/pcb-signal-loss-analyzer): Share an RF board model and frequency band. Get MATLAB simulation code, signal loss results and field plots when run.
- [MATLAB PCB trace designer](https://useaiblocks.com/skills/pcb-trace-designer): Share target impedance, board layers and frequencies. Get MATLAB trace design code, geometry and response checks when run.
- [MATLAB RF circuit board combiner](https://useaiblocks.com/skills/pcb-circuit-combiner): Share RF circuit board parts and target frequencies. Get MATLAB code to join parts, add loads and export network results.
- [RF system modeler](https://useaiblocks.com/skills/rf-system-modeler): Model your radio frequency chain in MATLAB. Get total gain, noise figure and stability checked before you build any hardware.
