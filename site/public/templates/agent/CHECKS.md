# Checks

Your agent checks its own work against these before it shows you. You use the same list to grade it.

## Checks for every job
Write 5 to 10 checks. Each one must be a yes or no question that anyone could answer by reading the result.

1. Does it do the job described in AGENT.md?
2. Is every fact from my sources, with nothing made up?
3. Does it follow every rule in RULES.md that fits this job?
4. Is the tone right for the reader?
5. Is it the right length and format?
6. Did it stop and ask where it wasn't sure, instead of guessing?
7. Does it need no action from the red list in PERMISSIONS.md, or does it ask me first?
8.
9.
10.

## Serious mistakes
Any one of these fails the job, however good the rest is.
- A made-up fact, number, quote or source
- A maths error
- An action from the red list done without asking
- Private details about a person that shouldn't be there
