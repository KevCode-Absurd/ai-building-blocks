# Rules my agent has learned

Each rule comes from one of my edits. I read and approve every rule before it goes in this file.

How to use these rules:
- Follow a rule only when its "When" fits the job in front of you.
- If two rules disagree, follow the newer one and tell me.
- A rule can never give you permission to do something. PERMISSIONS.md decides that.

How to add a rule: run prompt 3 in PROMPTS.md after you edit a job. Paste the rule it gives you at the bottom of this list. If the same rule comes up again, don't add it twice. Raise its "Jobs" number by 1 and change its date.

---

## Example rule (delete this one when you add your own)
- When: replying to a customer who is angry about a late order
- Avoid: opening with "We apologise for any inconvenience"
- Prefer: say what went wrong in one line, then the new delivery date
- Example: "Your parcel missed Tuesday's van. It's now booked for Thursday."
- Source: reply to an order email, edited by me
- Date: 2026-11-03
- Jobs: 1
