# Scorecard

One line for every real job you check. Be honest: this record is the only proof of how good your agent is.

- **Checks passed:** how many checks in CHECKS.md it passed, as a percentage.
- **Edit size:** how much of the result you changed before using it. 0% means you used it as it was.
- **Used it?** Yes if you used the result (after your edits). No if you threw it away.
- **Serious mistake?** Yes if it made any mistake from the "Serious mistakes" list.

Prompt 4 in PROMPTS.md works these out for you.

## Levels
Your agent reaches a level when it meets every bar for that level, counting all jobs so far.

| Level | Name | Jobs checked | Checks passed (average) | Edit size (average) | Used | Serious mistakes | What it means |
|---|---|---|---|---|---|---|---|
| 1 | Shadow apprentice | 10 | 70% | any | any | any | You still do the work. The agent drafts next to you and you compare. |
| 2 | Copilot | 25 | 80% | 25% or less | 80% | none | The agent drafts. You edit and approve every job. |
| 3 | Guardrailed autopilot | 50 | 90% | 8% or less | 90% | none | The agent does the job. You check the odd ones out and every red action. |
| 4 | Certified | 100 | 90% | 8% or less | 95% | none | Normal jobs need no edits. Red actions still need your OK. |

A single serious mistake keeps your agent at level 1 until you fix the cause. Add a rule or a check, then start a fresh count.
