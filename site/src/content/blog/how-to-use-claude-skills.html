What are Claude skills?

Claude skills are folders of instructions that teach Claude how to perform one particular job your way. Each skill contains a file called SKILL.md, which starts with a name and a short description of when to use it, followed by the steps, rules and checks. A skill folder can also hold supporting files, such as a template, a checklist or a script.

Once a skill is turned on, you no longer need to paste it into every conversation. Claude reads the short descriptions of your skills and loads the full instructions when a request matches one. You can also mention a skill by name in your message to make Claude use it deliberately.

Anthropic launched skills in October 2025 for the Claude apps, Claude Code and its developer platform (see Anthropic's launch post). Canva was one of the companies named in that announcement, and it said it planned to use skills to customise agents. The folder format is also published as an open standard called Agent Skills, so other AI tools can read the same files.

Here is the short version of this guide, in the order you would carry out each step:

  1. Turn on skills in Claude's settings, together with the code execution feature they depend on.
  2. Add a skill by uploading a ZIP of its folder (Claude apps) or copying the folder into your skills folder (Claude Code).
  3. Write your own with a simple SKILL.md containing a name, a description, and then the steps and checks.
  4. Test it with three realistic requests before you rely on it for real work.

All the steps below match Anthropic's help centre and documentation as of November 2026. Menu names change regularly, so follow the linked pages if your screens look different.

How does Claude decide to use a skill?

Claude doesn't read every skill completely before each reply, because it starts with each skill's name and description. If your request fits a description, Claude loads that skill's full SKILL.md, and it opens any supporting files only when they are needed.

That makes the description the most important line you write, and Anthropic's help centre calls it critical, because Claude relies on it to decide when to use the skill. A good description explains what the skill does and when to use it, in the words people would actually type. A description such as "Writes refund replies using our policy, for when a customer requests a refund" works far better than a vague line such as "Helps with customers".

Tip. If Claude ignores a skill you expected it to use, fix the description first, which matches Anthropic's own advice to make sure the description clearly says when the skill applies.

How to install Claude skills in the Claude apps

These steps come directly from Anthropic's help article on using skills in Claude. Skills depend on Claude's code execution feature, so you turn that on first, and the article also lists which plans include skills.

Turn skills on (individual plans)

  1. Open Settings, then Capabilities, and turn on Code execution and file creation. In the newer settings layout, this option is called Create and edit files.
  2. Go to Customize, then Skills, to see the skills available to you.
  3. Turn on the individual skills you want Claude to use.

Upload a skill you downloaded or wrote

  1. Make sure the skill is a ZIP file with the skill folder at its root and SKILL.md inside that folder, because Claude looks for that exact structure.
  2. Go to Customize, then open the Skills section.
  3. Select the + button, then choose Create skill from the options.
  4. Choose Upload a skill and select your ZIP file from your computer.
  5. The skill then appears in your list of available skills, where you can activate it.

On a Team or Enterprise plan

An owner opens Organization settings, then Plugins & skills, and checks the Policy tab, where both code execution and Skills need to be enabled. Owners can also add skills for the whole organisation and can turn off skills that members create, while members turn skills on under Customize, then Skills.

Why an upload fails

Anthropic lists the usual causes: the ZIP is too large, the folder name doesn't match the skill's name, SKILL.md is missing, or the name or description contains unacceptable characters. Its guide to creating custom skills also sets upload limits of 64 characters for the name and 200 characters for the description.

How to add a skill in Claude Code

Claude Code is Anthropic's coding assistant, which runs in your terminal and other places and reads skills from folders on your computer. These steps follow the official Claude Code skills docs.

  1. Pick where the skill should live: for every project on your computer, use ~/.claude/skills/skill-name/SKILL.md. For one project only, use .claude/skills/skill-name/SKILL.md inside that project, so that a project skill can be shared with your team along with the project's files.
  2. Copy the whole skill folder there: keep SKILL.md beside any supporting files it uses, or the skill may fail to find them.
  3. Check that Claude Code recognises it: type /skills to list your skills, or type / and look for the name. If you created a new skills folder, run /reload-skills, although edits to an existing skill are picked up as you make them.
  4. Use it: ask for the job in your own words, and Claude uses the skill when the description fits, or type /skill-name followed by your request to run it directly.

Claude Code is more relaxed about the file than the Claude apps, because the name defaults to the folder name and the description is recommended rather than required. Write both anyway, so that the same skill also works when you upload it to the Claude apps.

How to write a simple SKILL.md

A SKILL.md always has two distinct parts. At the top is a short block of settings, called front matter, which sits between two lines of three dashes, followed by your instructions in ordinary text.

The rules for the top block

  • name: use lowercase letters, numbers and hyphens only, up to 64 characters, such as refund-reply-writer. The open standard says it must match the folder name, and Claude's upload checks this too.
  • description: explain what the skill does and when to use it, and keep it under 200 characters so it uploads to the Claude apps.

What to put in the instructions

  • What to ask for: the material the job needs, and what Claude should do when something is missing.
  • Steps: numbered instructions with one action each, in the order you would carry them out.
  • Rules: your standards for tone, length, words to avoid and anything Claude must never promise.
  • Checks: yes-or-no questions that Claude answers before it hands the work back to you.
  • An example: one short sample of a good result, if you have one available.

Here is a template you can copy into a file named SKILL.md and then adapt for your own job:

---
name: your-skill-name
description: [What it does, in one sentence]. Use when [the requests that should trigger it].
---
# [Skill title]

## Ask for
- [Material 1, for example the customer's message]
- [Material 2, for example our policy]
If anything is missing, ask before you start. Never guess.

## Steps
1. [First action]
2. [Second action]
3. [Third action]

## Rules
- [Tone and length]
- [What never to say or promise]

## Checks before you answer
- [Yes-or-no check 1]
- [Yes-or-no check 2]
Say which checks passed. Fix any that failed.

Keep the file short and focused on one job, since the open standard suggests keeping SKILL.md under 500 lines and moving long reference material into separate files. For a first skill, somewhere between 30 and 60 lines is usually sufficient.

You don't have to write it from scratch, because you can paste this prompt into Claude and let it interview you and draft the file.

Prompt: draft a SKILL.md by interview

You are helping me write a Claude skill for one job I do often.

Interview me first. Ask one short question at a time, at most 10 in all. Cover: what starts the job, what material I give you, the steps I follow, my rules (tone, length, what never to promise), what a good result looks like, and how I check it. I can say "enough" to stop.

Then write the SKILL.md:
- Start with front matter between two lines of three dashes.
- "name": lowercase letters, numbers and hyphens only, under 64 characters.
- "description": what it does and when to use it, under 200 characters, using words I would type when asking for this job.
- Then sections: Ask for, Steps, Rules, Checks before you answer.
- Turn every rule I give you into a line in Rules or Checks.

Checks before you show me the file:
- Nothing is added that I did not tell you.
- The description names the requests that should trigger the skill.
- The file is under 80 lines.
Show the file in one code block. Then tell me the folder name to use, which must match the name.

A worked example: a skill for a Canva template creator

Canva runs a Canva Creators programme, which designers must apply to join. Once approved, they can publish templates to Canva's library and earn from a royalty pool based on how often their templates are used. Canva reviews every submission against its published design guidelines. Its help pages also say it doesn't accept templates made with AI tools to the point that the work isn't wholly the creator's own.

That last rule suggests a sensible skill for a freelance designer in the programme who wants an independent review before submitting, while keeping the design work entirely their own. This example was written for this article, so Canva didn't make it, and it isn't an official Canva tool.

What goes in

  • The guideline text you copy from Canva's current help pages, so the checks reflect the latest rules.
  • Your notes on the template, including what it is for, its pages, its fonts and any text you wrote.

The skill file (short version)

---
name: template-submission-checker
description: Checks my own template notes against the design guidelines I paste in before I submit. Use when I say "check my template" or "ready to submit?"
---
# Template submission checker

## Ask for
- The guideline text, pasted from the current help pages.
- My notes on the template.

## Steps
1. Turn the pasted guidelines into a numbered list of checks.
2. Check my notes against each one: pass, fail or can't tell.
3. For each fail, say what to change, in one line.

## Rules
- Use only the guidelines I paste. Never rely on memory.
- Never suggest AI-made images or designs.
- Don't rewrite my design. Point to the problem only.

## Checks before you answer
- Every guideline has a result.
- "Can't tell" items say what I need to check by eye.

What comes out

You get a table of guidelines with pass, fail or can't tell beside each one, plus a one-line correction for each failure, while every design decision stays yours. Because the skill reads the guidelines you paste in, it remains up to date whenever Canva changes them.

How to test a skill before you rely on it

A skill can look fine on the page and still fail in practice, so test it in three ways before you trust it with real work.

  1. Test that it triggers: start a new chat and ask for the job in three different ways, as a real person would. This follows the help centre's advice to try several prompts that should trigger the skill. If Claude doesn't use it, rewrite the description with the words you used.
  2. Test that it doesn't over-trigger: ask for something similar but different, because a refund skill shouldn't run when someone asks about delivery times.
  3. Test the result: run it on one real, completed job where you already know the right answer, then compare the two. Check whether it follows every step and whether the checks catch what they should.

When a test fails, change one thing at a time and then test again, so you know which change fixed it. In the Claude apps, you can highlight text in a skill file, choose Edit with Claude and describe the change you want.

Prompt: write test cases for a skill

You are a tester for AI skills.

Inputs:
SKILL START
[paste your SKILL.md]
SKILL END

Task: Write test requests for this skill.

Format:
1. Three requests that should trigger the skill, each worded differently, the way a busy person would type them.
2. Two requests that are close but should not trigger it.
3. One tricky case where the skill should stop and ask a question, because material is missing.
For each test, say what a good response must include.

Checks: Use only what the skill says it does. Flag any step or check in the skill that is too vague to test.

Watch out. Skills can include scripts that run when Claude uses them, so only add skills from people and sites you trust, and read SKILL.md before you upload it. Anthropic's help centre notes that Enterprise plans can scan third-party skills before they run.

Common mistakes with Claude skills

MistakeWhat happensDo this instead
A vague description such as "Helps with emails"Claude can't tell when to use it, so it rarely does.Say what it does and when, in the words you would type.
Folder name and skill name don't matchThe upload fails in the Claude apps.Make the folder name exactly the same as the name line.
One skill for many jobsThe steps blur together and results vary.Make one skill per job.
Zipping the files instead of the folderClaude can't find SKILL.md.Zip the folder itself, so the folder sits at the top of the ZIP.

Never updating itYou keep fixing the same thing by hand.Add each correction to Rules or Checks.

Before you upload: a checklist

  • Skills and code execution are both enabled in your settings.
  • The name uses lowercase letters and hyphens, and is under 64 characters.
  • The folder name matches the skill's name exactly, character for character.
  • The description explains what the skill does and when to use it, in under 200 characters.
  • SKILL.md is inside the folder, and the folder is at the top of the ZIP.
  • You have read the entire file, including any scripts it contains.
  • You have three realistic test requests prepared.

Questions people ask

Which Claude plans include skills?

As of November 2026, Anthropic's help article on using skills covers both individual and team plans, but plans change, so check that article for your own subscription. Every skill in the AI Blocks library is free to download.

What is the difference between Agent Skills and Claude skills?

Agent Skills is the name of the open folder format published at agentskills.io, while Claude skills are simply skills used in Claude. A skill written to the open format can also be read by other tools that support the standard.

Do I need to code to make a Claude skill?

No, because a SKILL.md is ordinary text, and scripts are optional additions that most business skills don't need at all.

Why isn't Claude using my skill?

First check that both the skill and code execution are turned on. Then rewrite the description so it says when to use the skill, in the words you actually type, or name the skill in your message to make Claude use it.

Can I use the same skill in ChatGPT or Gemini?

You can attach SKILL.md to a conversation in any AI and ask it to follow the file, and Google now offers skills in the Gemini app too. Check each application's documentation to see exactly how it loads skills.

Where can I find ready-made Claude skills?

Anthropic's guide to creating custom skills links to a set of example skills, and you can also search the AI Blocks library for skills by job. Whatever the source, read the file carefully before you turn it on.
