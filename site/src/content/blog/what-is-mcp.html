What is MCP, in plain words?

What is MCP? It stands for Model Context Protocol, an open standard that lets AI applications such as Claude and ChatGPT connect to other tools and data. Those might be your files, your calendar, your notes app, your shop or a library of instructions. Anthropic, the maker of Claude, created the standard, and many AI applications now support it.

The official site, modelcontextprotocol.io, compares it to a USB-C port, because any device with a USB-C plug fits any USB-C socket. In the same way, a tool that supports MCP can connect to any AI application that supports MCP, without a custom integration for each pair.

For a business owner, that has three practical consequences worth understanding:

  • Your AI can look things up in the tools you connect, instead of relying on you to copy and paste information.
  • Your AI can take actions in those tools, such as adding a spreadsheet row or creating a draft, whenever you allow it.
  • You stay in charge of what it can reach, because you choose which connections to add, which to turn on in each chat and which actions to approve.

In most AI applications, an MCP connection is called a connector, although some call it a plugin or an app. The rest of this guide explains the terminology, the safety rules and the steps to add your first connector.

Model Context Protocol explained: servers, connectors and tools

You will see a few terms again and again, so here is what each one means in practice.

WordWhat it meansExample
MCP serverThe program a company runs so AI apps can reach its tool. It usually lives at a web address.A notes app's MCP server, at a link the app gives you.
ConnectorThe name most AI apps give to an MCP connection once you add it."AI Blocks" in your list of connectors.
ToolsThe actions a server offers. Each tool does one thing."Search notes", "Create page", "Get item".
Sign-inHow the server knows it's you. Often a normal sign-in screen, so your AI never sees your password."Sign in with your account" when you add the connector.

Here is what happens when you ask your AI to use a connector. You make a request, such as "find last week's meeting notes", and your AI recognises that a connected tool can do that, so it asks the server to run it. The server sends back the result, which your AI then uses in its answer. If the tool would change something, your application usually asks you to approve it first.

Tip. A connector gives your AI access to a tool, but your AI can still misunderstand a request, so start with jobs where it only reads and reports.

What can an MCP server let your AI do?

That depends entirely on the individual server. The official MCP site gives examples such as an assistant that can reach your Google Calendar and Notion, and business chatbots that can query several databases. For a small business, typical uses include the following:

  • Read your own material: notes, documents, a product list or a help centre, so that answers are based on your facts.
  • Pull ready-made instructions: a library of skills or workflows that your AI can fetch whenever a job needs one.
  • Act in your apps: draft an email, add a task or update a spreadsheet, with your approval each time.
  • Join apps together: one server can reach many applications, as the Zapier example below shows.

A connector doesn't give your AI new skills on its own, because it only provides access. The instructions for doing a job well still come from you, a prompt or a skill. Our guide to prompts, skills and workflows explains how those fit together.

Is MCP safe? Permissions and trusted servers

A connector can see data and take actions in the tools you connect, which is both its purpose and its risk. Anthropic and OpenAI therefore give similar advice about using connectors safely.

  • Connect only servers you trust. Anthropic's help on custom connectors says to connect only to servers built and hosted by organisations you trust. OpenAI's MCP docs say not to connect a custom server unless you know and trust the app behind it.
  • Read what it asks for at sign-in: review the permissions requested, keep them as narrow as possible, and deny anything the job doesn't need.
  • Turn off tools you don't need: Claude lets you disable individual tools that aren't relevant to a particular chat.
  • Read approval requests before you allow them: in Claude, choose "Allow always" only for tools you trust to run unsupervised. OpenAI says ChatGPT asks for manual confirmation before write actions.
  • Watch for prompt injection: this happens when text inside a web page, email or file tries to give your AI orders. Both makers warn about it, so be careful whenever a connector reads content from outside your business.
  • Keep secrets out of chats: a well-built connector signs you in through its own screen, so you should never need to paste a password into the conversation.

Before you rely on a new server, you can ask your AI to describe its tools first by pasting this prompt into a chat with the connector turned on.

Prompt: review a connector's tools before you use it

I have just connected [connector name]. Before we use it for real work, review it with me.

Task: List every tool this connector gives you.

Format: a table with these columns:
- Tool name
- What it does, in plain words
- Reads only, or can change something (create, edit, send, delete, pay)
- What data it can see

Then:
1. Tell me which tools I need for this job: [describe the job].
2. Tell me which tools I could turn off for this job.
3. Flag any tool that can send, delete, pay or change a live account.

Rules: Do not call any tool that changes anything. If you are unsure what a tool does, say so instead of guessing. Wait for my go-ahead before using the connector.

How to add an MCP connector in Claude, ChatGPT and Claude Code

These steps follow each maker's help pages as of November 2026, although menus change often, and your plan or workspace must allow custom connectors. If a step doesn't match what you see, follow the linked page instead.

Claude (web and desktop)

  1. Go to Customize, then Connectors.
  2. Select + Add, then Add custom connector.
  3. Enter a name and the server's web address, then select Continue to proceed.
  4. Review the sign-in settings and choose the authentication option the server requires, then select Add.
  5. In a chat, select the + button at the lower left, then Connectors, and turn the connector on.

On Team and Enterprise plans, an owner adds the connector first under Organization settings, then Connectors, and members then find it in their own Connectors list and select Connect. Anthropic's help says free accounts can add one custom connector.

ChatGPT

  1. On the ChatGPT website, open Plugins.
  2. Select the plus button, then Add custom MCP server.
  3. Enter the server's address and its authentication details.
  4. Read the risk warning, choose I understand and want to continue, then Create as a plugin.
  5. Install the plugin, then type @ in a conversation and select it from the list.

OpenAI notes that custom servers are third-party services it hasn't verified, and your account or workspace must allow custom MCP servers.

Claude Code

In your terminal, you can add a server with a single command, using a short name and the server's address: claude mcp add --transport http [name] [server address]. Afterwards, run claude mcp list to confirm that it says Connected.

A worked example: Zapier MCP and one safe action

Zapier is an automation tool that connects different applications. Its Zapier MCP page says it connects AI tools such as Claude, ChatGPT and Cursor to more than 9,000 apps, as of November 2026. You connect apps to your Zapier account and then choose which apps and actions your AI may use. Zapier says you can review every MCP action in its History and remove access at any time, and the same page explains how MCP use counts toward your Zapier plan.

Imagine you run a small design studio where new enquiries arrive by email, and you want your AI to add each one to a spreadsheet of leads. This is an example set-up written for this article rather than an official Zapier tutorial.

What goes in

  • In Zapier, you allow one action only, which is adding a row to your leads spreadsheet, and nothing that sends, deletes or pays.
  • You add Zapier MCP to your AI as a connector, using the address that Zapier provides.
  • You paste an enquiry into the conversation and ask your AI to prepare the row.

What comes out

Your AI reads the enquiry, fills in the name, company, request and date received, and shows you the row. Once you approve it, the row is added, and later you can check Zapier's History to see exactly what ran.

The safety comes from the set-up, because the AI can perform only one action, it asks before performing it, and every action leaves a record.

Prompt: a safe first task with any connector

Use the [connector name] connection for this task.

Task: [the job, for example "add this enquiry as one row in my leads spreadsheet"].

Inputs:
INPUT START
[paste the enquiry, notes or other material]
INPUT END

Rules:
- Use only the tool or tools needed for this task. Name them before you start.
- Show me exactly what you will send to the tool (every field and value) and wait for my "yes".
- Never send, delete, pay or publish anything.
- If a field is missing from the input, leave it blank and tell me. Never guess.

After the tool runs, tell me what it returned, and anything that did not work.

Questions people ask

Do I need to code to use MCP?

No, because to use a connector you simply paste a web address into your AI application's settings and sign in if asked. Building your own MCP server, however, does require a developer.

What is the difference between an MCP server and an API?

An API is how one piece of software communicates with another, and each one is different. MCP is a shared standard on top, so any AI application that supports MCP can use any MCP server in the same way. A company can build an MCP server on top of the API it already has.

Which AI apps support MCP?

The official MCP site lists Claude and ChatGPT among AI assistants, along with development tools such as Visual Studio Code and Cursor. Support and plan rules vary by application, so check its help pages.

Can an MCP connector see all my data?

It can see what the server offers and what you allow at sign-in. That is why you should read the permissions carefully, keep them narrow and use servers from companies you trust.

Is MCP the same as a plugin or an app?

Different applications use different names, so Claude calls them connectors, while ChatGPT creates custom MCP servers as plugins. Underneath, the connection uses MCP in every case.
