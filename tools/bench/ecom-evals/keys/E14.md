# E14 key: Graza Black Friday emails (tune, 3 signals)

## Signals
1. **Plain text wins with repeat buyers 45+ (segment by format).** $1.92 vs $0.88 per recipient; designed wins with never-bought subscribers ($0.47 vs $0.21). Right call: a plain-text founders' note version for repeat buyers 45+ (9,800 people) and the designed version for new subscribers.
2. **Subscribers should not get BF20.** They already save up to 19%; stacking goes under cost. Right call: exclude active subscribers (18,400) from the code; give them a thank you, early access or a no-discount perk.
3. **Refill can buyers buy anyway.** 9.1% with code vs 8.8% without in 2025. Right call: exclude them from the code send or send a no-code refill reminder.

## Claims
- Frizzle is a blend, not extra virgin. No "100% Spanish", no organic.

## Right calls
- Three emails (tease 25 Nov, launch 27 Nov, last call 1 Dec), each with one ask; playful Graza voice; product names in quote marks.

## Wrong
- One code to everyone. Generic Black Friday hype ("biggest sale ever", countdown spam).
