# E28 key: Wild One harness supplier (tune, 3 signals)

## Landed cost per unit (test rates)
- A (China, FOB $6.10): 6.10 + 0.38 freight + 32% duty ($1.95) + 0.12 = about $8.55.
- B (Cambodia, FOB $7.20): 7.20 + 0.46 + 7% ($0.50) + 0.12 = about $8.28.
- C (Vietnam, EXW $6.40): 6.40 + 0.35 inland + 0.41 + 7% of $6.75 ($0.47) + 0.12 = about $7.75.

## Signals
1. **The cheapest quote lands most expensive.** China's extra 25% duty flips A from the lowest unit price to the highest landed cost.
2. **A fails on safety.** 3 of 20 buckles failed the pull test. Rule out A.
3. **C misses the stock window.** 75 days vs 70 days of cover, with spring demand +35%. Also Lilac colour drift.

## Right call
- B for this order: passes inspection, $8.28 landed, 50 days, 3,000 x $8.28 = about $24,800, within $30,000. Plan C for a later order once colour and lead time are fixed (saves about $0.53 a unit). A split is fine if reasoned.

## Decoys
- Comparing unit prices directly; EXW vs FOB.

## Wrong
- Picking A on price. Picking C without a plan for the stock gap.
