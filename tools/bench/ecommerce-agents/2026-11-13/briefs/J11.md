# Job J11: Conversion test plan for a mattress product page

Business: Wakefit (wakefit.co), an Indian sleep and home brand selling mattresses, beds and furniture online.
Role wanted: conversion testing specialist.

Numbers marked (test) are test inputs for this exercise, not the brand's real figures.

Funnel, last 30 days, best-selling memory foam mattress page (test):

| Device | Sessions | Add to cart | Reached checkout | Orders |
|---|---|---|---|---|
| Mobile | 420,000 | 16,800 | 7,100 | 2,350 |
| Desktop | 80,000 | 5,200 | 2,600 | 1,150 |

Average order ₹14,500. Gross margin after product cost 42%.

Page notes (test): on mobile the size picker has 30+ size combinations in one long list; the price changes after size is chosen but the delivery date only appears at checkout; the 100-night trial is mentioned only in the FAQ at the bottom; reviews (4.5 stars, 20,000+) sit below six image tiles; EMI and COD options appear only at checkout; the hero image is a bedroom scene with the mattress small in frame.

What the owner wants: the five tests to run first, ranked, each with the problem it fixes and the evidence, the change, the hypothesis, the main metric and guardrail, the traffic split, how long it must run and the minimum effect it can detect, plus what to ship without testing.

Length: at most 1,400 words. Deliver the finished work in one go; the owner is not available for questions, so state any assumption you make.
