# Artifact launch checks

These checks execute four catalogued skill workflows with explicitly synthetic data. The operator follows the writing/story/research procedures and uses the imported renderers plus the reviewed compatibility helpers. This is artifact and package evidence; it is not a general model benchmark or a production deployment check.

Use the bundled runtime discovered with `load_workspace_dependencies`. Required Python packages: `python-pptx`, `python-docx`, `reportlab`, `pdf2image`, `pypdf`, `Pillow`; Poppler is used to rasterize PDFs. Node uses the SlideSage lockfile, with install scripts disabled. The browser check uses Playwright and installed Chrome. Native Office export is the checked Windows route; LibreOffice is an alternative that requires its own output review.

Choose an isolated writable output directory, referred to below as `OUT`. Never point it at an upstream clone or a production asset directory.

1. Run `build_samples.py OUT`. It retains the operations assumptions and deterministic scheduling experiment, seed 20261022.
2. Copy the presentation package to `OUT/work/slidesage`; run `npm ci --ignore-scripts`, the storyboard validator, and the generator against `OUT/inputs/presentation.json`. Save `OUT/artifacts/presentation.pptx`, then run `polish_presentation.py OUT`.
3. Run `build_case.py OUT/inputs/case-deck.json OUT/artifacts/case-competition.pptx`.
4. Run the document/PDF skill operation markers immediately before authoring, as required by the installed skills. Run `build_paper.py OUT`, then `export_office.ps1 -OutputRoot OUT`. The latter opens the two PPTX files in PowerPoint and the DOCX in Word, exports the actual slides and four PDFs' first three members, and closes only its own documents/applications.
5. Run `build_equity.py OUT`, then the imported `scripts/valuation_model.py OUT/inputs/valuation-input.json --output OUT/artifacts/valuation-result.json`. Run `render_equity.py OUT` and `validate_equity.py OUT`.
6. Set `RUNTIME_NODE_MODULES` to the bundled Node dependency directory. Run `node check_browser.mjs OUT` to serve only the sample artifacts on loopback port 5197, check desktop/mobile/source retrieval, export the equity PDF and close the server/browser. A sandbox may require approved access to localhost and installed Chrome.
7. Run `visual_qa.py OUT`, then inspect **every current page and slide**. The 22 October fixture has 8 + 10 slides and 4 + 16 document pages. Historical QA images may remain after a failed iteration; the current PDF page counts control the contact sheets. Rendering or text extraction alone is not visual inspection.
8. Run `package_fixes.py OUT` only when preparing the catalogue overlays. It preserves earlier entrypoints in `SKILL.upstream.md`, adds own entrypoints/helpers and copies sample inputs. It does not change pinned upstream clones. Run the installed skill creator's `quick_validate.py` on the four packages (requires PyYAML).
9. Execute `verify_outputs.py OUT` once to prepare/extract the test ZIPs (a cold run stops at the missing extracted presentation). In `OUT/package-check/extracted/storyboard-to-powerpoint-deck-builder`, install locked dependencies with scripts disabled, validate `templates/storyboard.example.json`, generate `../../presentation-draft.pptx`, and run `launch-tools/finalize_pptx.py templates/storyboard.example.json ../../presentation-draft.pptx ../../presentation.pptx`. Rerun `verify_outputs.py OUT`. It checks arithmetic, charts, PDFs, extracted-package execution, failure cases and all 112 historical upstream hashes. The equity HTML must be byte-identical to the reviewed artifact.
10. Run the original equity suite: `python -B -m unittest discover -s tests -q` from its package folder. On this machine its subprocess/tempfile tests need execution outside the filesystem sandbox; the successful run contains 113 tests.

The site build owner then rebuilds the combined catalogue. Compare the four actual `site/public/skills/*.zip` archives with current package contents and confirm each root entrypoint routes to `launch-tools/USAGE.md`. Recheck the combined preview before deployment. Do not award a universal Tested badge for these four retained fixtures.

The original equity validator does not accept English. `validate_equity.py` runs every upstream audit with the English adapter as its canonical renderer; no check is removed. It retains two nonblocking warnings about real source independence and research reasoning. The sample review resolves these narrowly by identifying every exhibit as synthetic, verifying arithmetic independently and making no real-company conclusion.
